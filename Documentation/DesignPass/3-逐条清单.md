- [ ] `3:029` ## 2. 阶段推进：手动、任务化（问题 38、44）
- [ ] `3:031` **现状**：阶段 = 涌现的能力数，参数 P 和数据 D 都到门槛就自动升阶。全套自动化（crontab、守护进程、AutoML、自动标注）可以在没人操作时自己升阶；房租会在玩家不知情时让电脑被卖掉。
- [ ] `3:033` **规则**
- [ ] `3:034` 1. **升阶要玩家点确认。** P 和 D 都达标后不自动升阶，而是在「成长」页对应能力节点上出现金色按钮「让它试试」。玩家点了才播放涌现动画并升阶。
- [ ] `3:035`    按钮文字最简化为「试」（见《合并删减策划》3.4），下文沿用「让它试试」只为说明。
- [ ] `3:036` 2. **每阶段一个过关任务**，P、D 达标只是前提，任务完成才出现「让它试试」：
- [ ] `3:038` | 阶段 → 下一阶段 | 过关任务（玩家手动完成） | 对应历史 |
- [ ] `3:039` |---|---|---|
- [ ] `3:040` | 1 → 2 | 让它把「异或」桌答到 90%（必须买隐藏层 + S 形） | 感知机学不会异或 |
- [ ] `3:041` | 2 → 3 | 选一门专长：看图或读字，在那张桌拿到 B | CNN / RNN 分叉 |
- [ ] `3:042` | 3 → 4 | 「长句」桌拿到 75%（要门控记忆） | LSTM |

- [ ] `3:051` ## 3. 房租、房东、记账本（问题 44）
- [ ] `3:053` **现状**：能力 3 起收租，每 120 秒扣一次。欠款第 1 天房东弹窗，第 2 天拉闸，第 3 天卖电脑。开始收租时没有任何提醒，玩家觉得「莫名其妙就破产了」。
- [ ] `3:055` **改法**
- [ ] `3:056` 1. **YY 加房东联系人**，昵称带吐槽，比如「包租公·收钱比谁都准时」。所有房东消息都走这个会话，不再用弹窗。
- [ ] `3:057` 2. **开始收租前一天**房东先发消息：「下个月起每天 300，月底我上门收」。
- [ ] `3:058` 3. **桌面加一个「记账本」**（就是一个小程序）：
- [ ] `3:059`    - 阶段 1–3：每笔收支以「小票」形式进收件箱，**玩家要手动一条条贴进账本**（拖进去，或点「记」），有贴纸声和小动画。没贴的小票会堆在角落，账本图标上显示角标「12」。
- [ ] `3:060`    - 阶段 4 起：它学会了「自动同步」，所有收支自己写进账本，还会在 YY 里提醒：「明天该交房租了，余额还差 ¥200」。
- [ ] `3:061`    - 阶段 5–6：它能读懂账本，聊天时会主动提起，比如「这个月电费比上月多了 40%，要不要晚上再跑？」
- [ ] `3:062` 4. **破产保护**：欠款第 1 天，房东和它（阶段 4 以后）都会提醒；第 2 天拉闸前，便签置顶「交房租」；第 3 天卖电脑前给一个确认窗「把电脑卖了交房租？」，选「不」则继续欠着，再过一天强制卖。保证玩家一定看到过 3 次提醒。
