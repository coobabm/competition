- [ ] `4:052` ## 三、结构（网络架构，15 个）
- [ ] `4:054` ### 3.1 主干
- [ ] `4:056` **感知机 Perceptron · 1958**
- [ ] `4:057` - 一句话：一根会学习的开关。
- [ ] `4:058` - 效果：能分开「一条直线能分开的东西」
- [ ] `4:059` - 科普：每个输入乘上一个权重，加起来超过门槛就输出「是」。答错了就调权重，这就是最早的「学习」。Frank Rosenblatt 1958 年造出它，当时报纸说它将来能走路、说话。可它连「两个条件只能有一个成立」（异或）都学不会，神经网络因此冷了十几年。
- [ ] `4:061` **多层感知机 MLP · 1986**
- [ ] `4:062` - 一句话：在开关之间加几层「中间人」。
- [ ] `4:063` - 效果：解开异或；层数 1 → 3
- [ ] `4:064` - 科普：一层只能画一条直线，多叠几层，就能画出弯曲的边界。中间层先学出小组合，上层再拿组合做判断。1986 年反向传播让它真正练得动。缺点是它把每个位置分开记：图片挪一格，它就当没见过。
- [ ] `4:066` ### 3.2 视觉线
- [ ] `4:068` **卷积神经网络 LeNet · 1998**
- [ ] `4:069` - 一句话：用一个放大镜扫遍整张图。
- [ ] `4:070` - 效果：数字挪了位置也认得
- [ ] `4:071` - 科普：多层感知机把每个像素位置分开学，卷积网络换了个思路：用一个 5×5 的小窗口在整张图上滑动，同一套权重到处复用。这样不管数字写在左上还是右下，都能认出来，参数还少得多。杨立昆（Yann LeCun）用它读银行支票，读了十几年。
- [ ] `4:073` **AlexNet · 2012**
- [ ] `4:074` - 一句话：更深、更宽，两块显卡一起算。
- [ ] `4:075` - 效果：层数 5 → 8；训练 ×1.3
- [ ] `4:076` - 科普：2012 年 ImageNet 比赛，它把识别错误率从 26% 一口气降到 15%。秘诀有三个：ReLU 让深网络练得动，Dropout 防止死记硬背，再加两块 GTX 580 显卡并行。这一年常被看作深度学习时代的起点。
- [ ] `4:078` **VGG · 2014**
- [ ] `4:079` - 一句话：只用最小的窗口，叠得很深。
- [ ] `4:080` - 效果：层数 8 → 16；显存消耗 ×1.3
- [ ] `4:081` - 科普：牛津大学的思路很朴素：全部用 3×3 的小窗口，一层层叠到 16 层。两层 3×3 看到的范围等于一层 5×5，参数却更少、非线性更多。简单好用，但总参数很多，非常吃显存。
- [ ] `4:083` **GoogLeNet · 2014**
- [ ] `4:084` - 一句话：大小窗口并排，让网络自己挑。
- [ ] `4:085` - 效果：层数 16 → 22；参数 ÷10
- [ ] `4:086` - 科普：同一层里并排放 1×1、3×3、5×5 几种窗口（Inception 模块），网络自己决定该用哪种尺度看。比 VGG 更深，参数却少十几倍。名字里的大写 L 是在向 LeNet 致敬。
- [ ] `4:088` **残差网络 ResNet · 2015**
- [ ] `4:089` - 一句话：给每几层开一条近道。
- [ ] `4:090` - 效果：层数 22 → 152；不再越深越差
- [ ] `4:091` - 科普：网络叠到 20 多层后，反而越练越差，因为信号在层层传递中走样。何恺明等人的办法是每隔几层加一条「近道」，让信号可以直接跳过去，中间层只需要学「改动多少」。152 层的网络就此练得动，拿下 2015 年 ImageNet 冠军和 2016 年 CVPR 最佳论文。
- [ ] `4:093` **看图说话 Image Captioning · 2015**
- [ ] `4:094` - 一句话：一边看图，一边说话。
- [ ] `4:095` - 效果：能力「词汇生成」看图版
- [ ] `4:096` - 科普：卷积网络负责看，循环网络负责说，注意力把两者连起来：每说一个词，就回头看图里对应的那一块。「一只狗在草地上跑」，说到「狗」时盯着狗，说到「草地」时盯着地面。
- [ ] `4:098` ### 3.3 序列线
- [ ] `4:100` **循环神经网络 RNN · 1990**
- [ ] `4:101` - 一句话：边读边记。
- [ ] `4:102` - 效果：记得住约 8 个字
- [ ] `4:103` - 科普：读句子时，把上一个字留下的「印象」带到下一个字，一路传下去。问题是印象每传一步就淡一点，十来个字之前的就忘了。误差往回传时还会越乘越大，训练容易崩溃。
- [ ] `4:105` **长短期记忆网络 LSTM · 1997**
- [ ] `4:106` - 一句话：给记忆装上闸门。
- [ ] `4:107` - 效果：记得住 8 字 → 80 字
- [ ] `4:108` - 科普：在记忆上装三道门：输入门决定写什么，遗忘门决定丢什么，输出门决定说什么。重要的信息可以一路保留到句尾。Hochreiter 和 Schmidhuber 1997 年提出，冷门了十几年，到 2016 年已经在语音识别、输入法、翻译里随处可见。
- [ ] `4:110` **门控循环单元 GRU · 2014**
- [ ] `4:111` - 一句话：两道门的轻量版 LSTM。
- [ ] `4:112` - 效果：同等记忆，训练 ×1.05
- [ ] `4:113` - 科普：把 LSTM 的三道门精简成两道，参数更少、算得更快，多数任务上效果差不多。2014 年由 Cho 等人提出。
- [ ] `4:115` **文本卷积 TextCNN · 2014**
- [ ] `4:116` - 一句话：用看图的方法读句子。
- [ ] `4:117` - 效果：训练 ×1.3；只看得到相邻 5 个字
- [ ] `4:118` - 科普：把卷积从图片搬到文字上，小窗口在句子上滑动，一次看两三个词。整句可以同时算，速度很快，判断好评差评特别好用。代价是看不远：窗口外的词它不知道。Yoon Kim 2014 年提出。
- [ ] `4:120` **序列到序列 Seq2Seq · 2014**
- [ ] `4:121` - 一句话：先听完，再复述。
- [ ] `4:122` - 效果：能翻译；整句压进一个「瓶颈」
- [ ] `4:123` - 科普：一个网络读完整句，压成一串数字；另一个网络从这串数字出发，一个词一个词说出译文。Google 2014 年提出，神经网络第一次能做翻译。缺点是整句都挤在同一串数字里，句子一长，细节就丢了。
- [ ] `4:125` **注意力机制 Attention · 2014–2015**
- [ ] `4:126` - 一句话：翻每个词时，回头看原文。
- [ ] `4:127` - 效果：长句不丢细节；翻译准确率大涨
- [ ] `4:128` - 科普：不再只靠那串被压缩的数字，而是在说每个词时，把原文所有词扫一遍，给最相关的几个打高分。就像人做翻译时，眼睛会在原文上来回找。Bahdanau 等人提出。2016 年 9 月谷歌翻译改用这一套，错误率下降六成。
- [ ] `4:130` **Transformer**（不显示年份）
- [ ] `4:131` - 一句话：只用注意力，整句一起算。
- [ ] `4:132` - 效果：显卡利用率 ×3；参数规模上不封顶
- [ ] `4:133` - 科普：拿掉循环，拿掉卷积，只留注意力：每个词直接和句子里所有词比较，看谁跟自己有关。不用再一个字等一个字，整句同时计算，显卡终于能吃满。它本身不知道词的先后，所以要给每个位置编号。后来几乎所有大语言模型都是这种结构。

- [ ] `4:137` ## 四、技巧（训练方法，按领域分组）
- [ ] `4:139` ### 4.1 神经元的基本零件
- [ ] `4:141` | 名称 | 一句话 | 效果 | 科普 |
- [ ] `4:142` |---|---|---|---|
- [ ] `4:143` | 权重 Weight · 1958 | 每个输入有自己的分量。 | 训练 ×1.1 | 「价格」和「好评数」对买不买的影响不一样大。权重就是每个输入说话的音量，训练就是在调这些音量。 |
- [ ] `4:144` | 偏置 Bias · 1958 | 能挪动的判断门槛。 | 准确率 +2% | 有的人一点小事就答应，有的人要很多理由才答应。偏置决定「多少分才算是」。没有它，判断线永远穿过原点。 |
- [ ] `4:145` | 感知机学习规则 · 1958 | 错了就往对的方向挪一点。 | 训练 ×1.15 | 答对不动，答错就把权重朝正确答案推一小步。这是最早的学习算法，简单到可以用电路实现。 |
- [ ] `4:146` | 阶跃函数 Step · 1958 | 一个开关：过线是，不过否。 | 准确率 +1% | 最早的神经元只会输出 0 或 1。问题是开关没有坡度，模型不知道自己「差了多少」，误差传不回前面的层。 |
- [ ] `4:147` | S 形函数 Sigmoid · 1986 | 把开关换成调光旋钮。 | 误差能往回传；准确率 +1% | 输出在 0 到 1 之间平滑变化，就能算出每个权重该往哪边调、调多少。反向传播因此成立。缺点是两头太平，层一多，误差传几层就没了。 |
- [ ] `4:148` | 线性整流 ReLU · 2010 | 负数归零，正数照传。 | 训练 ×1.3；深网络练得动 | 公式简单到只有一行：小于 0 输出 0，大于 0 原样输出。正半边坡度恒为 1，误差往回传不会衰减。AlexNet 靠它一战成名。 |
- [ ] `4:150` ### 4.2 怎么学（优化器）
- [ ] `4:152` | 名称 | 一句话 | 效果 | 科普 |
- [ ] `4:153` |---|---|---|---|
- [ ] `4:154` | 小批量梯度下降 Mini-batch · 1986 | 看一批，再改一次。 | 训练 ×1.2 | 每张卡都改一次，方向忽左忽右；看几十张卡取平均再改，方向更稳。显卡一次能并行算一批，速度也快得多。 |
- [ ] `4:155` | 自动微分 Autodiff | 梯度让电脑自己算。 | 训练 ×1.1 | 反向传播靠的是微积分里的链式法则，以前要手推公式、手写代码。Theano、TensorFlow 这些框架能自动算出每一层的梯度，研究者只管设计网络。 |
- [ ] `4:156` | 动量 Momentum · 1986 | 像推球下坡，带着惯性冲。 | 训练 ×1.3 | 每一步不只看当前的坡度，还带着上一步的速度。遇到小坑能冲过去，平路上越走越快。 |
- [ ] `4:157` | RMSProp · 2012 | 每个参数自己定步子。 | 训练 ×1.6 | 有的参数梯度一直很大，有的很小，用同一个步长不合适。RMSProp 让梯度大的走小步、梯度小的走大步。Hinton 在网课里讲出来的，连论文都没发。 |
- [ ] `4:158` | Adam · 2014 | 动量 + 自适应步长。 | 训练 ×2 | 把动量和 RMSProp 合在一起，几乎不用调参就能用。2016 年最常用的优化器，没有之一。 |
- [ ] `4:159` | 学习率衰减 LR Schedule | 先大步，后小步。 | 准确率上限 +3% | 离答案远时大步走，快到了就小步挪，避免在最低点附近来回跳。就像倒车入库：先大把方向，再一点点修。 |
- [ ] `4:160` | 学习率预热 Warm-up | 起步先慢后快。 | 换模型后不崩 | 模型刚换时权重很乱，一开始就大步走容易翻车。预热让学习率从很小慢慢升上去。训练超大模型时几乎必用。 |
- [ ] `4:162` ### 4.3 防止死记硬背（正则化）
- [ ] `4:164` | 名称 | 一句话 | 效果 | 科普 |
- [ ] `4:165` |---|---|---|---|
- [ ] `4:166` | 早停 Early Stopping | 考试分不涨就停。 | 训练 +5%；不白烧电 | 练久了，模型开始背训练题，考新题反而变差。盯着考试分，几轮不涨就停，留下最好的那一版。 |

- [ ] `4:171` ### 4.4 让深网络稳定
- [ ] `4:173` | 名称 | 一句话 | 效果 | 科普 |
- [ ] `4:174` |---|---|---|---|
