## 候选变更与接口合同

`changes.patch` 包含目标文件、原文件 SHA256 和五行上下文，修改两个文件，需一起整合：

1. XgButtonPressFeedback：每次输入记录当前模式；在 LateUpdate 发现普通按压期间宿主 Reduced 开启后，只让私有文字效果进入收回。该次按压一旦收回，不因开关反复切换而重播或放大。Reduced 关闭后的新输入继续使用原普通模式。
2. XgJuice：新增显式调用的 `SettleKnock(RectTransform rt, float seconds = .06f)`，仅处理这个实例已存在的目标 Punch。从当前缩放/位置开始，以单调平滑插值收回到此前保存的静止变换；时长不超过 .06 动画秒或原剩余时长。重复调用不重新计时，无记录/null 目标不创建效果。下一次 Knock 清除 settling 标记并复用原静止基准。

普通模式原正弦回弹、缩放、位移、业务按钮 Knock、背景颜色、声音、粒子与其他旧特效均保留。新增 API 不自动改变宿主业务效果；通用按钮只在自己的 pressFx 上调用。本任务不扩大到全局动效引擎的 Reduced 政策。

连续性合同：切换登记时位置与缩放不跳变，之后无新振荡地回到静止。这里保证姿态连续（C0），不声称切换时速度连续（C1）。若原动作已有位移/形变，最多 .06 动画秒内消退；不能同时承诺“立刻归零”和“姿态连续”。时钟仍使用原实现的未缩放时间且单帧最多推进 .05 秒，因此卡顿时墙钟耗时可能更长。关闭 Reduced 不增强旧动作；新动作恢复旧普通模式。
