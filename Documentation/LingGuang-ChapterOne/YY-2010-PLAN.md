# YY native 2010 messenger redesign — 2026-10-03

User request: 网上搜索 QQ2010 图片，YY 做成那个年代的样子，红围巾熊猫头像，整个软件必须原生实现。

## Verified visual references (reference only, never packaged as UI)
- Tencent retrospective with QQ2010-era screenshots: https://cloud.tencent.com/developer/article/1088789
- Dated 2010-01-11 QQ2010 beta review with image figures: https://www.qudong.com/article/59734.html
- Designer explanation of the default-blue QQ2010 container design: https://www.woshipm.com/pd/89.html
- Earlier beta comparison/screenshots: https://news.qudong.com/2009/1019/54496.shtml
- One older MyDrivers URL could not be fetched; it is not used as verification evidence. Some original image hosts returned unsupported content types; accessible article captions and image-search previews were used, not downloaded executable clients.
- Reference visual characteristics: narrow/tall buddy panel, cyan/light-blue gradient header with avatar/nickname/signature/status, search, friends/groups/recent tabs, compact grouped contact rows. Chat window is separate: white text history with sender/time lines (not modern large bubbles), toolbar between history/input, close/send at bottom, avatar/profile column on right.
- Retain YY name and use original panda avatar, not Tencent logos or copied QQ artwork. Existing native DreamOS/Aero controls are the implementation substrate.

## Scope / preservation
Only Main scene's YY presentation and task-owned QQ2010 adapters/assets. Original 2010desktop, vendor assets, the other apps, Core/economy/save logic and parallel story code remain unchanged. Existing native MessagingManager + ChatItemPreset + ChatMessagePreset + TMP input and send flow remain authoritative. No screenshot-as-interface, HTML webview, or manually painted bitmap controls.

Avatar ready: Assets/LingGuangV05/Art/Generated/yy-panda-red-scarf.png (1254 square, transparent). Use for the YY header/main avatar and Lao Zhou contact/chat profile. Preserve aspect and native masks. Prompt/provenance in yy-panda-prompt.md.

- Runtime worker: new DesktopBridge/YY2010ShellController.cs and optional YY2010MessageStamp.cs. NO changes to Core/runtime/chat adapter or unrelated UI. Parent owns QA and scene execution.

Search filters native ChatItemPreset objects without recreating rows. Friends default, recent shows actual same session contact, Groups explicitly empty (no fictional chat group). No network.

Existing native chat taskbar remains chat, new native buddy window/taskbar belongs same software. Close/minimize one window must not delete conversation or stop reply/game simulation.

Remove/tone down bubble backgrounds and align both authors left; native content/time texts arranged as sender + timestamp line, then body, dynamic row height via native layouts. Optional YY2010MessageStamp decorates native timeText once after spawn with 我/老周; don't repeatedly prepend.
Toolbar with native emoji/history actions and unavailable voice/video controls visibly disabled with honest explanation if present. History scrolls native conversation to top or toggles a native history view; no fake enabled actions.
