# 灵光一现开发日志：让“教会 AI”变得更直观

2026 年 10 月 11 日 · 版本 **2026.10.11.2**

这次更新围绕两个体验展开：玩家能看见自己教给 AI 的东西，也能在自由聊天之外，感受到养着这台电脑的生活压力。

## 从猜错到学会

开局先让 AI 猜，玩家再确认或纠正。宽界面把它的答案放在题目旁边，右侧显示学习反馈，并告诉玩家下一步该做什么。参数和样本都达标后，需要玩家主动验收才能进入下一章，避免还没看清变化就被推着走。

![开局教学：AI 先猜，玩家纠正](images/01-teaching.png)

训练页保留固定体检题和成绩反馈，希望升级的意义能落实到“它现在会什么”，再回到自由对话里感受变化。这版还补充了 50 道开局逻辑命题、8 道按 2016 年日期开放的梗题；家人的主观态度短信不再按客观对错评分。

![训练反馈、进章条件和费用提示](images/02-training.png)

## 电脑从第一章就要交电费

取消教学期免电费，开局资金为 ¥1,200。每轮训练即时收费，待机用电按日结算；房租仍从第三章开始。新增资金账本，能查余额、未结电费、累计收入支出和最近 300 笔流水。旧存档从现有余额开始记，不补造历史交易。

![资金账本界面，使用测试进度](images/03-funds.png)

*配图中的 ¥40,000 收入由功能测试注入，用于检查不同来源的收入和支出是否正确入账，不代表实际试玩收入或收益平衡。*

## 贴吧可以接话，秘密仍然属于玩家

帖子新增“参与讨论”：可以自由输入，回复会参考帖子内容和最近对话，并保存讨论与未读状态。模型不可用时保留话题相关的预设回复。

同时删除老周那封知情邮件，清理人物和剧情里直接知道程序、训练进度的内容。朋友、群友和客户围绕生活与交付结果交流，让这个应用保持玩家自己的秘密。

![贴吧公开讨论中的实际问答](images/04-discussion.png)

*图中是游戏内虚构帖子和功能测试对话。章节与余额通过测试准备，不代表自然游玩进度。*

## 把操作中的小问题补齐

- 修复桌面壁纸选择没有应用到实际背景的问题。
- 修复从主机进入桌面后，左侧仍露出房间的缝隙；保留显示器边框和原有操作映射。
- 加入六个存档槽、五分钟自动保存和章节首次快照；加载章节时不把快照距今的时间算成离线收益。
- 增加道具科普详情，补齐喵鱼关闭、赌场反馈、小蜘蛛渐隐；游戏内关机可回到主菜单。

## 验证与接下来的打磨

本版 Windows 构建成功，200 项逻辑检查通过；桌面流程检查覆盖教学、训练、真实模型对话、贴吧回复和保存、账本、壁纸切换及关机返回。构建仍有 75 条警告，主要为已有 API 和未使用字段提示。

希望评委在两小时体验内有机会看到突变。带阅读时间的脚本模拟约 36—46 分钟能达到突变，但这只是可达性检查，完整真人试玩的节奏仍需要继续调整。

本地 Windows 分享包包含 Qwen3-4B 的量化模型和推理运行库，已经独立启动并验证回复。**此 GitHub 源码仓库不包含模型权重、运行库或 Windows 游戏包。** 游戏中的学习通过概念板、记忆、阶段和对话上下文体现，这次没有微调 GGUF 模型权重。

后续继续补齐人工题库、旅行图片、邮件与视频内容，以及“手工记账到 AI 协助记账”的完整玩法。这些内容尚未全部实现。
