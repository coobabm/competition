## 范围与接入
- 保留当前 Main / DreamOS / 游戏逻辑及未提交修改。
- 复用 DesktopMedia 缓存与 UI Paint；真实摄影保存在 Media/Photos，以内容 ID 唯一寻址，不再按少数大类轮换图集。
- 38 新闻、33 论坛帖子、9 时代热帖分别寻址；同一内容在搜索结果/正文使用同图属于身份一致，不算复用。
- 9 GPU、3 硬件、8 礼物分别配图；28 数据包直接用现有样本的原生 UI 预览（不生成无关照片）。商品图片应与型号/用途相符，不把后来的型号冒充 2016 产品。
- 联系人使用不同的生活物件/宠物/风景头像；同人物跨窗口保持同一头像。保留灵光 PixelZero。
- 家庭账单/收入用不同图片；结尾视频用本片帧作封面；真实聊天图片用最小接入补齐。
- 保留程序生成的训练样本、棋子、表情、UI 图标；不恢复已退休图库。赌场美术是独立游戏装饰，不改玩法。
