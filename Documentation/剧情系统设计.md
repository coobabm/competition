# 灵光一闪 · 剧情系统

2026-10-03。已实现，接在 `Assets/LingGuangV05/Scenes/Main.unity` 上。本文件是写剧情和扩展系统的说明。

## 1. 设计依据

| 来源 | 借用的做法 |
|---|---|
| Valve《AI-driven Dynamic Dialog》（GDC 2012，Left 4 Dead 的规则库对白） | 用"事实 + 条件"挑台词；条件越多越具体，具体的优先，通用的兜底；台词播完把事实写回记忆 |
| Emily Short / Failbetter 的 storylet、quality-based narrative | 每段内容 = 前置条件 + 内容 + 播放后的效果；剧情只读写数值，可任意拼接 |
| Supergiant《Hades》的对话选择 | 优先级分层：主线节拍压过闲聊；同类闲聊轮换，播过的往后排，不重复 |
| Yarn Spinner 的 saliency | 多条可选时选"最匹配"的那条 |

参考链接：
- https://www.gdcvault.com/play/1015528/AI-driven-Dynamic-Dialog-through
- https://emshort.blog/2016/04/12/beyond-branching-quality-based-and-salience-based-narrative-structures/
- https://mkremins.github.io/publications/Storylets_SketchingAMap.pdf
- https://docs.yarnspinner.dev/write-yarn-scripts/advanced-scripting/storylets-and-saliency-a-primer
- https://www.christi-kerr.com/post/how-the-dialogue-system-in-hades-rewards-failure

## 2. 结构

```
Core/Story/            纯 C#，不依赖 Unity，可搬到别的项目
  StoryJson            小型 JSON 读取器（支持 // 注释、对象、数组）
  StoryLibrary         节拍 + 台词，从多个 JSON 合并；未知字段、重复 id 直接报错
  StoryCondition       "x >= 3" / "x" / "!x"，加载时解析一次
  StoryVars            IStoryVars 接口；StoryContext 叠加剧情记忆（flag./fired./first./plays./ext.）
  StoryEngine          选节拍：无组的全播；同组只播最优一条
  StoryRunner          串行播放、等待、节奏、优先级插队；IStoryOutput 交给表现层
  StoryState           存档里的剧情记忆（GameState.story）
  ChapterOneStoryVars  本游戏的变量表和信号表（剧情能用的名字都登记在这里）

Runtime/Story/StoryDirector    Unity 宿主：读 Resources/LingGuangV05/Story/*.json，转发信号，轮询状态
DesktopBridge/Story/
  StoryBootstrap               场景里有 ChapterOneRuntime 就自动挂上，不改场景文件
  StoryDesktopPresenter        旁白字幕、右上角提示、章节标题卡、涌现演出、老周 YY 消息、快捷键

Resources/LingGuangV05/Story/  剧情内容（ch1_story.json 节拍，ch1_lines.json 台词）
Tests/Editor/StoryTests.cs     19 个测试，含内容检查
Tools/LingGuangStory.Tests/    命令行跑同一组测试
```

## 3. 写一个节拍

```json
{
  "id": "n_first_fix",
  "on": "card.resolved:corrected",
  "when": ["cardsReviewed >= 1"],
  "priority": 20,
  "steps": [
    { "op": "first", "id": "corrected", "key": "first_fix_record" },
    { "op": "narrate", "key": "n_first_fix" },
    { "op": "say", "who": "laozhou", "key": "lz_board", "delay": 6 }
  ]
}
```

| 字段 | 含义 | 默认 |
|---|---|---|
| `on` | 信号名，可以是数组。`名字:参数` 只匹配该参数；`*` 匹配任何信号；`state` 是状态轮询（每 0.25 秒，状态有变化时） | 必填 |
| `when` | 全部成立才播 | 无条件 |
| `once` | 只播一次 | true |
| `priority` | 高的先播、可插队；≥100 无视"忙碌"和旁白间隔 | 0 |
| `group` | 同组只播一条：优先级 → 条件数 → 播放次数少 → 最久没播 → 文件顺序 | 无 |
| `cooldown` / `groupCooldown` | 本节拍 / 本组的冷却秒数（剧情时钟） | 0 |

条件里能用的名字：
- 游戏数值：见 `ChapterOneStoryVars.Names`（`cardsReviewed`、`accuracy`、`canStartExam`、`named`……）。
- 剧情记忆：`flag.X`、`fired.X`（节拍 X 播完）、`first.X`、`plays.X`、`ext.X`、`story.clock`。

步骤：

| op | 作用 | 阻塞 |
|---|---|---|
| `narrate` | 旁白字幕（2026 年的它），打字机效果，空格/回车跳过 | 是 |
| `cutscene` | 演出：`Title`（章节标题卡）、`Emerge`（涌现） | 是 |
| `say` | `who: laozhou` 发进 YY 老周对话；其他人走提示框。`delay` 相对上一条消息 | 否 |
| `notify` | 右上角提示，可带 `app`/`tab`，点击打开 | 否 |
| `open` | 打开应用页签 | 否 |
| `unlock` | 写 `flag.unlock.<id>`，以后做功能解锁 | 否 |
| `wait` | 等 `seconds` | 是 |
| `waitSignal` | 等信号 `ev`，`timeout` 秒后放行（0 = 一直等） | 是 |
| `flag` / `set` | 写剧情 flag / 写游戏变量（目前游戏侧不允许写） | 否 |
| `emit` | 发信号，可接力触发别的节拍 | 否 |
| `first` | 记"第一天的它"，只在没有时写，自动带游戏日 | 否 |
| `unfire` / `log` | 调试用 | 否 |

台词放 `lines`：值可以是字符串，或字符串数组（重复播放时轮换）。占位符：`{name}`、`{callMe}`、`{tic}`、`{date}`（桌面时钟的日期：2016-05-29 01:47 加上已玩秒数，见 `Core/GameCalendar.cs`）、`{day}`。

## 4. 信号

| 来源 | 信号 |
|---|---|
| 宿主 | `boot`（读档/开局）、`state`（状态轮询） |
| 模拟 | `card.resolved:correct/corrected/wrong`、`exam.started/passed/failed`、`gpu.bought/sold`、`case.bought`、`bill.paid`、`power.unpaid`、`breaker.tripped/reset`、`skill.upgraded:semantic/training`、`node.added/removed`、`edge.added/removed`、`job.enabled/disabled`、`day.ended` |
| 运行时 / 桌面 | `name.set`、`app.open:<应用 id>`、`app.installed`（灵光.exe 下载完成）、`chat.sent:laozhou` |
| 剧情内部 | `chapter.up`、`story.next:<参数>` |

新信号先加进 `ChapterOneStoryVars.Signals`，否则内容检查失败。

## 5. 运行规则

- 节拍串行播放；播完最后一步才记为已播，中途退出下次重播。
- 旁白节奏：两段旁白节拍之间至少 40 秒（`StoryDirector.minNarrationGap`）；考试中、演出中旁白等待。
- 剧情记忆存在 `GameState.story`，随原有存档一起保存；旧存档读入时为空，不需要改版本号。
- 测试模式（`useDiskSave = false`，QA 脚本用）剧情不运行，不弹覆盖层。
- 涌现演出不调模型；光敏安全：无闪烁，亮度变化 ≥ 0.3 秒；`PlayerPrefs` 的 `LingGuangV05.ReduceMotion = 1` 时跳过抖动和乱码。
