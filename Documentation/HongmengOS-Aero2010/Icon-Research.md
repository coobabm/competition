# Windows 7 icon source research

User feedback: the first original Aero-style icon set did not resemble Windows 7 closely enough. User selected a publishable icon set rather than Microsoft extracts. The selected implementation uses unmodified KDE Oxygen icons, loaded from separate StreamingAssets files; see README.md and the included licenses/manifest.

## Best visual match: original Windows 7 extracted icons

- Viewer: https://win7icons.visnalize.com/
- Author's explanation: https://visnalize.com/blog/win7-icons-viewer-downloader
- Viewer source: https://github.com/Visnalize/win7-icons

The author describes 1,030+ original Windows 7 icons in PNG and ICO, grouped by Shell32, Control Panel, Internet Explorer, Windows Mail, Windows Live Messenger, Windows Media Player, PowerShell, WordPad and other system collections. The viewer visibly shows the period-correct 3D/perspective, glossy color and document/folder artwork.

Important boundary: an open-source viewer license does not establish a license to redistribute Microsoft's icon artwork with a game. No such distribution license has been confirmed. Use as visual reference until project usage rights are resolved.

- https://www.iconshock.com/iconsets-license/

Original glossy Windows-style design pack rather than extracted Microsoft icons. The advertised free subset and licenses need per-pack verification. No purchase, download, or agreement has been made.

## Selected: KDE Oxygen

https://github.com/KDE/oxygen-icons

Official COPYING and REUSE.toml state LGPL-3.0-or-later with an artwork-library clarification. The selected 13 icons and preferred editable sources are distributed together with license texts and attribution, and remain replaceable rather than being packed into a sprite atlas. This is a late-2000s glossy alternative, not a claim to contain Windows 7 original icons.
