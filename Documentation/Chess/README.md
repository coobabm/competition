# 国际象棋 2D 表现与风扇收尾

## 入口
`ComputerCaseMenu.unity` → 机箱电源 → Main 桌面 → 游戏中心 → 国际象棋。直接启动原 Main 的入口也保留。

## 本次实现
- 原创 RGBA 棋子图集，白/黑双方各六类，共 12 个 sprite；替换原文字圆牌。内置 ImageGen 生成，原图路径、提示词与 alpha 裁切位置在 `ChessPieces.prompt.txt`。Unity 以原生 Sprite.Create 引用同一张纹理，无新依赖。
- 点击或拖放走棋；空格显示合法落点小圆点，吃子目标显示外环。所有目标来自原 ChessGame.LegalMoves；终局和 AI 回合不显示可走点。
- 当前被将军一方的王轻颤，实测最大偏移 1.71 UI 像素；解除将军复位，减少动态效果时不颤动。
- 吃子：棋子轮廓白闪、被吃子击退消散、落点挤压拉伸、飘字、粒子、45ms 局部顿帧、3px 棋盘震动、冲击波、拖动尾迹、选中发光、落子/吃子音效、双方独立的纯视觉连吃计数。
- 获胜：金/绿色彩屑、波纹、胜利飘字、胜利音；落败和和棋反馈较克制。
- 复用 XgJuice 与原有音效池，LocalHitStop=true，不修改全局 Time.timeScale，不震动桌面摄像机。
- 吃过路兵消散位置为被吃兵所在格；升变保留原 UI 的自动升后；王车易位等规则未改。
- 入主游戏以镜头到位且启动完成为准，此后风扇 9.6 秒开始淡出，10 秒到期首帧停止；按真实时间运行，重复触发不延长。

## 输入与生命周期
- 使用原 LCD 转发的源相机坐标；IDropHandler 才能提交棋步，EndDrag/失焦/拖出/切页只取消。
- 棋盘不可见时暂停 AI 展示，清掉拖拽和特效；新局重置连吃与 ghost。取消回调只执行一次，不把旧棋局的 AI/结算带入新局。
- 两个复用 ghost、一份局部白闪材质；不重复建全桌面效果层。素材 Sprite 由自己的 owner 清理。

## 成本与限制
图集 1024×1536、无 mip/压缩、双线性采样。固定 64 格视图，仅选择/落子时重绘；每次重绘 O(64×L)，L 为选中棋子的合法候选数。规则与 AI 搜索复杂度不变；帧内表现规模由两个 ghost 与复用粒子池约束。连吃只影响表现，不增加棋力或玩法奖励。
