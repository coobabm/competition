# hongmengos 98 — 复古 CRT 桌面

## 打开场景

`Assets/DreamOS - Complete OS UI/Scenes/90desktop.unity`

这是当前 hongmengos 桌面的独立副本，不覆盖现代版场景、DreamOS 原始 Desktop 或其共享 UI Manager。

## 外观与操作

- Windows 95/98 方向：灰色立体控件、深蓝标题栏、蓝绿桌面、32×32 原创彩色像素图标。
- 参考用户提供的米白色台式 CRT 外形：中空前框、厚后壳、下方按键、转轴底座；不再采用右侧示波器式大面板。
- 物理玻璃开口保持 4:3；轻微三分之四视角下透视投影并不等于屏幕像素宽高比。
- 低分辨率栅格、柔焦、荧光扩散、玻璃反射及周边光晕。曲率为 0.025，避免过大的桶形扭曲。
- 下方 FOCUS −/+ 调清晰度，BRIGHTNESS −/+ 调亮度；关屏时仍可调整。
- 右下电源按钮：机械声与短促放电声 → 一次白闪 → 画面收束/展开。快速重复点击在转场内忽略。
- 关屏后源相机暂停渲染，桌面输入关闭；再次开屏保留当前桌面窗口状态。
- Inspector 的 `RetroCrtController.flashStrength` 可调白闪强度，0 表示关闭白闪。
- Start 菜单、桌面图标、任务栏以及窗口功能继续使用现有 DreamOS 事件。
- 设置固定在任务栏，其他应用按打开状态显示；保留免密码启动、桌面点击音和清理后的 About。

## 渲染与输入

源 DreamOS Canvas → 专用相机 → 1024×768 RenderTexture → CRT Glass shader → 3D 显示器前面的 WorldSpace Canvas。

源桌面使用现有 UI 层 5，源相机只画该层；主相机仅画 Default 层 0 的模型与可见屏幕，避免 RenderTexture 自采样反馈。没有新增全局 Layer 或修改项目图形设置。

输入从主相机透视射线映射到玻璃平面，再应用和 shader 相同的逆桶形映射；源 GraphicRaycaster 从自动 EventSystem 注册表移除，只接受中继坐标。保留按键、双击、拖动、滚动与输入框选择状态。关屏清理拖动、hover 和源输入焦点。

## 资源与成本边界

- 外壳是程序化生成并保存的真实网格，不是参考照片贴图；不依赖付费模型服务。
- 硬件音效为本地程序合成的原创短音。运行时材质和音频在控制器释放时清理，不修改系统音量。
- shader 使用多次采样换取柔焦和光晕；扫描线按屏幕导数衰减高频对比，避免小视口和关机收束时的混叠。
- 这是可调的 CRT 视觉近似，不是电子枪或光学追迹仿真；单鼠标输入为目标，不支持多点触摸同时拖动。
- 旧的桌面 ZIP 不含此版本；本轮未重新导出队友安装包。
