## 全屏行为

- 机箱开机时屏幕保持黑色，镜头单段推进到铺满游戏画面后，再显示第一章。
- 直接进入主场景也铺满游戏画面，不再露出实体显示器外框、按钮或边角。
- 打开、最小化应用，读取存档以及切换章节后，桌面仍铺满画面。
- 应用窗口继续保留各自适合内容的默认大小，可拖动、最大化和还原。
- 这里的全屏指游戏中的电脑覆盖整个游戏视口，不强制改变 Windows 显示模式。

## 本轮已实现的壁纸基础

首次见面完成后，默认壁纸淡出，中心、输入、输出和金色问号依次亮起；序列结束后出现一次 Windows 风格的“桌面背景已更改”提示。壁纸保留在图标与窗口下方，应用背景能够透出光点。窗口全部最小化后，光点平滑提亮，悬停可查看说明。后续的完整概念图、托盘置顶以及四份策划其余内容仍按清单继续。
