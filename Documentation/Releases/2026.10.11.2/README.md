完整 Windows 64 位试玩包，内置 Qwen3-4B-Q4_K_M 与本地推理运行库；自由对话不需要填写 API 密钥。游戏版本为 2026.10.11.2，发布于 2026-10-12。

## 下载和启动

GitHub 每个附件有 2 GB 限制，完整游戏 ZIP 分成了两份。请在发布页的 **Assets** 中下载下面三个文件，放在同一个文件夹：

1. `LingGuang-2026.10.11.2-Windows-Qwen.zip.001`
2. `LingGuang-2026.10.11.2-Windows-Qwen.zip.002`
3. `Assemble-LingGuang.cmd`

双击 **Assemble-LingGuang.cmd**。工具会检查两个分卷是否完整，然后合并成普通 ZIP，并再次校验完整文件。看到绿色 `SUCCESS` 后，使用 Windows 的“全部解压缩”，打开解压后的 `ClaudeHandoff-Windows` 文件夹，双击 **LingGuang.exe**。

工具使用 Windows 自带 PowerShell，不需要安装其他解压软件。它只在所在文件夹读取分卷、生成 ZIP，不修改系统设置，不需要管理员权限。缺少分卷或校验失败时会停止，并保留下载文件。

请预留约 **10 GB** 空间用于分卷、合并后的 ZIP 和解压后的游戏。首次启动需等待本地模型加载，回复速度取决于电脑性能。

**不要下载页面底部的 Source code 来代替游戏包，也不要单独运行或发送 exe。** 游戏必须保留 `LingGuang_Data`、模型及其余依赖。分享给朋友时可以发送完整解压文件夹，或者以上三个下载文件。
