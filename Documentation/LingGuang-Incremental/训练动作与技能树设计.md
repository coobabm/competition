# 灵光.exe 第二版：一键训练 → 评估 → 技能树

日期：2026-10-03。基于现有 `Assets/LingGuangV05/XingGuang/`（规则在 `Core/`，界面在 `Desktop/`）。2026-10-03 已按本文实现；与本文不同的地方见 `Assets/LingGuangV05/XingGuang/README.md` 的「已知未完成」。

## 1. 改什么

| 现在 | 第二版 |
|---|---|
| 训练是开关：打开后按秒连续跑 | 训练是**一个动作**：按一下「训练」跑一轮（epoch）。开局全靠手按，后期一级一级自动化 |
| 存检查点时顺带发论文 | 每轮训练完有一次**评估**：数字跳上去、打分、发奖金、给技能点 |
| 架构 / 研究用引用★在列表里解锁；层数、宽度、学习率是旋钮 | 架构、层数、学习率、数据集、研究全部变成**技能树节点**，用训练赚来的 ¥ 解锁 |
| 标注台的手感只有一行反馈文字 | 每个动作都带手感：闪白、击退、飘字、粒子、顿帧、震屏、冲击波、拖拽、发光、音效、连击分数 |

标注台、订单、显卡 / 电费共享、存档方式不变。标注台的新题库另见 [标注题库设计.md](标注题库设计.md)。

## 2. 核心循环

```
标注（是 / 否）──> 样本 ──> 【训练】一轮 ──> 【评估】打分 ──> ¥ + 技能点
     ^                                                      │
     └──────────── 技能树：更深、更快、更多数据、自动化 <────────┘
```

每一环都是一次点击、一次反馈，节奏大约 2–4 秒一拍。

### 2.1 训练（一个动作）

- 训练页中央只有一个大按钮「训练一轮」。按一下：
  - 模型前进 `Tau / 16` 步（`Tau` 是现有的收敛步数常量，MNIST + LeNet 大约 300 步，所以 16 下左右跑到收敛）。
  - 显卡按训练负载耗电 1 秒（`host.Train(1)`），和现在一样记进电费单。
  - 连击：1.5 秒内再按，连击 +1，每级 +5% 步数，最多 ×2（沿用 `ManualStep` 的规则）。
  - 一轮内 loss 曲线只画这一段，训练准确率只前进不评估。
- 按住不放也只算一下。自动重复要靠技能（见 2.4）。
- 一轮过程 0.6 秒：进度条从左到右冲满，到头时放一个冲击波，然后才允许下一下。这 0.6 秒就是节奏，也防止狂点。
- 发散（NaN）仍按现有 `Hazard` 判定，只在轮结束时掷一次。

### 2.2 评估（训练完的结算）

每 4 轮自动触发一次评估（技能「每轮评估」可以改成每轮），或者玩家随时按「评估」。

1. 遮罩弹出评估卡，验证集准确率从 0 滚到真实值（0.8 秒，`Evaluate(run)` 的结果），最后一位停住时顿帧。
2. 给**模型分**（0–1000）：`1000 × (chanceError − 当前误差) / (chanceError − floorError)`。50% 瞎猜是 0 分，到数据集极限是 1000。
3. 评级：D < 300，C ≥ 300，B ≥ 600，A ≥ 800，S ≥ 950。评级印章砸进卡片。
4. 奖励：
   - **奖金 ¥** = （模型分 − 该数据集历史最高分）× `citationBase` × 0.1。只有刷新纪录才给。MNIST 从 0 到 900 分一共 ¥90；CIFAR（base 6）0 到 700 分一共 ¥420；ImageNet（base 40）0 到 800 分一共 ¥3200。
   - **评级首达奖**：C ¥20、B ¥60、A ¥200、S ¥800，乘 `citationBase`。
   - **论文**：刷新纪录时顺带存检查点，跨过 `papers[]` 门槛照旧发论文、给引用。引用不再是解锁货币，只做技能树里的「门槛」。
5. 没刷新纪录：卡片灰一点，飘「没有进步 +¥0」，不震屏。连续 3 次没进步，灵光（或老周）提示「该换学习率 / 该加层 / 该标数据了」。

评估是本作的"打 Boss"时刻，所有最重的手感都在这里。

### 2.3 技能树

三棵树，一个页面，左右拖拽平移、滚轮缩放。节点用 ¥ 购买，部分节点另需论文门槛。

**视觉树**（根：LeNet-5，开局已有）

```
LeNet-5
├─ 层数 2→3→4→5           ¥80 / 100 / 120 / 150        （现有 LayerCost 公式）
├─ 宽度 16→32→64            ¥150 / 450                    （现有 WidthCost 公式）
├─ 学习率旋钮               ¥60     解锁 0.1 / 0.03 / 0.01 / 0.003 / 0.001 的选择。未解锁固定 0.01
├─ MNIST 完整包             ¥300    6 万张（现有 BuyDataset）
└─ AlexNet                  ¥500 + MNIST 1 篇论文
   ├─ 层数 6→8              ¥180 / 220
   ├─ 宽度 128→256          ¥1350 / 4050
   ├─ CIFAR-10              ¥600
   └─ VGG-16                ¥2000 + 3 篇论文
      ├─ 层数 到 16         每层按公式
      ├─ GoogLeNet          ¥6000 + 6 篇论文（分支：参数少，省显存）
      └─ ResNet             ¥15000 + 10 篇论文（分支：层数无上限）
         └─ ImageNet        ¥4000
```

**序列树**（根：朴素 RNN）

```
朴素 RNN
├─ 层数 1→2                 ¥120
├─ 宽度 16→32→64
├─ 学习率旋钮               ¥60
├─ 全唐诗 完整包            ¥300
├─ 逻辑题 完整包            ¥500
└─ LSTM                     ¥500 + 1 篇论文（唐诗或逻辑题任一）
   ├─ 层数 到 3
   ├─ 人民日报语料          ¥800
   ├─ GRU                   ¥1500 + 3 篇论文（分支：快 5%）
   └─ Seq2Seq               ¥4000 + 5 篇论文
      ├─ 中英平行语料       ¥5000
      └─ 注意力             ¥12000 + 10 篇论文
```

**研究树**（两条线共用）

```
动量 SGD ¥200 ─> RMSProp ¥1200 ─> Adam ¥5000
Dropout ¥400 ─> 数据增强 ¥900
梯度裁剪 ¥150 ─> BatchNorm ¥3000
早停与自动存档 ¥600 ─> 学习率衰减 ¥1500
cuDNN 加速 ¥8000      迁移学习 ¥12000
自动化：训练脚本 ¥250 ─> 定时任务 ¥900 ─> 后台守护 ¥3000 ─> 自动评估 ¥5000 ─> AutoML ¥20000
```

节点效果沿用 `XgCatalog.Research` 现有数值。价格按早期 ¥ 收入定：开局标注每秒约 ¥0.5–0.8，第一次评估（MNIST 到 B）大约在第 3–4 分钟拿到 ¥60 + ¥20，正好够「层数 +1」或「学习率旋钮」。后面每一层解锁的价格大约等于上一层解锁后 2–3 分钟的收入。要用 `Tools/XingGuang/bot` 重跑。

节点数据结构（加进 `XgCatalog`）：

```csharp
public sealed class XgNode
{
    public string id, tree, parent;       // "vision.depth.3", "vision", "vision.depth.2"
    public XgNodeKind kind;               // Arch, Depth, Width, LrKnob, Dataset, Research, Auto
    public string target;                 // 架构 / 数据集 / 研究 id，或层数、宽度的数值
    public double cost;                   // ¥
    public int needPapers;                // 该树已发论文数门槛
    public float x, y;                    // 树上的坐标
}
```

已解锁的节点 id 存进现有 `XgState.unlocked`，存档格式不用升级版本号。

### 2.4 自动化（一步步）

| 级 | 节点 | 效果 |
|---|---|---|
| 0 | — | 全靠按 |
| 1 | 训练脚本 `run.sh` | 按住按钮自动连按，每 0.6 秒一下，连击不断 |
| 2 | 定时任务 `crontab` | 灵光窗口开着时，每 3 秒自动训练一下 |
| 3 | 后台守护进程 | 窗口关了也训练，离线按真实时间补（现有 `Tick` 的 86400 秒上限） |
| 4 | 自动评估 + 早停 | 每轮自动评估，刷新纪录自动存检查点（吸收现有「早停与自动存档」） |
| 5 | AutoML 流水线 | 自动调学习率、自动换到样本最多的数据集、自动发论文；玩家只管技能树 |

每升一级，训练按钮上的手改成相应的图标（手 → 脚本 → 时钟 → 守护进程 → 流水线），按钮本身还能按，手按永远比自动快 1 倍，留一个"想快就自己来"的理由。

自动化同时也作用于标注台：现有的自动答题（`autoVision` 等）不变。

## 3. 手感设计

所有效果做成一个 `XgJuice` 组件，纯 UI（Canvas 内），不用 ParticleSystem，避免和 DreamOS 的层级打架。每个效果一个函数，按事件组合。

### 3.1 效果库

| 效果 | 实现 | 参数 |
|---|---|---|
| 闪白 | 全窗白色 Image，alpha 从 0.8 衰减到 0 | 90 ms。失败时改成红色 0.5 |
| 击退 | 目标 RectTransform 往反方向弹 8–24 px，再弹簧回来 | 按钮按下用 scale 0.92 → 1.06 → 1 |
| 飘字 | 对象池 TMP，从起点上浮 60 px、放大 1 → 1.3、淡出 | 700 ms；暴击字体加粗、颜色金 |
| 粒子 | 对象池 Image（圆点 / 方块 / ¥ 符号），随机方向、重力、旋转 | 每次 8–40 个，寿命 0.4–0.9 s |
| 顿帧 | `Time.timeScale = 0` 若干毫秒，用 unscaled 协程恢复 | 60 / 120 / 200 ms。灵光的 Tick 用 unscaled dt 累积，不受影响 |
| 震屏 | 整个灵光窗口 RectTransform 随机偏移，衰减 | 幅度 3 / 6 / 12 px，时长 150–400 ms |
| 冲击波 | 空心圆 Image 从 0 放大到 400 px，线宽变细，淡出 | 350 ms |
| 发光 | 节点 / 按钮外圈 Image，alpha 用正弦呼吸；可购买时呼吸，鼠标悬停时常亮 | 周期 1.2 s |
| 拖拽 | 技能树平移；数据包拖到显卡上安装；检查点卡拖到订单上签约 | 松手时击退 + 冲击波 |
| 音效 | 先程序合成（`AudioClip.Create`：方波 / 噪声 / 扫频），每个事件 3 个变体随机，音高随连击上升 | 后期换素材 |
| 连击分数 | 见 3.3 | |

| 评级 S | 另加：顿帧 200 ms；震屏 12 px；两圈冲击波；全屏金色粒子；老周立刻在 YY 发消息 |
| 连击过档 | 闪白；震屏 6 px；飘出档位名；连击数字放大弹回；音高升一级 |
| 连击清零 | 数字碎成粒子落下；低沉短音 |
| 没进步 | 卡片灰；飘字「+¥0」；低沉短音；不震屏 |
| NaN 发散 | 闪红；震屏 12 px；顿帧 200 ms；曲线乱码闪烁 300 ms；电流杂音；loss 文字乱跳 |
| 技能节点可买 | 节点发光呼吸；连到父节点的线亮起 |
| 解锁节点 | 按住 0.6 秒充能（圆环填充 + 发光变强），松手即取消；完成时节点冲击波，¥ 粒子从钱包飞到节点，子节点线依次点亮，「咔嗒」+ 上扬音 |
| 买数据包 | 拖拽数据包图标到显卡上；落下时击退 + 20 个粒子 + 硬盘读写声 |
| 签订单 | 拖检查点卡到订单上；印章砸入 + 震屏 3 px |
| 自动化升级 | 按钮上的手变成新图标，闪白一次；之后每次自动训练只有轻微击退和一声短音，不震屏（避免疲劳） |

疲劳控制：同类效果 0.3 秒内不重复震屏；自动化触发的事件全部降一档；设置里有「减少特效」开关（顿帧和震屏关掉，其它保留）。

### 3.3 连击分数

连击是贯穿标注和训练的一个数字，显示在窗口右上角，是手感的主线。

- **怎么涨**：标注答对 +1；训练一轮 +1；评估刷新纪录 +5。两次动作间隔不超过 1.5 秒才算连续（训练一轮是 0.6 秒，正好接得上）。
- **怎么断**：标注答错、间隔超时、NaN 发散都清零。清零时数字碎成粒子落下。
- **加成**：标注奖金 × (1 + 连击 × 0.05)，最多 ×2（现有 `labelCombo` 和 `combo` 两个计数合并成一个）；训练步数同样加成。评估奖金不吃连击，避免滚雪球。
- **档位**：10 连「不错」、25 连「手热了」、50 连「上头」、100 连「灵光一闪」。每过一档：闪白、震屏 6 px、飘出档位名、数字放大一下、音高升一级，连击数字边框常亮。100 连以上数字变金色，粒子一直冒。
- **最高连击**存进 `XgState.bestCombo`，训练页右上角显示「最高 ×137」，灵光和老周都会拿它说事。
- 自动化来的动作（定时任务、自动答题）不算连击，连击只属于手。这样自动化之后还有理由自己上手。

## 4. 界面

灵光窗口的页签改成：标注台 · 训练 · 技能树 · 订单。右上角常驻连击数字。

**训练页**（代替现在的视觉 / 序列两页）
- 顶部：线路切换（视觉 / 序列），显示当前架构、层数、宽度、学习率、数据集，每一项点一下跳到技能树对应节点。
- 中间：大按钮「训练一轮」，按钮下面是 16 格的轮进度和 loss 曲线。
- 右侧：最近一次评估卡（分数、评级、历史最高），「评估」按钮。
- 底部：显卡状态、耗电、灵光的一句评论。

**技能树页**
- 一张可拖拽的画布，三棵树并排。节点是圆形，已解锁亮、可买呼吸、锁住灰。
- 点节点看说明和价格，按住解锁。
- 右上角显示 ¥ 和论文数。

**评估卡**：遮罩居中，可以点任意处关掉，自动化到 4 级后改成右下角小卡滑入、3 秒自动消失。
