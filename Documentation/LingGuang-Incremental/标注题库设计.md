# 灵光.exe 标注题库扩展：2016 年的互联网

日期：2026-10-03。补充 [训练动作与技能树设计.md](训练动作与技能树设计.md) 的标注台部分。2026-10-03 已按本文实现；与本文不同的地方见 `Assets/LingGuangV05/XingGuang/README.md` 的「已知未完成」。

现在标注台只有三张桌：手写数字、唐诗下一字、逻辑题。都是"课本题"，和 2016 年 5 月底这个设定没关系。这里加 8 张桌，全部是那年真实存在的"数据标注活"，题面用那年的热梗、剧、事件。每张桌仍只答「是 / 否」，仍然是先定答案再出题，答案在构造上一定正确。

## 2. 新增的桌

每张桌对应一个数据集，挂在视觉线或序列线上，可以训练、发论文、接订单，和现有的逻辑题一样。

### 2.1 弹幕情绪（序列线）「这条弹幕是在夸吗？」

2016 年 B 站、直播间的真实活：弹幕情感分类。

- 生成：先掷"夸 / 骂 / 中性"，再从对应模板拼句。夸：「前方高能」「给跪了」「666」「up 主辛苦了」「这波操作可以」「23333」「厉害了」；骂：「辣眼睛」「这届 up 不行」「我选择狗带」「告辞」「？？？」「退钱」；中性：「来了来了」「空降 3:20」「打卡」「第一」。
- 加料：
  - 反讽题（难度 3+）：「真棒，一集水了四十分钟」。模板里标明反讽，答案是"否"。
  - 群友题：网吧群的阿杰 / 小刚的口吻，他们在 YY 群里也会说同样的话，玩家会认出来。
- 订单：「某弹幕网站」评论审核，¥/秒。
- 论文门槛：.7 / .8 / .88 / .93 / .96。

### 2.2 垃圾信息（序列线）「这条是垃圾短信吗？」

把老版灵光的"垃圾邮件订单"搬回来当一张桌。

- 垃圾：「恭喜您被《我是歌手》栏目组抽中幸运观众，奖金 98000 元」「老板，发票需要吗」「微商代购 一手货源」「澳门首家线上赌场上线啦」「您的 ETC 已停用」（这条是后来的梗，不用）。
- 正常：「您的快递已到小区门口菜鸟驿站」「周三下午组会改到 4 点」「妈：吃饭没」「移动：本月流量已用 80%」。
- 加料：
  - 老周题：每标 30 条，老周在 YY 发一条「帮我看看这个是不是骗子」，在 YY 里答，也算标注，答对老周说一句谢。
  - 迷惑题：正经的推广短信（「中国移动：充 100 送 20」）算正常，题面会标注"商业推广不算垃圾"。
- 订单：「市反诈中心」，「某邮箱」。

### 2.3 标题党（序列线）「这是标题党吗？」

2016 年公众号、UC 头条的标题文化。

- 生成：先掷是 / 否，再拼。标题党模板：「震惊！…」「99% 的人都不知道…」「…看完我哭了」「刚刚，…出大事了」「这个…火了，原因竟是…」。正常标题：「市气象台：明日最高气温 33℃」「AlphaGo 4:1 战胜李世石」「霍金开通微博 粉丝一天破两百万」「科比退役战砍 60 分」。
- 加料：
  - 真事假标题：「震惊！一个围棋程序打败了世界冠军」。内容是真的，标题还是标题党，答案"是"。题面规则写清楚：只看标题风格，不看真假。
  - 玩家熟悉的也来：「震惊！县城网吧老板用旧显卡训练出人工智能」。
- 订单：「某浏览器资讯频道」。

### 2.4 刷单评论（序列线）「这条评论是刷的吗？」

淘宝 2016 年的真实问题，也是老周"网吧兼卖电脑配件"这条线的梗。

- 刷单：「好评好评好评 老板人很好 下次还来」「宝贝收到了 很好 五星」「质量不错 物流很快 包装很好 很满意」（三连短句、没有具体内容、重复词）。
- 真实：「显卡风扇有点响，玩 LOL 够用了，就是电费涨了」「比网吧的那台快多了，但是驱动装了半天」。
- 加料：真实评论用老周、阿杰、表姐的口吻，内容对应游戏里的东西（显卡、电费、灵光）。
- 订单：「淘宝卖家联盟」改接这个数据集。

### 2.5 中式英语（序列线）「这句英文说得对吗？」

给 Seq2Seq / 翻译数据集一个手标入口。

- 错：「no zuo no die」「you can you up, no can no BB」「good good study, day day up」「people mountain people sea」「give you some color to see see」「long time no see」（陷阱：这句英语里已经通用，答案"对"，题面给理由）。
- 对：「It's raining cats and dogs」「Long time no see」「How much is this graphics card?」。
- 加料：中英对照题（难度 3+）：「"老司机" 翻译成 "old driver" 对吗？」答案"否"，理由"意思是老手，不是老年驾驶员"。
- 这张桌的样本喂 `translate` 数据集。

### 2.6 验证码（视觉线）「图里的是雨伞吗？」

2016 年春运 12306 验证码的梗："请点击所有的 ××"。

- 画法：用现有 `XgIconGraphic` 画 12 种简笔图标（雨伞、电风扇、锅、公交车、茶杯、鞋、蜜蜂、热水瓶、算盘、灯笼、钥匙、风筝），加随机旋转、噪点、干扰线，难度越高越糊。
- 问：「这是 ×× 吗？」有 50% 问的是别的东西。
- 加料：
  - 难度 4：两张并排，「两张都是雨伞吗？」
  - 彩蛋：偶尔出「请点击所有的 老司机」，图里是一个方向盘。答案看图。
- 喂 `cifar` 数据集（当作小图分类的手标入口）。
- 订单：「铁路售票系统」。

### 2.7 表情包情绪（视觉线）「这个表情是在生气吗？」

- 画法：`XgIconGraphic` 画一张圆脸，眉、眼、嘴各 4 种形状组合出喜、怒、哀、懵、滑稽（暴走漫画那种），底下一行配文。
- 问脸不问字：「这张脸是在笑吗？」字和脸有 30% 的概率对不上（配文「我太难了」配一张笑脸），这是陷阱。
- 加料：
  - 斗图模式（难度 3+）：连续 5 张，每张 2.5 秒倒计时，全对多给 ¥3，题面「阿杰向你发起斗图」。
  - 模型给建议时，灵光的脸也用这套画，随把握大小换表情。
- 喂 `mnist` 之外的新数据集「表情包」，论文门槛低，引用少，是开局第二张视觉桌。

### 2.8 围棋气数（视觉线）「这块黑棋还有气吗？」

AlphaGo 两个月前刚赢，老周迷上 AI 就是因为这个。

- 画法：9×9 小棋盘，随机放 4–10 颗子，标出一块黑棋。
- 问：「这块黑棋有气吗？」（难度 1）、「白棋下在 ✕ 能提掉这块黑棋吗？」（难度 3）、「这块棋是活棋吗」不做（太难判定）。
- 生成：先随机摆，用连通分量数气，再决定问哪块、问什么。
- 加料：标到 100 题，老周发消息「你这是要自己做个 AlphaGo？」。
- 单独数据集「围棋局面」，订单「县围棋协会」（判定死活教学）。

## 4. 数据结构

现有 `XgCard` 够用：`question / why / category / level` 已有，图形桌多用 `digit / seed`。加一个 `string[] tags`（哪个梗、出现日期）给"出处"行和日期过滤用。

生成器加到 `Core/` 里，一张桌一个文件：`XgDanmu.cs`、`XgSpam.cs`、`XgHeadline.cs`、`XgReview.cs`、`XgChinglish.cs`、`XgCaptcha.cs`、`XgMeme.cs`、`XgGo.cs`。模板表放 `Resources/LingGuangV05/Cards/*.json`，一条模板一行：

```json
{ "text": "前方高能", "label": "praise", "since": "2015-01-01", "source": "B 站弹幕用语", "irony": false }
```

`XgCatalog.Desks` 从 3 张改成读所有有模板的桌。标注台页签改成横向滚动的桌子列表，新桌按进度解锁：

| 解锁条件 | 桌 |
|---|---|
| 开局 | 手写数字、唐诗、逻辑题 |
| 第一次训练 | 弹幕情绪、垃圾信息 |
| 第一篇论文 | 表情包、标题党 |
| LSTM | 刷单评论、验证码 |
| Seq2Seq | 中式英语 |
| 标注总数 500 | 围棋气数 |

## 5. 测试

- 每个生成器：1000 题是 / 否各占 45%–55%；每题的 `truth` 用独立方法复核（围棋用另一套数气；验证码用 asked == drawn）。
- 日期过滤：把游戏日期设到 2016-05-29，断言没有一条 `since` 晚于这天的模板出现。
- 反讽 / 陷阱题答案和模板标注一致。
