# 灵光.exe：人机协作标注（简单题交给它，拿不准的才问你）

日期：2026-10-03。在 [训练动作与技能树设计.md](训练动作与技能树设计.md)、[标注题库设计.md](标注题库设计.md) 之上。本文是设计，未实现。

## 1. 一句话

灵光先看每张题卡，给出「是 / 否」和**把握**。把握够高的，它自己标；不够的，进「拿不准」队列交给玩家。玩家能调**把握阈值**：调低，它包办得多但会标错（噪声标签）；调高，标得准但玩家要多干活。文字题由本机的 Qwen3.5-4B 真的去判断，图片题用灵光自己训练出来的检查点。

这就是真实标注行业的「预标注 + 人工复核」和机器学习里的「不确定性采样」（主动学习）。

## 2. 本机实测（2026-10-03，M2 Max，打包进游戏的 llama-server + Qwen3.5-4B Q4_K_M）

用游戏自己的生成器出了 150 张文字题（逻辑 / 弹幕 / 短信 / 标题党 / 刷单 / 中式英语各 25 张，答案已知），让模型只输出 1 个 token，读 `top_logprobs` 里「是」「否」的概率，把握 = max(p, 1 − p)。

| 桌 | 准确率 | 把握 ≥ 0.9 的比例 | 其中准确率 | 每题耗时 |
|---|---|---|---|---|
| 逻辑题 | 76% | 44% | 91% | 0.19 s |
| 弹幕情绪 | 88% | 36% | 89% | 0.12 s |
| 垃圾短信 | 96% | 60% | 93% | 0.14 s |
| 标题党 | 68% | 40% | 100% | 0.12 s |
| 刷单评论 | 84% | 0% | — | 0.13 s |
| 中式英语 | 68% | 56% | 100% | 0.12 s |
| **合计** | **80%** | | | |

| 把握阈值 | 自动标的比例 | 自动标的准确率 |
|---|---|---|
| 0.6 | 88% | 82% |
| 0.7 | 66% | 87% |
| 0.8 | 49% | 95% |
| 0.9 | 39% | 95% |
| 0.95 | 28% | 98% |

结论：
- 速度够：每题 0.1–0.2 秒，后台预判下几张，玩家感觉不到等待。
- 把握是真的有用：阈值越高越准、包办得越少。这个取舍就是玩法本身，不用编造。
- 不同桌性格不同：刷单评论它总是「拿不准」（全部交给玩家），短信它很有把握。老司机题（反讽、陷阱）它答对 83%。
- 只有文字题能用：模型是纯文本 GGUF，没有视觉投影（mmproj）。数字、验证码、表情包、围棋仍由灵光自己的检查点判断。

## 3. 技能树：最左边新增「标注」树

技能树从左到右变成：**标注 · 视觉 CNN · 序列 RNN · 研究与自动化**。打开技能树默认看最左边。

```
              加薪（多级 0/17，×1 → ×10）
                   │
            自动答题（多级 0/10）
                   │
         拿不准才问我（协作模式）
          ┌────────┼─────────┐
   灵光的大脑（本地模型）  难例加价   抽检
          │
     多开推理（并发 ×4）
```

| 节点 | 价格 | 前置 | 效果 |
|---|---|---|---|
| 加薪 | ¥10 起，每级 ×1.7 | — | 现有的 17 级加薪搬进来：手标报酬 ×1 → ×10。节点外圈按级数分段点亮，按住买下一级。标注台右栏的商店行保留，两处买的是同一个东西 |
| 自动答题 | ¥60 起，每级 ×1.7 | 任一检查点 ≥ 60% | 改成**全局**等级（现在是每张桌各自 10 级）：每级每秒多看 0.3 张，对所有有检查点的桌生效。旧存档取各桌最高等级 |
| 拿不准才问我 | ¥300 | 自动答题 Lv 1 | 开启协作模式和把握阈值滑块（见第 4 节）。没买之前，自动答题像现在一样「全包」，答错就作废 |
| 灵光的大脑 | ¥1200 + 序列线论文 1 篇 | 拿不准才问我 | 文字桌改由本地模型真判断。本地模型没启动时节点显示「大脑离线」，自动退回检查点 |
| 难例加价 | ¥800 | 拿不准才问我 | 玩家手答「拿不准」队列里的题：报酬 ×1.5，样本按 2 条算（难例更有信息量） |
| 抽检 | ¥1500 | 拿不准才问我 | 自动标错的题有 40% 被抽出来，退回「拿不准」队列，不进训练集 |
| 多开推理 | ¥3000 | 灵光的大脑 | 服务端并发 1 → 4，大脑每秒能判断的题数 ×3；同时 YY 聊天不再排队 |

## 4. 协作模式怎么玩

### 4.1 流程

```
生成题卡 ──> 灵光判断（答案 + 把握）
                 │
     把握 ≥ 阈值 ─┼─> 自动标注 ──> 对：¥（自动单价）+ 1 条样本
                 │                 错：噪声标签（抽检可能拦下）
     把握 < 阈值 ─┴─> 「拿不准」队列 ──> 玩家答 ──> 对：¥ × 加薪 × 连击 × 难例加价，样本 ×2
                                               错：照旧作废、断连击
```

- 出题速度 = 自动答题等级 × 0.3 张/秒（每张开启的桌）。
- 「拿不准」队列最多 20 张。满了以后新题等待，自动那边也停下来，等玩家清队列。逼玩家处理难题，又不会无限堆积。
- 队列空了：玩家可以直接答普通题（就是现在的玩法），也可以去训练。

### 4.2 把握阈值

标注台右栏新增一行「把握阈值」滑块，范围 50%–99%，默认 80%。旁边实时显示最近 100 题的：

- 自动比例（它包办了多少）
- 自动准确率（它标对了多少；游戏知道真答案，所以能实时算）
- 噪声标签数

玩家能直接看到第 2 节那张表在自己手上发生。

### 4.3 噪声标签

自动标错的题不是简单作废，而是**污染数据**：每条噪声标签抵消 2 条好样本（数据量项变差），评估分数会掉。阈值调太低，钱来得快、模型反而训不上去。这让阈值成为真正的取舍，不是「越低越好」。

技能树「抽检」和训练页可以清理噪声（抽检拦下 40%；以后也可以加「重新标注」按钮，花玩家时间把噪声翻成好样本）。

### 4.4 图片题的「把握」

图片桌（数字、验证码、表情包、围棋）没有真模型，用检查点模拟：

- 答对时把握 ≈ 检查点准确率 + 随机波动，偏高。
- 答错时把握偏低（0.5–0.75 之间）。
- 难度越高的题，把握整体下降。

所以阈值对图片桌同样有「越高越准」的效果，但数字是游戏规则算出来的，界面上写明「检查点估计」，文字桌写「本地模型」。

## 5. 本地模型调用

| 项 | 做法 |
|---|---|
| 请求 | 系统提示「你是一个数据标注员。只回答一个字：是 或 否。」，用户消息 = 桌的问题 + 题面；`max_tokens = 1`，`temperature = 0`，`logprobs = true`，`top_logprobs = 10`，关闭思考 |
| 把握 | p(是) / (p(是) + p(否))，取 top_logprobs 里以「是」「否」开头的 token |
| 不作弊 | 真答案从不发给模型，只在本地用来计分和统计准确率 |
| 预判 | 后台保持每张开启的桌都有 3 张已判断好的题；判断结果存进题卡（`card.brainP`），读档后不用重判 |
| 并发 | 现在服务端是 `-np 1`。判断请求走单独的低优先级队列，聊天插队优先；买「多开推理」后改 `-np 4` |
| 电费 | 每次判断记 0.05 GPU·秒的电，和训练同一张电费单（设定上是灵光在你的显卡上思考） |
| 失败 | 服务没起、超时、解析不出概率：这张题退回检查点模拟，并在界面上标「大脑离线」 |
| 统计 | 每桌记最近 50 次大脑判断的对错，显示「大脑在弹幕上：近 50 题 88%」 |
| 灵光说话 | 第一篇论文后灵光能说话。题进「拿不准」队列时，旁边显示它的一句话（现有 `CardComment`），例如「这个……我不确定是不是反话。你来。」 |

## 6. 界面

**标注台（协作模式开启后）**

- 题卡上方一条「自动通过」流水：最近 6 张它自动标的题从右往左滑过，对的打绿勾；抽检拦下的变黄，飘回队列。
- 题卡上显示灵光的猜测和把握条：「灵光：是？ 62%（本地模型）」。玩家推翻它的判断并答对时，飘字「纠错！」，连击 +2。
- 桌子页签上显示队列数：「弹幕 3」。
- 右栏商店多一行「把握阈值」滑块和三项实时统计。

**技能树**

- 标注树在最左边，打开技能树时默认镜头对准它。
- 多级节点（加薪、自动答题）外圈分段显示等级，中间写「Lv 5/17」，按住买下一级。

## 8. 要你决定的

1. 噪声标签的惩罚（1 条抵 2 条好样本）会不会太狠？也可以只是「不算样本」。
2. 「拿不准」队列满了要不要让自动那边也停？停：逼玩家干活；不停：更挂机。
3. 自动答题从「每桌 10 级」改成「全局 10 级」可以吗？（技能树里放 11 个桌 × 10 级太乱。）
