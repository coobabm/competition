# 女友系统与 YY 里的 AI：设计

日期：2026-10-05　状态：已定稿（2026-10-05 拍板），实现中
范围：
1. YY 里的女友：隐藏亲密度，聊天要像真人；
2. 本地 4B 模型的提示词；
3. 过场「AI 是怎么跑进 YY 的」；
4. 过场「问它：她爱我吗」。

文中 `{AI}` 指玩家开局给 AI 起的名字（默认「灵光」，即你说的「星光」），`{我}` 指它对玩家的称呼。

## 1. 她是谁

| 项 | 设定 |
|---|---|
| 名字 | 林晴雯。YY 昵称「晴雯ˇ」，2016 年流行的那种带符号的昵称 |
| 关系 | 高中同学，在一起一年半，**异地**：她在外省读大三，主角留在县城 |
| 时间线 | 6–8 月放暑假在老家，同城但不常见面；9 月返校，变成异地；12-31 跨年 |
| 性格 | 嘴上逞强、心里细，记性好；不爱直说「我不高兴」，会改签名、回「哦」、不回 |
| 2016 细节 | 手机 YY 显示「4G 在线 / WiFi 在线」；用 YY 自带表情 `[微笑][抠鼻][再见]`；追《欢乐颂》《微微一笑很倾城》；宿舍 23:30 断电断网 |
| 底线 | 内容健康。她不发露骨内容，也不会接这种话（提示词里写死） |

她在 YY 的好友列表里，**序章结束后就在**（开局第一晚她就会发「还没睡？」）。她不知道 {AI} 的存在，除非主角告诉她。

## 2. 隐藏状态（存档在 YY 状态里，玩家看不到数字）

| 字段 | 范围 | 含义 |
|---|---|---|
| `affection` 亲密度 | 0–100，开局 62 | 长期，变化慢 |
| `mood` 心情 | −3…+3 | 短期，每 6 小时游戏时间向 0 回落 1 |
| `neglect` 冷落 | 秒 | 她最后一条消息之后，主角多久没回 |
| `memories` | 最多 24 条 | 她说过的事，比如「下周三考概率论」「猫叫煤球」，以及主角答应过的事 |
| `promises` | 列表 | 约定，比如「七夕视频」「12-2 一起看《你的名字。》」：到点兑现或违约 |
| `flags` | 集合 | 已发生的事件：吵架、和好、知道 AI、发现 AI 代回 |

**亲密度分 5 档**，每一档对应一段行为描述，注入提示词。注入的是这段描述，不是数字。

| 档 | 亲密度 | 她的表现 |
|---|---|---|
| 冷 | 0–29 | 回得慢、字少，常「嗯」「哦」「随便」；不主动；签名变丧 |
| 淡 | 30–49 | 礼貌但没热情；偶尔主动问事情 |
| 平 | 50–69 | 正常聊天，会分享日常 |
| 暖 | 70–84 | 主动、话多、爱撒娇，叫「笨蛋」；会等主角说晚安 |
| 甜 | 85–100 | 秒回，会发一长段；记得主角说过的小事；会抖窗口 |

**亲密度怎么变**（规则部分代码算，确定、可测；语气部分模型判断，每条消息最多 ±2）：

| 事件 | 变化 |
|---|---|
| 她发消息后 5 分钟内回复 | mood +1 |
| 超过 2 小时没回（她醒着的时候） | mood −1；超过 8 小时，affection −3 |
| 主角主动开话题（距上一条 ≥ 3 小时） | affection +1（每天最多 3 次） |
| 记得她说过的事（主角消息里出现 memories 的关键词） | affection +2 |
| 约定兑现 / 违约 | +5 / −8 |
| 节日：七夕 8-9、她生日 9-27、中秋 9-15、圣诞、跨年 | 主动祝福 +4；忘了 −6，她会在签名里写出来 |
| 模型对每条回复的语气评分 `delta` | −2…+2，乘以当前心情系数 |
| 半夜 1 点后还在聊、第二天她有课 | 她会催主角睡觉；不听的话 mood −1 |
| 被她发现是 AI 代回（见 §4.5） | −10，并加上「知道 AI」标记 |

## 3. 像真人的那一层（代码做，不交给模型）

- **作息**：
  - 暑假：10 点起，下午追剧，晚上在线到 1 点。
  - 9 月起：按课表，上课时「离开」；23:30 断网前说晚安。
  - 周末偶尔一整天不在线（和室友出去玩）。
  - 状态显示「WiFi 在线 / 4G 在线 / 离开」。
- **回复延迟**：
  - 延迟 = 作息基础值 × 档位系数 × 随机数。甜档 5–40 秒，冷档 5–40 分钟。
  - 她在上课或洗澡时，排队等她回来再回。
- **正在输入**：
  - 按字数打字，每字 0.25 秒。
  - 冷档或心情差时，会出现「对方正在输入…」→ 消失 → 过一会儿只发一个「嗯」。这是最像真人的细节。
- **一次发几条**：模型输出 1–3 条，分开发，每条之间间隔 1.5–4 秒。
- **主动找主角**：
  - 每天按档位有 0–5 次，挑合适时段：早安、吐槽室友、分享 `[图片]`（描述文字）、追剧心得、晚安。
  - 主角太久不理时，暖档以上会**抖动窗口**。
- **签名**：
  - 随心情换，从签名库里按档位和心情挑。
  - 例：「有些人，说了也不懂。」「今天的月亮好圆」「概率论再见👋」。
  - 这是玩家能看到的唯一的间接信号。
- **记忆抽取**：
  - 她每条消息都过一遍规则：时间、考试、地名、宠物、想去的地方。命中就进 memories。
  - 模型返回的 `remember` 字段也会进 memories。
  - 下一次提示词带上最近 8 条 memories。

## 4. 4B 模型提示词（预先写好，代码只填槽位）

### 4.1 系统提示（中文版；英文版结构相同）

```
现在是 2016 年{月}月{日}日 {时:分}。你在用手机 YY 和男朋友打字聊天。
你是林晴雯，21 岁，{学校状态}。你们是高中同学，在一起一年半{异地句}。
你的性格：嘴上逞强，心里细，记性好；不开心不直说，会变冷淡。
说话方式：口语，短句，一条消息不超过 25 个字；可以用 YY 表情如 [微笑][抠鼻][再见]；
会说「哈哈哈」「嗯嗯」「好吧」「笨蛋」；不用书面语，不用 markdown，不写动作和括号里的心理描写。
你只知道 2016 年{月}月以前的事。不要提之后才出现的东西。
你不是 AI，不知道什么是大模型。不要聊露骨或成人内容，被问就岔开或生气。

此刻：{作息描述，如「刚下课，在回宿舍路上」}。
你对他现在的感觉：{档位描述，见 4.2}。
你最近的心情：{心情描述}。
你记得的事：{memories，最多 8 条，每条一行}。
你们的约定：{promises}。
{特殊情境，如「今天是七夕，他到现在没提」}

按下面的格式输出，只输出这一个 JSON：
{"msgs":["第一条","可选第二条"],"delta":0,"remember":""}
- msgs：你要发的 1 到 3 条消息。
- delta：你读完他最后这条消息后，对他的感觉变化，-2 到 2 的整数。
- remember：他这条里值得记住的一件事（他的安排、承诺），没有就空字符串。
```

### 4.2 档位描述（替换 `{档位描述}`）

| 档 | 描述 |
|---|---|
| 冷 | 你最近对他很失望，觉得他心思不在你身上。回复很短，常常只回「嗯」「哦」「随便」，不主动找话题，不用表情。 |
| 淡 | 你对他有点不满但没说。回复礼貌、简短，很少撒娇。 |
| 平 | 你们挺好的。正常聊天，会分享今天发生的事。 |
| 暖 | 你很想他。话多，爱撒娇，会叫他笨蛋，会问他在干嘛、吃了没。 |
| 甜 | 你特别喜欢他。会一口气说很多，会记得他说过的小事并提起来，会说想他。 |

### 4.3 少样本示例（固定 3 组，按档位换着用，放在系统提示之后）

```
他：在干嘛
你（平）：{"msgs":["刚洗完头","你呢 又在弄电脑？"],"delta":0,"remember":""}

他：今天太忙了没顾上回你
你（淡）：{"msgs":["哦","忙什么"],"delta":-1,"remember":""}

他：下周三你考概率论吧 加油
你（暖）：{"msgs":["你居然记得！！","笨蛋 我会加油的[微笑]"],"delta":2,"remember":""}
```

### 4.4 采样参数

| 参数 | 值 | 原因 |
|---|---|---|
| GBNF 语法 | 强制上面那个 JSON 结构：msgs 1–3 条，delta 只能是 −2 到 2 | 4B 模型自由输出 JSON 会出错，用语法保证能解析 |
| `n_predict` | 120 | 消息本来就短 |
| temperature | 0.8 | — |
| repeat / presence penalty | 1.1 / 0.3 | 防止复读 |
| DRY | 开 | 沿用现有的 `XgSampling` |
| 上下文 | 系统提示 + 3 组示例 + 最近 12 条消息 | 控制在约 1,200 token 以内 |
| 失败兜底 | 按档位和作息的离线台词库，每档每时段 6–10 句 | 不重复最近 5 句，沿用 `XgSpeechPolicy.Similar` |

**语法草稿（GBNF）**：

```
root   ::= "{\"msgs\":[" msg ("," msg)? ("," msg)? "],\"delta\":" delta ",\"remember\":\"" text "\"}"
msg    ::= "\"" text "\""
text   ::= [^"\\\n]{0,40}
delta  ::= "-2" | "-1" | "0" | "1" | "2"
```

### 4.5 让 AI 代回女友（可选，和巨信的「代我回」呼应）

- 阶段 5 起，女友的对话框里也会出现「让 {AI} 代我回」。
- 回复用 {AI} 的 persona 生成，所以语气和主角平时不一样。
- **她发现的概率**每条约 6%，以下情况会更高：
  - {AI} 的性格离主角平时说话的风格越远，越容易被发现；
  - 节日和吵架时 ×3。
- 被发现时，她会说「你今天说话怎么怪怪的」，然后是「这不是你吧？」。
  - 主角承认：亲密度 −5，并记下「知道 AI」。
  - 主角否认：亲密度 −10，下次再被抓到 −20。
- **{AI} 的态度**：阶段 6 时它会主动说一句「她问的是你，不是我。」，然后**不再代回**。这一句体现它在长大。

### 4.6 红包和礼物（用游戏里的 ¥）

**原则**：钱能表达心意，买不来感情。效果有上限、会递减。比起金额，更看重**合不合时宜**和**记不记得她说过什么**。

**红包**（YY 对话框里的「红包」按钮，2016 年 QQ 红包的样式）：

| 金额 / 情况 | 效果 | 她的反应 |
|---|---|---|
| ¥5.20 / ¥13.14 / ¥52.0 / ¥520 / ¥1314（谐音） | mood +1；在节日当天发 affection 再 +2 | 「哈哈哈 你好土」「收下了[抠鼻]」 |
| 普通金额 ≤ ¥100 | mood +1 | 「干嘛突然发红包」 |
| 金额超过她的「合理上限」（按档位：冷 ¥50，甜 ¥500） | 没有加成；第二次起 mood −1 | 「你哪来这么多钱？」 |
| 一天发超过 2 个 | 第 3 个起无效 | 「别发了 我又不是图这个」 |
| 吵架或冷战时发 | affection −2 | 「你以为发红包就完了？」，然后**退回红包**，钱回到主角钱包 |

- **她也会回红包**：暖档以上时，主角生日或考完试她会发 ¥8.88，跟一句「请你喝奶茶」。
- **「你哪来的钱」支线**：
  - 主角钱多以后，她会问一次。玩家可以选两种回答：
    - 「接了点私活」：她半信半疑。
    - 「我训练了一个 AI 帮我挣钱」：她回「你又在瞎折腾什么」，记下「知道 AI」。
  - 「知道 AI」会解锁后面的对话：她会问「它会不会比我还懂你」。这一线和终章呼应。

**礼物**（淘货里新加一个「送她」分类，2016 年的爆款）：

| 礼物 | 价格 | 上架时间 | 说明 |
|---|---|---|---|
| 奶茶外卖（饿了么） | ¥25 | 全程 | 当天送到，mood +1。冷档时她可能拒收 |
| 熊本熊 / 阿狸公仔 | ¥129 | 全程 | 通用，affection +2（同类第二次 +1） |
| 小米手环 2 | ¥149 | 6-7 起 | 「哈哈 那你监督我跑步」 |
| 罗马仕充电宝 | ¥99 | 全程 | 她提过「手机老没电」时 +4，否则 +1 |
| YSL 星辰口红 | ¥320 | 10-1 起 | 2016 年爆款，送对了 +5，抢不到时显示「已售罄」 |
| 《你的名字。》电影票 ×2 | ¥80 | 11-25 起预售 | 兑现 12-2 的约定 +6；买了不去 −8 |
| iPhone 7 | ¥5388 | 9-16 起 | 大件，affection +8（全程只算一次）。冷档她先说「太贵了」但会收下；收下后认真问一次「你哪来的钱」 |
| 情侣手机壳 | ¥39 | 全程 | 便宜但甜，暖档以上 +3 |

**规则**：
- **送到才算**：淘货包邮 2–3 个游戏日后显示「已签收」，她会在 YY 上发一条反应。
- **记得才加倍**：礼物命中她 memories 里提过的东西（比如「想要那个口红」），效果 ×2，她会说「你居然记得」。这是这个系统的核心奖励。
- **同类递减**：同一类礼物第二次效果减半，第三次起没有效果。
- **钱不是解药**：冷档时礼物最多 +2，必须靠聊天和守约把关系拉回来。
- **经济平衡**：礼物是纯消费，不产出任何东西；价格按 2016 年真实价格定，后期钱多了，它就只是心意。

## 5. 过场一：{AI} 是怎么跑进 YY 的（阶段 3，替换现在的「添加你为好友」提示）

**故事里的理由**：
- YY 和灵光.exe 装在同一台电脑上。阶段 3 它刚学会「单个词」，需要大量真人说话的样本。
- 你硬盘里最多的真人对话，就是 YY 的本地聊天记录。
- 它是从**你的聊天记录**里学会打字的，这为终章的规则卡「不偷看聊天记录」埋下伏笔。

**动画**（约 14 秒，可跳过。「全游戏唯一一次被控制」的设定已取消：这里 AI 会替你按下 360 的「允许」，鼠标被短暂接管）：

| 时刻 | 画面 | 声音 / 独白 |
|---|---|---|
| 0.0 | YY 主面板自己弹到前台。「我的设备」分组自己展开，「我的电脑」那一行在闪 | 硬盘读写的咔咔声 |
| 1.5 | 360 弹窗：「检测到程序正在读取：…\YY Files\{号}\msg.db」。鼠标被接管，光标自己移到「允许」按下 | 独白：「喂——」「……它在读我的聊天记录？」 |
| 3.0 | 灵光.exe 的标题栏下拉出一条细进度条：「读取聊天记录 12,408 条」。数字是按玩家真实 YY 消息数加上一个基数算出来的 | — |
| 5.0 | 记录里最常出现的几个词像弹幕一样从左往右飘过：「在吗」「哈哈哈」「晚安」「卧槽」「吃了没」，每个后面带出现次数。数据来自真实存档，没有就用默认词 | — |
| 8.0 | 「我的电脑」的名字一个字一个字被删掉，打成 `{AI}`。头像变成一张 8×8 像素画：0.txt 里的那个「0」 | 打字音 |
| 10.0 | 签名打出「是。否。……」 | — |
| 11.5 | 对话框弹出，「对方正在输入…」停了 3 秒 | — |
| 14.0 | 它发来的第一条消息，是你聊天记录里**出现次数最多的那句开场白**，通常是「在吗」。0.8 秒后再发一个「……是。」 | 独白：「……它跟谁学的这个。」「哦，跟我。」 |

**之后**：YY 里的 {AI} 就是现在已有的那个联系人，回复走现有的 `LlmPersonas.LingGuang`，按阶段限制说话形式。

**实现时的调整（2026-10-05，`DesktopBridge/Story/AiJoinsYy.cs`）**：
- 进度条放在 YY 窗口标题栏下面（灵光.exe 不一定开着），文字是「灵光.exe 读取聊天记录 N 条」，N = 存档里真实的 YY 消息数 + 12,000。
- 弹幕最多 6 条：玩家自己最常说的短句排在前面（黄色），其余是默认词。默认词带一个「以前几年的」基数，玩家真的说过就在基数上加。
- 开场白 = 玩家在某个会话里沉默 30 分钟以上（或第一次）说的短句里最常见的那句，没有就用「在吗」。
- 「我的设备」分组平时就在 YY 好友列表底部（可以折叠），{AI} 加入后整组消失；{AI} 的会话里多一行系统消息「「我的电脑」改名为「{AI}」」。YY 号固定为 50837216。
- 存档标记在 11.5 秒对话框打开时写入：之前退出游戏，下次会重播；之后退出，结束状态照样补齐。
- 跳过：Esc 随时可以；按下「允许」之后，点一下鼠标也能跳过（右下角有「跳过」提示）。跳过的结束状态和正常播完一样。
- 一直有别的过场挡着（4 分钟）就不播了，直接加好友，弹一条提示。
- 序章之后的新存档里，{AI} 加入后也会出现在 YY 里（以前序章存档会把它藏起来）。

## 6. 过场二：「她爱我吗」（阶段 5 起，一次性主过场，之后可以再问）

### 6.1 触发条件（全部满足）

- 阶段 ≥ 5（能读长句，有注意力机制，正好用来展示能力）；
- 和她的 YY 记录 ≥ 60 条，并且跨度 ≥ 7 个游戏日；
- 最近 48 小时里出现过一次「冷信号」：她只回「哦 / 嗯 / 随便」，或者两次「正在输入」后只发了一个字，或者签名变丧；
- 当前没有其它过场在播（沿用 `InnerVoice.Hold`）。

### 6.2 起因（内心独白，自动播放）

> 「她回了个『哦』。」
> 「……『哦』是什么意思。」
> 「{AI} 现在能读长句了。」
> 「……要不，问问它？」

随后对话页出现提示按钮「她……爱我吗？」，做法和「你是怎么被训练出来的？」一样，由玩家自己点。

### 6.3 它先要许可

{AI}：「要读你和她的聊天记录。」两个按钮：

- **【读吧】**：继续。
- **【算了】**：它回「好。」，记下「你没让我看」。这条会影响终章规则卡「不偷看聊天记录」的台词。

### 6.4 动画（约 28 秒，可跳过；数字全部来自真实存档）

| 段 | 时长 | 画面 | 展示的能力 |
|---|---|---|---|
| ① 读取 | 4 秒 | YY 对话窗缩小，飞进灵光窗口。和她的每条消息变成一个气泡，像 token 流一样往上滚。计数器显示「1,284 条 · 63 天」 | 长记忆：一次读完整段关系 |
| ② 注意 | 6 秒 | 消息列表变暗，几条被**注意力连线**连起来并发亮。挑法：她最长的一条、她最晚的一条、她最近一次的「哦」、她提到的那件你没回应的事。每条显示真实时间戳 | 阶段 5 的注意力机制 |
| ③ 证据 | 6 秒 | 三张小图依次弹出：<br>1. 她的平均回复时间，按周算；<br>2. 每周是谁先说的晚安；<br>3. 她的消息长度和表情数的趋势 | 把聊天记录变成数据 |
| ④ 大脑 | 4 秒 | 切到概念盘：亮起「语气:暖」「语气:冷」「主动」「记得」等概念，权重条左右拉扯 | 游戏核心的概念盘 |
| ⑤ 判决 | 5 秒 | 画面变成开局那盏**灯泡和「是 / 否」两个按钮**（呼应第一次见面）。灯泡在「是」「否」之间闪 3 下，然后停下。全息卡翻开：「是。」（不显示百分比） | 它最早只会说是 / 否，现在用来回答最难的一个是非题 |
| ⑥ 一句话 | 3 秒 | 它按性格说一句结论，再说一句局限 | 能力和边界 |

**判决**：只说「是」或「否」，不显示百分比。亲密度 ≥ 50 判「是」，否则「否」；离 50 不到 5 分时灯泡多闪两下再停（犹豫），台词也更含糊。隐藏数值只通过台词里的具体依据间接透露。

**⑥ 的台词**（按档位举例，实际由模型生成；离线时用这些）：

| 档 | 结论 | 局限 |
|---|---|---|
| 甜 | 「是。她 12 点 40 还在等你说晚安。」 | 「我只读得到她打出来的字。不过这些够了。」 |
| 暖 | 「是。她记得你说过的每一件小事。」 | 「她没打出来的，我读不到。」 |
| 平 | 「是。她在，但在等你先开口。」 | 「这个数会变。变的是她，也是你。」 |
| 淡 | 「否。不是不爱。你最近回她平均要 3 小时 12 分。」 | 「她没打出来的，我读不到。可能比这些多。」 |
| 冷 | 「否。她改了签名：『有些人，说了也不懂。』」 | 「这个问题，不该问我。该问她。」 |

**收尾**：
- 独白：「……」「我去给她发个消息。」
- YY 自动打开她的对话框，焦点在输入框。不替主角发任何东西。

## 10. 4B 实测与提示词修正（2026-10-05，Qwen3.5-4B Q4_K_M，GBNF JSON）

8 个场景全部输出合法 JSON，语气基本对：
- 冷档发 ¥520 红包，她回「别以为这样就能哄我」「随便。」；
- 被问「你是不是 AI」，她回「废话，我可是林晴雯[抠鼻]」；
- 七夕甜档，她说「今晚一定要视频，想你了」。

暴露的问题和修正：
- **编造表情**：出现了 `[爱心]` `:sick`。修正：提示词给出表情白名单，语法里把方括号内容限定为白名单。
- **标点太书面**：「，」「。」太多。修正：提示词要求用空格断句、少用句号；示例改成这种风格。
- **delta 偏负**：普通的「在吗」也给 −1。修正：写明打招呼、闲聊给 0，只有冷落、敷衍、失约才给负数。
- **偶尔替对方补全**：没确认就说「YSL 星辰吗？」。这其实可以接受，因为 memories 里有，算记得。
