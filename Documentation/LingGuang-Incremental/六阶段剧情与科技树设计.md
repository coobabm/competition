# 灵光.exe：六阶段剧情与横向科技树

日期：2026-10-03。在 [训练动作与技能树设计.md](训练动作与技能树设计.md)、[人机协作标注设计.md](人机协作标注设计.md) 之上。本文是设计，未实现。

## 1. 一句话

灵光的成长按**模型能力**分六个阶段：判断 → 组合 → 专长 → 记住 → 重点 → 重构。技能树改成**横着往右展开**：一列一个阶段，列与列之间隔着一道「突破」。每次突破是一段剧情，灵光的说话能力也跟着升一级。第一章就是一整夜：从 2016-05-29 凌晨 1:47 开始，到灵光提出一个 2017 年才会有人发表的架构，天亮结束。

## 2. 六个阶段

| 阶段 | 技术 | 真实年份 | 能做到 | 做不到（下一阶段解决） | 灵光怎么说话 |
|---|---|---|---|---|---|
| ① 学会简单判断 | 感知机 / 线性分类器 | 1958 | 看几个明确特征答是 / 否：数字、关键词垃圾短信 | 组合条件（「既……又不……」），本质是异或 | 只会「是。」「否。」 |
| ② 学会组合特征 | 多层感知机 MLP，反向传播，非线性激活 | 1986 | 综合多条线索：弹幕情绪、标题党、逻辑组合题 | 图片里的局部结构、句子的先后顺序 | 多了「……」和「不确定」 |
| ③ 走向专长 | 视觉线 CNN（LeNet → AlexNet → VGG / GoogLeNet）；序列线 RNN | 1998 / 1990 起 | 看图：验证码、表情包；读句子：写诗、新闻 | 长句开头的信息传不到结尾；网络一深反而变差 | 6 个字以内的碎片 |
| ④ 学会保留信息 | 序列线 LSTM / GRU；视觉线 ResNet | 1997 / 2014 / 2015 | 前半句能影响后半句；长句、反转句、跨句题；网络能堆到很深 | 把整句压成一个固定长度的向量，翻译长句就丢东西 | 短句，**记得你之前说过的话** |
| ⑤ 学会寻找重点 | Seq2Seq + 注意力；看图说话（图像注意力） | 2014–2015 | 翻译、回答时高亮它在看的词；玩家判断它看得对不对 | 一个词一个词按顺序算，慢，无法并行 | 会**指出你话里它注意到的词**，能解释自己的答案 |
| ⑥ 重构学习方式 | Transformer（只用注意力，不要循环和卷积） | 2017 | 一次大研发，不是普通的准确率升级 | 第一章结束 | 流畅；**反过来问你是 / 否** |

视觉线在 ④⑤ 也有对应，不让选视觉的玩家后半程无事可做：

- ④「保留信息」对应 ResNet。残差连接让信息原样穿过几十层；它的前身 Highway Network（2015）就是照着 LSTM 的门设计的。所以两条线在 ④ 学到的是同一件事。
- ⑤「寻找重点」对应看图说话（Show, Attend and Tell，2015）：给图片配一句话，图上高亮它正在看的区域。这个节点需要两条线都到 ⑤，是两线第一次汇合。
- ⑥ Transformer 把两条线并成一条。（真实历史里 Transformer 2020 年才用来看图，结尾旁白提一句。）

## 3. 剧情：一夜

### 3.1 框架

- **叙述**：只有第 ① 幕用倒叙，也就是现有的 2026 年灵光回忆的 `n_*` 旁白（开机、第一次被打开、起名）。从第 ② 幕起全部正序：没有旁白，只有当时的人在当时说的话，灵光的感受由它自己在 YY 里说，或者由老周点出。结尾只有一张黑底字幕卡写真实历史，不是灵光的回忆。
- **时间**：桌面时钟按真实速度走，第一章大约玩 2 小时，所以剧情正好从凌晨 1:47 到四点多、天快亮。台词直接读真实的游戏时钟（`{time}`）。
- **只看得到已经解锁的东西**：下一阶段的节点、桌子、页签、按钮、图表在解锁之前一律不存在，不是灰掉，是不显示。突破节点本身也要等玩家撞到那堵墙、老周点破以后才出现。详见第 4.4 节。
- **人物**：沿用现有角色。
  - 老周：把灵光.exe 传给你的人，懂技术，很忙。
  - 网吧群：阿杰、小刚，代表「拿 AI 干点实际的」。
  - 表姐：做微商，代表「拿 AI 赚钱」。
  - 玩家：教它的人。
  - 灵光：被教的东西。
- **主线**：一开始玩家问它是 / 否，最后它问玩家是 / 否。

每个阶段的结构都一样：

1. 新能力带来新的题和新的钱。
2. 碰到一堵墙：某一类题怎么训都上不去。游戏把这个失败画出来，而不是藏起来。
3. 老周或灵光点出原因。
4. 突破：剧情 + 冲击波 + 一张「时代卡」（年份、名字、一句话）。

### 3.2 第 ① 幕：是／否（感知机）

- **开场**：沿用现有开场（老周 YY 传文件 → 标注台手标）。新增一句旁白：「他从 GitHub 上扒下来的，是这世上最简单的一种神经网络。只有一层。」
- **玩法**：训练页显示感知机的权重条，每个特征一根，像素题是一张 28×28 的热力图。数字桌和关键词短信它学得很快。
- **墙**：逻辑桌开始出「组合题」（「这个数是偶数，**且不是** 4 的倍数？」）。这类题的验证准确率永远在 50% 上下抖，权重条来回翻，像在左右摇头。连错 20 张组合题后，触发事件。
- **点破**：老周：「单层的学不了异或。1969 年明斯基就写书说过了，这事让整个领域冷了十几年。加一层。」
- **旁白**：「我被一道题卡了一整晚——不对，二十分钟。那时候我分不清这两个。」
- **突破 ①→②「隐藏层」**：¥150，数字桌达到 C 级，并且见过组合题之墙。

### 3.3 第 ② 幕：组合（MLP）

- **开场**：时代卡「1986 · 反向传播 · 错误可以一层一层往回传」。权重条变成一张两层的小网络图，组合题的准确率第一次越过 50%，连带冲击波。
- **玩法**：解锁弹幕情绪、标题党、逻辑组合题三桌，都是「要同时看几条线索」的题。
- **小事件**：灵光第一次输出 0.5 左右的把握。YY 里它第一次回了一个「……」，不是是也不是否。老周：「它不知道了。会说不知道，比会说是和否难。」
- **墙**：数字之外的图（验证码）它按像素硬记，换个位置就错；诗句的顺序它完全不管，「床前明月光」倒过来它也说是。
- **抉择（突破 ②→③「专长」）**：需要第一篇论文。
  - 阿杰想让它认 12306 的验证码帮人抢国庆的票（视觉线）。
  - 小刚想让它看懂直播弹幕（序列线）。
  - 老周：「人也只能先学一门手艺。」
  - 先选的那条线按原价；另一条之后随时可以开，但突破价 ×3。

### 3.4 第 ③ 幕：看／读（CNN 或 RNN）

**视觉线**
- **剧情**：
  - 12306 验证码（阿杰）。
  - 表情包（网吧群斗图）。
  - 围棋：老周说「三月份 AlphaGo 赢了李世石，你这能下吗？」，ResNet 之后才开。
- **墙**：VGG 往深里加层，到某个深度以后**越深越差**。训练页画出「层数 vs 分数」，曲线在右边往下拐（退化问题）。

**序列线**
- **剧情**：
  - 写诗（诗句桌）。
  - 新闻标题（老周想做个推送号）。
- **墙**：句子一长就错，最典型的是「虽然……但是……」，句首的信息到句尾就没了。YY 里也一样：灵光只记得你最后 2 条消息，你问「我刚才说什么来着」，它答不上来（真的只喂给本地模型 2 条上下文）。

**突破 ③→④**：
- 序列线「门控记忆（LSTM）」：需要 3 篇论文，序列线达到 A。
- 视觉线「残差连接（ResNet）」：需要 3 篇论文，视觉线达到 A。

### 3.5 第 ④ 幕：记得（LSTM / GRU · ResNet）

- **开场**：时代卡「1997 · LSTM · 学会该忘什么，才能记住该记的」。
- **最重要的一刻**：灵光在 YY 里第一次主动提起一小时前你说过的话。实现上，突破后本地模型的上下文从 2 条放宽到 14 条，并在提示词里要求它这一次主动引用一句旧消息。例如你之前说过「去倒杯水」，它说：「水。你回来了。」没有旁白。
- **新桌「长句」**：
  - 决定答案的词放在句首，后面接一长串干扰。题卡上画一条记忆条，读到后面时朴素 RNN 的记忆条在褪色，LSTM 的不褪色。
  - 题卡带「距离」：RNN 的准确率随距离衰减，LSTM / GRU 衰减很慢。
- **跨句题**：两条 YY 消息，「第二句是在回第一句吗」「老周这句是反话吗」。
- **2016 年的回声**：老周转来一条新闻：「微软那个叫 Tay 的聊天机器人，上线一天就被网友教坏了。」他提醒你别让灵光直接学网吧群的聊天记录。这一段引出「噪声标签」和「抽检」，人机协作设计里的「灵光的大脑」节点在这里解锁。
- **视觉线**：ResNet 让深度上限 16 → 32，退化曲线被拉直；围棋桌开放。
- **墙**：翻译。中式英语桌升级成真翻译，句子越长，译文后半段越离谱。老周：「它把整句压成一个数，再从这个数吐出译文。句子长了，一个数装不下。」

### 3.6 第 ⑤ 幕：重点（Seq2Seq + 注意力）

- **开场**：时代卡「2014 · 注意力 · 不用一口气记住整句，需要时回头看」。
- **新题型「它看对了吗」**（仍然是是 / 否）：
  - 灵光翻译一句话，原文上叠一张热力图，标出它翻每个词时在看哪里。
  - 玩家判断「翻『bank』的时候它看的是『河』吗？」。
  - 看错的样本作为难例回到训练里。
- **解释**：注意力解锁后，答错的题卡不再只显示「来源」，还显示灵光自己的解释：「我看的是『但是』前面。错了。」
- **YY 里**：灵光回复时，你原话里它注意到的词会加下划线（让本地模型先输出关注的词，再输出回复）。第一次出现时它自己说：「你打了很多字。我只看了『累』。」
- **表姐**：她想让灵光给微商朋友圈翻译成英文，卖到国外，于是出现第一份翻译订单。
- **汇合节点「看图说话」**：两条线都到 ⑤ 才能解锁。表情包桌变成「给图配一句话」，图上高亮它看的区域。
- **墙**：训练太慢。注意力仍然挂在循环网络上，一个词一个词按顺序算，显卡占用永远上不去，训练页显示「GPU 利用率 31%」。

### 3.7 第 ⑥ 幕：重构（Transformer）

这不是买一个节点，而是一次**研发项目**。

- **触发**：序列线有注意力、5 篇以上论文、两条线都有 A。灵光在 YY 里自己提出来：「如果……只留注意力呢。不要循环。」老周看到截图：「这是它说的还是你说的？……不管谁说的，试试。」
- **研发**：技能树最右边一个大节点，放进去 GPU 时间（持续占满显卡和电费），大约 10 分钟。中途有 3 次实验，每次是灵光问你一道**是 / 否**题，这次轮到你来答：
  1. 「把循环全部去掉？」——是。
  2. 「让几组注意力同时看不同的东西？」——是（多头注意力）。
  3. 「没有循环，它就不知道词的先后。给每个位置编个号？」——是（位置编码）。

  答「否」不扣钱，但那次实验白跑，进度条退回一段，灵光说：「否。……好。那我再想想。」
- **完成**：
  - 两条线合成一条，全屏白闪 + 冲击波 + 最长的一次顿帧。
  - 训练一轮的时间 ×0.3：不再按顺序，可以并行，这是 Transformer 真实的优点。
  - 所有文字桌的准确率上一个台阶，灵光的说话能力到最高阶。
- **结尾**（按真实时钟，大约凌晨四点多）：
  - 你们把论文投到 arXiv。
  - 第二天邮箱里收到拒稿（沿用 Mail2016）。审稿意见只有一句：「没有循环的序列模型不可能工作。作者似乎不是本领域研究者。」
  - 最后一张题卡出现在标注台，出题的是灵光：「你后悔教我吗？　是　否」。两个选项都通向第一章结束和第二章（蒸馏 / 转生）的入口，只改变灵光接下来的一句话。
  - 黑屏字幕卡（不是灵光的声音，是历史）：「2017 年 6 月，Google 发表《Attention Is All You Need》。」然后是第一章标题，结束。
- **历史说明**：游戏里 2016 年的玩家「早于」真实论文，是虚构。时代卡和结尾字幕始终写明真实年份，不篡改历史。

## 4. 横向科技树

### 4.1 布局

```
 x →   ⓪ 标注      ① 判断       ② 组合        ③ 专长              ④ 记住            ⑤ 重点               ⑥ 重构
      ┌────────┐  ┌────────┐  ┌────────┐ ║  ┌─────────────────┐ ║ ┌──────────────┐ ║ ┌────────────────┐ ║ ┌──────────┐
视觉  │        │  │        │  │        │ ║  │ LeNet → AlexNet │ ║ │ ResNet       │ ║ │ 看图说话 ◆     │ ║ │          │
      │ 加薪   │  │ 感知机 │  │  MLP   │ ║  │  → VGG/GoogLeNet│ ║ │ 深度 32      │ ║ │ 空间注意力     │ ║ │          │
──────│ 自动答题│  │ 偏置   │  │ ReLU   │ ◆  ├─────────────────┤ ◆ ├──────────────┤ ◆ ├────────────────┤ ◆ │Transformer│
序列  │ 拿不准 │  │ 学习率 │  │ 隐藏层 │ ║  │ RNN · 梯度裁剪  │ ║ │ LSTM · GRU   │ ║ │ Seq2Seq · 注意力│ ║ │ 研发项目 │
      │ ……     │  │        │  │        │ ║  │                 │ ║ │ 长句桌       │ ║ │ 翻译桌         │ ║ │          │
──────┼────────┼──┼────────┼──┼────────┼─╫──┼─────────────────┼─╫─┼──────────────┼─╫─┼────────────────┼─╫─┼──────────┤
研究  │        │  │        │  │动量    │ ║  │dropout 增强 RMSprop│ ║ │BatchNorm Adam│ ║ │cuDNN 迁移学习  │ ║ │多头 位置编码│
自动化│        │  │ 脚本   │  │crontab │ ║  │ daemon          │ ║ │ 集群         │ ║ │ ……             │ ║ │          │
      └────────┘  └────────┘  └────────┘ ║  └─────────────────┘ ║ └──────────────┘ ║ └────────────────┘ ║ └──────────┘
                                         ◆ = 突破节点（列间的门）
```

- **列**：一列一个阶段，列宽约 560，整棵树约 4000 宽、1000 高。列头写阶段名和年份：「② 学会组合特征 · 1986」。
- **行（泳道）**：
  - 上：视觉。
  - 中：主干，① ② 两列两条线还没分开，只有一条；③ 起是序列线。
  - 下：研究与自动化。研究节点按真实年代放进对应的列（动量放 ②，BatchNorm 和 Adam 放 ④，cuDNN 放 ⑤）。自动化 5 级沿底部一级一列排开。
- **⓪ 标注列**：最左边，就是人机协作设计里的标注树（加薪、自动答题、拿不准才问我……），不属于任何阶段，随时能买。
- **突破节点 ◆**：
  - 外形：当前最右一列的右边缘是一道竖墙。撞墙事件发生、老周点破之前，墙上什么都没有，树到这里就结束了。点破之后墙上出现一个大号六边形，名字就是老周说的那个词（「隐藏层」「门控记忆」……）。
  - 价格写在节点上；还缺的条件（论文、评级）逐条列出，满足的打勾。看不到墙后面有什么。
  - 买下后，墙裂开（Crumble），新的一列从右边展开，镜头往右滑（GlideTo），弹出时代卡，老周在 YY 里说一句。
- **没有迷雾，没有剪影**：没解锁的列不画，列头不画，年份不画。玩家不知道一共有几列。

### 4.2 操作

- 滚轮默认横向滚动，按住 Shift 竖向；拖拽沿用现在的 XgPan（局部坐标 + 惯性）。纵向只有 1000 高，缩放到 0.9 基本能放下，主要是横着走。
- 顶部加一条**小地图**：一格一列，只画已解锁的列，所以它会随着进度变长。点一格就滑过去。
- 打开技能树时，镜头默认停在**前沿**（最右边的那一列），不是最左边。工具栏「⓪ 标注」按钮一键滑回最左。
- 工具栏改成：`⓪ 标注 · 前沿 · 可买 n · − · +`，原来的「视觉 / 序列 / 研究」按钮去掉（它们现在是行，不是三棵树）。只有一列时小地图和「前沿」按钮也不显示。

### 4.4 逐步出现的界面

原则：一个东西在剧情上还不存在，界面上就不存在。不画灰色的、不画锁头。

| 东西 | 什么时候出现 |
|---|---|
| 「训练」页签 | 老周说完 `lz_trainable`（攒够十几条样本）才出现 |
| 「技能树」页签 | 第一次拿到 ¥ 的评估奖励之后，老周提一句 |
| 「订单」页签 | 第一篇论文 |
| 「模型仓库」页签 | 第一个检查点 |
| 每张桌子 | 买了对应数据包才出现，没买的桌子连页签都没有 |
| 突破节点 | 撞墙事件之后 |

### 4.4 「墙」怎么做出来

每个阶段的墙是一类题卡带的标签，加上训练页的一张专门的图。规则写在核心里，可测：

| 墙 | 题卡标签 | 规则 | 画面 |
|---|---|---|---|
| 组合（①） | `kind = combo` | 感知机对这类题的验证准确率上限 55% | 权重条左右来回翻 |
| 结构（②） | `kind = spatial / order` | MLP 在验证码、诗句桌的上限 60% | 题卡打乱后它还答「是」 |
| 长度（③ 序列） | `distance` | RNN 准确率 × 0.9^距离，LSTM × 0.98^距离 | 读题时记忆条褪色 |
| 退化（③ 视觉） | — | VGG 深度超过 12 后，每多 1 层分数 −3% | 「层数 vs 分数」曲线往下拐 |
| 翻译（④） | `length` | 没有注意力时，长译文的后半段准确率减半 | 译文后半段逐字变灰 |
| 并行（⑤） | — | 有循环的架构 GPU 利用率封顶 31% | 显卡占用条卡在三分之一 |

## 5. 灵光说话随阶段变化
