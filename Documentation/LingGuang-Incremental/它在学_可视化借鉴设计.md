## 二、逐个设计

### 2.1 训练页：双曲线和显微镜（Playground）

**双曲线。** 曲线卡现在只有一条准确率线。改成两条：
- 实线 = **练过的题**，也就是训练集准确率；
- 虚线 = **新题**，也就是没见过的题，诊断证据里已经有"练过的 12 题 / 新题 12 题"这组数据。

两条线**分开**，就是死记硬背（过拟合）。中间的空隙用淡红填充，旁边标一句"它在背答案"。这正好和"下降风险 · 过拟合"的原因对应：玩家会**先看见空隙变大，再看到风险标签**。

**显微镜。** `XgRealTrainPanel` 不再只在三个剧情时刻出现。训练页加一个小按钮"🔬 看它学"，随时可以打开，但每次只跑一小轮（约 8 秒）。面板里：
- **左边：** 8×8 输入图，每张下方是它的回答 ✓/×。
- **中间：** 每个隐藏单元一张 8×8 小热力图，取它的权重，绿正红负，也就是 Playground 的"神经元在看哪里"。每训练一步重画一次，玩家能看到一个单元**慢慢变成"0 的外圈"**。
- **连线：** 输入到单元、单元到输出，线宽 ∝ |w|，颜色是 w 的正负；变化快的线闪一下。
- **右边：** 两条误差小线（练过的 / 新的）。

数据全来自 `XgTinyRun`，不需要新的模型代码。

### 2.2 对话页：候选条和注意力连线（Transformer Explainer）

**下一个字的候选条。** 它在 YY 里打字时，每打出一个字，输入框上方闪一下 **3–5 个候选字和它们的概率条**，选中的那个是高亮色。
- 阶段 2–3：候选很散，比如"凉 22%、好 18%、是 15%……"，常常选错。
- 阶段 5–6：选中的那个能到 80% 以上。

**一眼就能看出它"越来越有把握"。** 概率不需要真模型：从掌握度和答案生成。正确字的概率 ≈ 掌握度，其余按习惯分配，比如阶段 3 的错法是"选 X"。

**温度旋钮**（可选，阶段 4 起）：放在语气习惯旁边。温度低，说话稳；温度高，说话跳，偶尔冒出怪句子。这正好接上语气区"它学会了你喜欢的口气"。

**注意力连线**（阶段 5 起，"它记住你说过的话"）：悬停它回复里的一个词，从这个词连线到你**之前**说过的话里它注意的那几个词，线越粗注意越多。比如它说"老周的显卡"，线连回你三条消息之前那句"我借了老周的显卡"。这是"记住了"最直观的证据。

### 2.3 答卷和看图区："它怎么看的"（CNN Explainer）

- 答卷里的看图题，比如手写数字、验证码、表情包，点一下就展开**分层视图**：

  ```
  输入 8×8  →  4 张边缘图  →  4 张池化图  →  [是 0: 87%] [不是: 13%]
  ```

- 点其中一张边缘图，会看到一个 3×3 窗口在输入上滑动，每走一步，右边那格亮一下（点积）。最后一列是概率条。
- 答**错**的题，展开以后能看到是哪张特征图"看偏了"。比如把 6 看成 0，是因为"闭合外圈"那张图亮得太满。
- 需要给 `XgTinyNet` 加一个很小的卷积层：4 个 3×3 核加 2×2 池化，数据还用现有的 8×8 数字。这是这几项里唯一要动模型代码的。

### 2.4 纠错的瞬间：梯度往回流（micrograd）

在答卷上纠正一道错题（`RememberSheetCard` 那一步）时，播放约 1.2 秒的动画：
1. 输出端冒出一个红点，标上"错 −1"；
2. 红色沿连线**往回**流，经过的节点各显示一个小数，比如"该怪它 0.3"；
3. 流过的权重各挪一点，线的粗细跟着变；
4. 下一轮训练，这道题翻成 ✓。

不需要真的算整个大模型的梯度：动画画在显微镜那张小网上，数值取 `XgTinyNet` 一次真实的反向传播。

### 2.5 终章：逐层点亮（llm-viz）

预训练进度条旁边画一叠 Transformer 块（2D 等距视角就够，不用 3D）：
- 进度每过 1/12，点亮一层；
- 左侧一句解说，比如"第 3 层：它开始分清主语和宾语"；
- 每层用 `PretrainLoss` 当下的值着色，点亮的那层闪一下。

原理讲解视频里的 Transformer 段落，也可以照 llm-viz 的"镜头沿数据流走"重做。

## 三、实施顺序和代价

| 步 | 内容 | 改哪 | 新模型代码 |
|---|---|---|---|
| 1 | 训练页双曲线 | `XgTrainPage.cs` 曲线卡；`XgSim` 加一个新题准确率序列 | 无 |
| 2 | 显微镜（常驻的真训练面板） | `XgRealTrainPanel.cs`：开放入口、加热力图单元和连线 | 无 |
| 3 | 对话页候选条 | 对话页打字逻辑；按阶段生成候选分布 | 无 |
| 4 | 注意力连线（阶段 5+） | 对话页；记忆里的 bigram 匹配 | 无 |
| 5 | "它怎么看的"分层视图 | `XgTinyNet` 加卷积层；答卷看图题加展开 | 小卷积层 |
| 6 | 纠错梯度回流 | 答卷纠错动画，借显微镜的小网 | 读 grad |
| 7 | 终章逐层点亮 | 预训练面板 | 无 |

**许可：** cnn-explainer、transformer-explainer、llm-viz、micrograd 是 MIT，playground 是 Apache-2.0，都能借代码。但它们是网页 TS/JS，Unity 里实际上是照着用 `MaskableGraphic` 重画（和 `XgCortexGraphic` 一样），借的是设计，不是代码。
