## 一、交房租：在 YY 里给房东转账

### 1.1 现在

房租每隔一段时间自动从钱包里扣（截图：「房租 ¥350/天 · 1:38 后扣 ¥700（两天）」）。玩家不知道钱去哪了，也没有「交租」这件事的感觉。

### 1.2 改成

主人公自己租房，房租就是他每月要亲手转给房东的一笔钱。

| 步骤 | 发生什么 |
|---|---|
| 1. 到期当天 | 房东「按时到账」在 YY 发消息，说清楚数：「小伙子，这期房租 ¥2100，今天转一下哈。」消息下面带一张转账请求卡：金额 + 「转账」按钮 |
| 2. 玩家转账 | 点卡片上的「转账」，或在房东聊天框工具栏点「￥ 转账」输入金额，或直接打字「转你 2100」。钱从钱包扣掉，聊天里出现一个橙色转账气泡「￥2100.00 已转账」 |
| 3. 房东回 | 「收到👍」或「这个月还挺准时」（按时交满三次后） |
| 4. 没转 | 不会自动扣钱。拖着就按现有的欠租升级走，但每一步都是房东在 YY 里说：第 1 天「别忘了房租哈」→ 第 2 天「再不交我拉闸了」→ 第 3 天拉闸（显卡全停，手动「教」还能挣钱）→ 第 4 天「电脑先押我这儿」（卖电脑，原破产结局） |
| 5. 钱不够 | 可以先转一部分（输入比应付少的数）。房东：「先转这些？行，剩下的月底前补上。」剩余部分照样计入欠租 |

**细节**
- 租期：沿用现在的房租节奏，但一次收一期（比如每 7 个游戏日一期），而不是每天扣，让「交租日」成为一个事件。金额 = 每日租金 × 天数。
- 第 3 阶段之前免租（沿用现有规则）。开始收租的前一天，房东先打招呼：「下周开始收房租了哈，每周一转我。」
- 转账卡和红包共用一套气泡样式，颜色不同（转账橙色、红包红色）。
- 记账本（如果做了）自动记一笔「房租」。
- 晚交不罚钱，只影响房东的态度（突发事件 `e051 要涨房租` 讲价更难）。准时交满五期，房东在冬至送饺子（`e083`）。
- 「转你 2100」这类打字只在房东的会话里生效；数字可以带「¥」「块」「元」。

### 1.3 程序

| 项 | 位置 |
|---|---|
| 取消自动扣租 | `ChapterOneSim.Bills`（房租部分）：到期只生成一张「应付账单」，不扣钱 |
| 房东消息 | `YYChatHub` 的 `landlord` 会话：到期、提醒、拉闸、收到，全部是写好的台词（不走模型） |
| 转账 | 房东会话工具栏加「￥ 转账」按钮（复用 `YYGirlfriendBar` 的红包面板写法）；转账卡消息类型 `YYKind.Transfer`；打字识别「转你 / 转给你 + 数字」 |
| 欠租升级 | 沿用现有的欠款天数逻辑，只是触发点从「钱包 < 0」改成「有未付账单」 |

## 二、科技树：可以缩放，拖动不卡

### 2.1 缩放

- 鼠标滚轮缩放，以鼠标所在位置为中心；范围 50%–150%，每格 10%。
- 右上角已有的「− ＋」按钮改为缩放，旁边加「⤢ 适应」：一键缩放到整棵树装得下。
- 缩放时字号不变形：节点用 `localScale` 缩放整块内容；缩到 70% 以下时隐藏节点下方的价格小字，只留名字和图标。
- 双击空白处回到 100% 并居中到「下一步可买」的节点。
- 缩放比例存进设置，下次打开保持。

### 2.2 拖动卡顿的修复

| 可能原因 | 修法 |
|---|---|
| 拖动时每帧刷新整棵树（重设每个节点的文字、颜色、状态） | 拖动和缩放时只改内容根节点的 `anchoredPosition` / `localScale`，不调用 `Refresh()`；松手后再刷新一次 |
| 连线每帧重新生成网格 | 连线合成一个 `MaskableGraphic`，只在购买、解锁时 `SetVerticesDirty`；拖动不重画 |
| 每个节点都是射线目标，拖动时悬停提示不断触发 | 拖动开始时关掉悬停提示（`UiTip` 暂停），节点的装饰图层 `raycastTarget = false`，只留一个透明的点击层 |
| 科技树和整个 .exe 在同一个 Canvas | 科技树内容放进单独的子 Canvas |
| 屏幕外的节点也在画 | 加 `RectMask2D`（裁掉屏幕外的）；节点多时按可见区域开关 |
| 拖动跟手不顺 | 用 `ScrollRect` 的惯性拖动（或自写：松手后速度按 0.9 每帧衰减），拖动边界留 200 像素回弹 |

目标：科技树拖动和缩放时稳定 60 帧，Profiler 里拖动期间没有 `Canvas.BuildBatch` 尖峰。

## 三、国际象棋五十题

- 数据：`Design/data/chess_mates_lichess.json`，**一步杀 25 题、两步杀 25 题**，全部取自 Lichess 公开题库（CC0，可商用；制作人员名单里致谢 Lichess）。每题记了原题编号、难度分（809–1392，都是入门难度）、原对局着法、轮到谁走、正确着法和原题链接。
- 题目局面需要用游戏里的国际象棋规则把 `pgn` 走一遍得到（同时缓存成 FEN）；轮到黑方走的题，棋盘翻过来，玩家执黑。
- 两步杀：玩家走第一步，对方的应着自动走，玩家再走一步。
- 判对：玩家走的步只要同样是将杀就算对（不一定非得是题库里那一步）。
- 出题顺序按难度分从低到高。
- 之前手写的 7 题（`chess_mates.json`）当作「入门教学」放在最前面，先做这 7 题再进五十题。
- 整合时程序自动验证每一题：复盘后局面合法、正确着法确实将杀；不过的题丢掉并记进整合记录。
