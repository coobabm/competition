# 重构调研 01 · 玩法与爽感（2026-10-22）

状态：调研稿，未改任何游戏代码。
输入：`Design/玩家反馈_改进方案_20261022.md`（F1–F14）、`Design/技能树与自动化_重构设计_v4_20261022.md`（下称 v4）、`Design/ui/lab_v4_prototype.html`、`Documentation/LingGuang-Incremental/策划案v0.2/全流程策划案.md`、`灵光一现_策划案_v1.1.md`；代码（只读）：`XgCatalog.cs`、`XgSim.Epiphany / StageOneTutor / Holdout / Mistakes / Diagnosis / Inbreeding / QualityTraps / Flywheel / AnswerTrace / Brain / StoryPacing / Abilities`、`XgBoard.cs`、`Desktop/XgLabelPage*.cs`、`Desktop/XgLabelGhost.cs`、`Desktop/MiniGames/*`。

一句话结论：**现在玩家在"替 AI 答题"，不是在"教 AI"。** 答题这个动作一旦被自动化，玩家手里就没有别的动词了，只剩买格子。v4 把"答题工厂"修得更顺，但没有换掉这个核心动词。重构要做的是：把"答对题"交给它，把"决定它学什么、找出它哪里学歪、判断它是真懂还是背题"交给玩家——而这些机制代码里其实已经有一半（概念板、双曲线、错题分组、近亲繁殖、抽检陷阱），只是埋在二级页面里，没被做成玩法。

## 1. 诊断

### 1.1 现在的前 30 分钟（按代码与引导步骤还原）

### 1.2 不爽在哪（按维度）

| 维度 | 问题 | 证据 |
|---|---|---|
| **核心动词** | 玩家是"标准答案"，AI 学习只是副作用（答对 = +1 样本）。"教"这个字在操作上不存在：你不能选它学什么、不能看到这一张教了它什么 | `XgLabelPage.cs` 注释：「Right answers pay … and add a sample; wrong ones … are discarded」 |
| **自动化悖论** | 增量游戏的规则是"把你现在的动作交出去，然后给你一个更高层的动作"。这里交出去的是唯一的动作，交完之后上层只有"买格子"和"点训练"。40 个小游戏一旦自动化，全部变成背景收入 | F4/F11/F12 都在抱怨自动化，本质是自动化后没东西可玩 |
| **反馈** | 教会它一张卡，看不到任何变化（只有样本数 +1）；训练一轮 0.6 秒，结果是一个百分比；准确率变化不落到具体的卡上 | `EpochSeconds .6`；双曲线、错题分组在训练页二级区域 |
| **决策 / 权衡** | 第 1 阶段便签只给主线一步（`XgGuide`：no side tasks），等于线性清单；科技树多数节点是"必买"；v4 之前唯一真权衡只有电力 | `TutorLessons` 注释：「the player learns one idea at a time」 |
| **目标** | 每阶段目标是"能力考 6/8"，一个隐藏的样本×参数门槛（`AbilityParamsK {0,0,6,60,400,900,2000}`）。玩家不知道离目标还差在哪，只能"再练几轮" | 老周台词「别光埋头一轮一轮地硬练」——设计自己也承认在硬练 |
| **多样性** | 题型多但动词同一个："选对的那个"。皮肤换了 40 次，大脑用的是同一块肌肉 | MiniGames 目录 |
| **奖励节奏** | 首个 ¥120 需约 100+ 张正确手答（连击帮忙）；之后价格 ×1.55/级、×3/时代，收入线性增长，没有"翻倍"时刻；最大的情绪奖励（涌现）每 30–45 分钟一次，中间空 | `AutoCost`、v4 §4.2 节奏表 |
| **数字** | 金额是 ¥0.75、0.2 题/秒、¥0.2/秒这种量级，涨幅不可感；增量游戏的"数字爆炸"感没有 | `CrowdTierIncome`、`AutoRatePerLevel` |
| **惩罚** | 答错罚 50% 又断连击，鼓励保守与无聊（不敢试） | `HandFine .5`、`ArithFine .5`；F6 高数比常识还便宜 |
| **好东西被埋** | 已有高价值机制但是二级页面、被动显示：概念板（真实可解释的"脑"：特征格、合并概念、朝"是"的权重）、AnswerTrace（每次预测用到了哪些概念）、双曲线（练过的题 vs 新题 = 过拟合）、错题分组（"把 7 认成 1"）、卡住诊断四选一、近亲繁殖（自动错标污染数据）、众包陷阱题、数据飞轮 | `XgBoard.cs`、`XgSim.AnswerTrace.cs`、`XgSim.Holdout.cs`、`XgSim.Mistakes.cs`、`XgSim.Diagnosis.cs`、`XgSim.Inbreeding.cs`、`XgSim.QualityTraps.cs` |

### 1.3 v4 解决了什么、没解决什么

- 解决：自动化可控（槽位）、低准确率也能挂（效率曲线）、定价、技能树可读、电力权衡、开场提速、视觉焦点。这些都该做，是"地基"。
- 没解决：**玩家每秒钟在干什么**。v4 之后，第 2 阶段起玩家手动答题的理由只剩"新桌冷启动""神题""连击加价"。核心十秒仍是是/否点击，或者看槽位跑钱。

## 2. 核心机制概念（8 个）

统一原则：玩家 = 老师 / 调参工程师 / 质检员；AI = 学生 / 工人。**它答题，你出题、挑题、找茬、判断它是不是真懂。** 每个机制都要让"它变了"看得见、落在具体卡片上。

### C1 喂卡看线（数据沙盘 · 决策边界）

- **动词**：从"待标卡池"里挑卡 → 拖进"教它"托盘（或拖进"考它"堆）；可删卡、复制加噪（数据增强）、改标签。
- **画面**：一张 2D 散点板。每张卡是一个点，坐标是两个可读特征（垃圾短信：「含链接」×「感叹号/【】数量」；手写数字：「墨水量」×「有没有闭环」）。模型的边界是一条线 / 一片色区，**每拖一张卡就实时挪动**。拖进去的那一下，测试集里有 N 张卡变色（错→对），飘字「+7 翻对」。
- **爽点**：一张卡带动一片——"四两拨千斤"。挑到关键样本（边界附近的难例）翻对最多；挑到冗余样本几乎不动。玩家自己发现"难例最值钱"=主动学习（active learning）。
- **增量扩展**：第 1 阶段 1 条直线（感知机）；**XOR 之墙在这里是物理可见的**——红蓝十字摆开，你怎么拖线都分不开（AI 寒冬）；买 MLP 后线变成会弯的曲线；第 3 阶段起维度太多画不下，散点板升级成"概念板"视图（已有）。后期由"自动挑卡"科技接管（=主动学习科技），玩家只挑每批里最难的几张。
- **叙事 / ML**：感知机 1958、XOR 1969、MLP 1986、主动学习。老周不再"讲"线性可分，玩家自己撞上。
- **实现成本：M**。散点板用一个自绘 `Graphic`（参照 `XgLabelPreviewGraphic`、`XgTechLinksGraphic`）；特征取自 `XgBoard` 卡片的 raw features，挑两个可读的投影即可；边界用现有 `Predict` 在网格上采样 32×32 着色。只在第 1–2 阶段需要精确，之后切概念板。

### C2 找茬与打补丁（对抗 · 骗子军备竞赛）

- **动词**：**红队**——用碎片拼一条短信 / 涂改一张手写数字 / 换一句弹幕的语气，去骗过它；**蓝队**——把骗过它的样本塞回训练集，补上盲区。
- **画面**：一张"骗它"工作台：短信由词块拼成（「【顺丰】」「您的积分即将清零」「10086」「点击 t.cn/…」「爸，我换号了」），实时显示它的判断与把握条；把握跌破 50% 那一刻，卡片"咔"地翻面，盖上红章「骗过了」。
- **爽点**：Hacknet/黑客式的"我找到漏洞了"；再加"补丁后它反过来识破你上一招"的成长感。
- **增量扩展**：每周（游戏内日历）骗子团伙出新话术（2016 真实：积分兑换、冒充 10086、ETC 过期、猜猜我是谁、"爸我换号了"），自动槽里的垃圾短信桌准确率**开始掉**——"它开始漏判了"。玩家抓新样本 → 补丁 → 收入恢复并超过之前。这是一个可以持续到第 6 阶段的"外部压力源"，后期扩到刷单评论（水军话术）、验证码（12306 图形验证码 2015 年底上线）、标题党。
- **叙事 / ML**：对抗样本（Szegedy 2013、Goodfellow 2014 FGSM）、分布漂移、数据投毒；接市反诈中心订单（`antifraud`）、电商风控（`fakereview`）。终章伏笔：玩家亲手学会了"如何骗过一个 AI"——和"关机规则"那条暗线呼应。
- **实现成本：M**。词块拼句复用 `XgSentenceGame`/`XgPackSwipe` 的拖拽；判断用现有本地 `Predict`（概念板），不需要 LLM；话术漂移 = 定期往 spam 测试分布里注入新特征组合，并让部署准确率按"未覆盖份额"下降（可复用 `Inbreeding` 的"上限扣减"写法）。

### C3 背题还是懂了（过拟合 · 见好就收）

- **动词**：训练不再是"点一下等进度条"，而是**一轮一轮押注**：每轮按「再练一轮」或「就这版，上线」。
- **画面**：已有的双曲线（`XgSim.Holdout`：练过的题 vs 新题）放到训练页中央、做大。练过的题一直往上爬；新题在某个隐藏点之后开始往下掉。曲线分叉时卡片开始"背答案"的小动画（它念出一张练过的卡的原文）。
- **爽点**：推运气（Balatro 的"再出一手"、21 点的"再要一张"）。停在最高点：「恰到好处」金色结算 + 奖金；贪了：新题掉下去，它开始背题，老周吐槽「跟你高三一模一样」。
- **增量扩展**：早停（Early Stopping，现有 `earlystop` 节点）科技 = 自动在峰值停；Dropout/数据增强 = 推迟分叉点、抬高峰值；数据越多越杂，峰越高越宽。玩家能感到每个科技"把赌桌变得更有利"，而不是"+3%"。
- **叙事 / ML**：过拟合、验证集、早停、Dropout 2012。对应已有台词「原来它也会背答案」。
- **实现成本：S**。数据已在 `histVal`/练过的题序列里；只需把训练改成按轮手动推进（自动训练科技后恢复自动），加峰值判定与结算卡。

### C4 错题剧场（它的错误是内容）

- **动词**：翻看它的错题集，给错误"归类"（把 7 认成 1 / 只看感叹号 / 把反话当真话），一类修好时整类一起翻对。
- **画面**：错题像弹幕一样滚过，挑最好笑的弹给 YY 群聊（晴雯、老周、表姐会回）。修好一类错误时，那一类的 23 张卡**一起翻面**（多米诺），收益计数器跳一大截。
- **爽点**：笑点 + "批量清除"的消消乐快感。它的错是它的性格，也是剧情素材（"它把晴雯的自拍认成了表情包"）。
- **增量扩展**：错误类型 = 收集图鉴（已有现象 `ph.*` 图鉴可承载），每阶段的"历史之墙"就是一个修不好的错误类（XOR、长句失忆、定长瓶颈、太慢）——你攒满证据，里程碑模型才亮。
- **叙事 / ML**：误差分析、混淆矩阵、"历史之墙 = 一类结构性错误"。
- **实现成本：S–M**。`XgSim.Mistakes` 已有错误分组与可读名；群聊转发复用 YY 图片 / 斗图消息；"整类翻面"是表现层。

### C5 你在看哪（"给我看看为什么"·捷径学习）

- **动词**：点它的任意一个判断 → 显示它看了哪几个词 / 哪几块像素（高亮热力）；发现它在"抄近路"后，**遮住**那个特征或者喂反例。
- **画面**：短信上「！！！」三个字被烧红，其余灰——它只认感叹号。验证码桌：它看的是背景颜色不是字。表情包桌：它看的是水印"斗图网"。遮掉后准确率先掉、再练回来更高。
- **爽点**：侦探式"原来如此"；看穿它的瞬间像《Return of the Obra Dinn》的推理落锤。
- **增量扩展**：第 3 阶段解锁（视觉线后），后期变成自动"捷径体检"科技；第 5 阶段注意力（Attention）=它自己画热力图，玩家第一次看到它"自己知道该看哪"——直接成为涌现时刻的视觉语言。
- **叙事 / ML**：显著性图（Simonyan 2013）、捷径学习、"坦克与天气"的经典传说（可做老周段子，标注为传闻）、注意力 2015。
- **实现成本：M**。`XgSim.AnswerTrace` 已记录"每次预测实际用到的概念及权重"，文本高亮可直接映射到 `XgBoardElement` 的位置；图像桌用卡片绘制时已知的格子。遮挡 = 训练时屏蔽某特征键。

### C6 课程表（排课 · 直方图对比）

- **动词**：在有限算力（GPU·小时）内排一张"课程表"：先喂哪批、易难比例、复习比例、每批几轮。
- **画面**：横向时间轴上拖数据块（像 Opus Magnum 排指令），跑一次得到三项指标：成绩、耗电、耗时；和"全网玩家"直方图比较（离线生成的假分布即可）。
- **爽点**：Zachtronics 式"我的解更优雅"；可重复优化。
- **增量扩展**：第 3–5 阶段每个大订单（翻译、长句、律所合同）一张课程表谜题；后期"课程学习"科技给出默认解。
- **叙事 / ML**：课程学习 2009、灾难性遗忘（只喂新数据旧能力掉）、学习率预热。
- **实现成本：L**。需要新的排程 UI 和较可信的模拟；建议只做 5–6 个手工谜题而不是通用系统。**列为可选。**

### C7 师徒擂台（人机对决）

- **动词**：同一串卡，你和它同时答，限时 30 秒，比对数与速度。
- **画面**：左右分屏，比分滚动；它赢你的那一局，屏幕停顿半秒，字幕「它比我快了」，然后槽位科技亮起。
- **爽点**：把"顿悟→自动化"从一个看不见的影子计数，变成一场你亲手输掉的比赛——输得心甘情愿，正是交出动词的仪式。后期反过来：神题、棋类里你还能赢它（F7/F8 的"神人"与赢棋奖金接这里）。
- **增量扩展**：每阶段一场"毕业擂台"代替（或包装）能力考 6/8；擂台赢了它 = 它还没学会，输了 = 它毕业。
- **叙事 / ML**：人类基线、2016 AlphaGo 对李世石（游戏内正是这一年）。
- **实现成本：S**。`XgLabelGhost` 已能给出它对当前卡的猜测；擂台就是同屏展示 + 计时。

### C8 电表与夜班（算力 / 电力调度）

- **动词**：分配额定功率给"上班（自动答题）"和"上学（训练）"；2016 民用峰谷电价，夜里训练便宜；夏天显卡过热降频。
- **画面**：v4 的电表 + 一条 24 小时电价带；拖动"夜班训练"窗口。
- **爽点**：Factorio 式"刚好卡满额定功率不超载"的满足感。
- **增量扩展**：v4 的电力线（额定功率 / 省电 / 机房）原样承载；预训练剧情跳闸保留。
- **叙事 / ML**：算力即成本；接电费、房租、晴雯抱怨电脑吵。
- **实现成本：S–M**（v4 P5 已规划，只多一条电价带）。

## 3. 推荐新核心循环

### 3.1 三层循环

```
秒层（3–15 秒）  挑卡 → 拖进「教它」→ 边界/概念板挪动 → 「+N 翻对」→ 槽位收入跳一下
                 （冷启动的新桌：亲手答 10–20 张做种子，之后都是"挑"不是"答"）
        ↓
分钟层（2–8 分钟）三选一的"活儿"同时挂在桌上：
                 ① 客诉/骗子新话术 → 找茬（C2/C5）→ 打补丁
                 ② 训练押注（C3）→ 上线新检查点 → 槽位收入 ×1.3–2
                 ③ 错题剧场清一类错（C4）→ 整类翻面 → 发群聊
        ↓
小时层（25–40 分钟）历史之墙（一个结构性错误类，C1/C4 里看得见）
                 → 攒证据 → 买里程碑模型 → 师徒擂台毕业（C7）→ 涌现演出 → 新能力 / 新桌 / 新角色线
                 v4 六条主线（槽位、准确率、边做边学、速度、单价、电力）在这一层持续花钱
```

动词交接表（自动化悖论的解法）：

| 阶段 | 交给它的动词 | 玩家新拿到的动词 |
|---|---|---|
| 1 | （无，亲手答是/否当种子） | 挑卡喂线（C1） |
| 1 末 | 答是/否（擂台输给它 → 槽位 1） | 见好就收（C3） |
| 2 | 多选一桌 | 错题剧场（C4） |
| 3 | 识图/单词 | 你在看哪 + 找茬（C5+C2） |
| 4 | 挑卡（主动学习科技） | 骗子军备竞赛常态化、课程表（可选 C6） |
| 5 | 训练押注（早停科技）、热力图（注意力） | 调度电力 / 夜班（C8）、大订单 |
| 6 | 几乎全部 | 预训练"喂整个互联网"：选源、清洗、去毒（C1+C2 的终极版），结局抉择 |

### 3.2 六阶段进度弧

| 阶段 | 时长 | 秒层主玩法 | 分钟层 | 历史之墙（看得见的形式） | 擂台/涌现 |
|---|---|---|---|---|---|
| Ⅰ 感知机 | 12–15 分 | 2D 散点板，拖短信卡推直线 | 第一次见好就收 | XOR：十字摆开，线怎么拖都分不开，屏幕变灰"AI 寒冬" | 擂台：是/否 30 秒赛，它赢 → 槽位 1；灯泡自己亮「否」 |
| Ⅱ MLP | 20 分 | 线会弯；手写数字墨水×闭环 | 错题剧场开张（"把 7 认成 1"） | 梯度消失：层数 >4 曲线平掉（C3 曲线直接平） | 认出不在数据集里的"0" |
| Ⅲ CNN+RNN | 30–35 分 | 概念板替代散点板；挑难例 | 你在看哪 + 第一次骗子话术潮 | 遗忘：长句前半句的热力图是黑的 | 自己续诗 |
| Ⅳ LSTM/ResNet | 30–35 分 | 自动挑卡，玩家只挑每批最难 3 张 | 军备竞赛常态化；刷单水军、12306 验证码 | 翻译不了：输入输出长度不等 | 它第一次主动叫你 |
| Ⅴ 注意力 | 30–35 分 | 它自己画热力图，你只核对 | 大订单 + 电力调度 | 太慢：循环不能并行（电表永远红） | 「如果只用注意力呢？」 |
| Ⅵ 自研 | 25–30 分 | 预训练选源：拖网站进"喂它"，每个源带收益与毒性 | 去毒 / 清洗 / 结局相关选择 | — | 终章三结局 |

### 3.3 奖励节奏目标

| 频率 | 事件 | 目标 |
|---|---|---|
| 每 1–3 秒 | 槽位到账浮字、拖卡后翻对计数 | 任何时刻屏幕上都有在动的数字 |
| 每 15–30 秒 | 一次"翻对 ≥5 张"或一次连击档升级 | 第 1 阶段起 |
| 每 60–180 秒 | 一次可买（v4 §4.2 判据：最便宜有效项 ≤ 收入×180 秒，≥85% 时间） | 沿用 v4 |
| 每 5–8 分钟 | 一个分钟层"活儿"完成（补丁上线 / 恰到好处 / 清掉一类错） | 每次收入台阶 ×1.3–2，**要有台阶，不只是斜坡** |
| 每 10–15 分钟 | 叙事揭示（新话术、角色反应、新桌） | |
| 每 25–40 分钟 | 墙 → 擂台 → 涌现 | |
| 每阶段 | 收入 ×5–10（v4 是 ×3，偏保守；建议显示层用"题/秒"与"¥/秒"双数字，让涨幅更显眼） | |

数字建议：前 5 分钟内必须买到第一件东西（现在约 10 分钟+）；手答罚款在 C1 体系下取消（玩家改为"挑"，不再"答错扣钱"），罚款只留给众包抽检剧情。

### 3.4 Juice 清单

视觉
- 拖卡入托盘：卡片吸附 + 0.96→1.04 回弹；边界线弹簧插值（不是瞬移），250 ms。
- 翻对：测试点由红变绿逐个"咔哒"翻面，间隔 20 ms 串成一串；超过 10 张时最后一张放大飘出「+23 翻对」。
- 骗过它：卡片翻面盖红章（旋转 -8°，章边抖 2 帧）；补丁后同一张卡再翻回来盖绿章「识破」。
- 恰到好处：曲线峰值处金色闪光 + 冲击环（复用 v4 购买冲击环）。贪过头：新题曲线变红往下拖出拖尾，卡片念出练过的原文（打字机）。
- 整类翻面：错题墙多米诺倒下，配连击音阶。
- 热力图：从灰到红的扫描显影（像洗照片），600 ms。
- 擂台：分屏比分滚轮；它反超的一瞬间全屏 0.5 秒慢放 + 静音。
- 收入台阶：顶部 ¥/秒 数字换档时"计程表"滚动 + 色温变暖。

声音（2016 桌面质感）
- 拖卡：纸张摩擦；吸附：机械键盘轻击。
- 翻对：音阶递增的短"叮"（Balatro 的连锁上行音阶思路），超过 10 张变和弦。
- 骗过它：老式 QQ"咳嗽"提示音同类的短促音；识破：拨号成功音同类。
- 恰到好处：硬币落罐；贪过头：显卡风扇骤响 + 硬盘"咔咔"。
- 超载：电流嗡 + 灯管闪烁声。
- 涌现：全部环境音抽空 1 秒再进 BGM 新层（BGM 分层随阶段加乐器）。

数字表现
- 所有关键数同时显示"变化量"（+3.2% / +7 翻对 / ×1.4 收入），变化量比总量更大号。
- 大数缩写（万 / 亿）只在第 4 阶段以后出现，前期保持整数元以内的手感。

减少特效：沿用 v4 §6.6 规则；翻对改为静态计数，热力图直接出图。

## 5. 需要负责人拍板的问题

1. **核心动词换不换**
   A. 保持"答题"为核心，只做 v4（低风险，爽感问题基本不解决）
   B. 秒层换成"挑卡喂线"（C1），答题只用于新桌冷启动
   C. B + 分钟层 C2/C3/C4
   **建议 C**，分批上线（先 C3 + C7，因为是 S 成本）。

2. **答错罚款**
   A. 保留 50%　B. 降到 0，只断连击　C. 取消手答罚款，罚款只留众包抽检剧情
   **建议 C**：玩家需要敢试，C1 体系里"答错"本身不再是主要动作。

3. **第 1 阶段散点板用不用真模型**
   A. 用现有概念板 `Predict` 实时算（真）　B. 手工预制每张卡对边界的影响（假但可控）　C. 混合：第 1 阶段预制，第 2 阶段起真算
   **建议 C**：保证开场 10 分钟手感稳定。

4. **骗子军备竞赛的压力强度**
   A. 只给新机会（新话术 = 新订单，不掉准确率）　B. 自动槽准确率会掉，但有下限（最多 −15%）　C. 不处理会持续掉
   **建议 B**：有压力但不惩罚挂机玩家。

5. **训练押注（C3）是否替代自动训练**
   A. 每次都手动押　B. 前两阶段手动，买"早停"后自动并可随时接管　C. 只在大模型训练时手动

   A. 保留考试　B. 改擂台（它赢你 = 毕业）　C. 考试 + 擂台演出包装
