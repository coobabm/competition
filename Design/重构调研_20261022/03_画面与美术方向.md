## 0. 一句话结论

画面显得“AI 做的”，主要不是因为某一张图画得差。根本原因是**没有一个统一的视觉主张**：写实 3D、写实 AI 照片、半写实 AI 肖像、苹果风圆角图标、Win7 玻璃和赛博 HUD 混在一起，每一类素材都停在“生成器的默认审美”上。
建议的主张是**「人的 2016」与「机器的荧光」两个世界**：
- 桌面这一侧做成**真实、杂乱、温暖的 2016 中文互联网**；
- len.exe 这一侧做成**严格限色、带扫描线和点阵的荧光终端**；
- 两边之间的**切换**（实验室全屏）就是全作的招牌特效。

## 2. 三个可选方向

### 方向 A「2016 · 真桌面」：写实怀旧，把年代感做实

- **主张**：这台电脑就是 2016 年你表哥的电脑。所有东西都应该像当年真有人用过：杂乱、低分辨率、JPEG 压缩痕迹、非主流头像。
- **参考**：Hypnospace Outlaw（虚构年代互联网的完整性）、Emily is Away（真实 IM 质感）、Simulacra / Sara is Missing（手机界面恐怖片的“真”）、Her Story（桌面即叙事）；现实素材取 2016 年的 QQ2016 / YY8、百度贴吧 2016 版、淘宝 2016 年橙色、暴风影音、酷狗。
- **调色**：Win7 系统色

| 令牌 | Hex | 用途 |
|---|---|---|
| aero.glass | `#BFD9F2`（α 0.55） | 窗口框 |
| aero.title | `#1E395B` | 标题字 |
| taskbar | `#0F2236`（α 0.85） | 任务栏 |
| select.fill / border | `#CBE8F6` / `#26A0DA` | 资源管理器选中 |
| hover.fill / border | `#E5F3FB` / `#70C0E7` | 悬停 |
| win.bg | `#F0F0F0` | 对话框底 |
| taohuo.orange | `#FF5000` | 淘货 |
| yy.yellow | `#FFC300` | YY |

- **字体**（均可商用）：思源黑体 / Noto Sans CJK SC（OFL）作为“微软雅黑替身”，正文 12px；文泉驿点阵正黑用于 12px 像素级系统字（GPL + 字体例外，可嵌入）。**不能**随游戏分发微软雅黑或宋体。
- **图标规则**：3/4 透视的实物剪影，不加底板；规格 48/32/16 三档，16px 逐像素修整；左上方光源。
- **动效/特效**：Win7 原生节奏，窗口开合 150ms 缩放加淡入、Aero Peek、任务栏缩略图。不加 bloom，“真”本身就是效果。
- **3D 房间**：保持写实，多加生活痕迹（便利贴、充电线、泡面盒）。
- **2016 桌面**：本方向的主战场。
- **AI 实验室**：做成 2016 年真实的开发工具风格，参照 VS2015 Dark、Caffe 终端、`nvidia-smi`、TensorBoard 0.x 和 matplotlib 默认配色。全屏也只是“窗口最大化”。
- **AI 素材怎么处理**：
  - 头像全部换成 2016 风格：猫狗、风景、动漫截图、非主流字图，用 AI 生成加 64px 降采样也行，因为观感就是低清；
  - 新闻和教学图统一过一层“2016 网页 JPEG”滤镜：缩到 160×120 或 400×300，JPEG 质量 55，轻锐化加 0.5px 色偏；
  - 商品图改用 3D 房间里的模型渲染，或者用 CC 授权的真实照片。
- **成本**：低到中。约 30 个图标外包重绘，按每个 ¥150–400，或由一名像素/图标美术做 1–2 周；滤镜脚本约 1 天；头像库约 2 天。
- **风险**：不够“酷”，商店缩略图冲击力弱。

### 方向 B「荧光管」：CRT 磷光终端，机器的视角

- **主张**：玩家看到的是 AI 的感知。屏幕上的一切都受荧光管的物理限制：一种主色、点阵抖动、扫描线、余辉。
- **参考**：Return of the Obra Dinn（1-bit 加抖动的限色纪律）、NieR:Automata 黑客与终端界面、Analogue: A Hate Story / Hate Plus（终端里的 AI 叙事）、Alien: Isolation 的终端、Inscryption 第三幕、Hotline Miami（强对比与节奏感）、《黑客帝国》的绿雨（只取其意，不照抄）。
- **调色**（P1 绿磷，延续现有薄荷绿）

| 令牌 | Hex | 用途 |
|---|---|---|
| phos.bg | `#050807` | 底 |
| phos.panel | `#0A100E` | 面板 |
| phos.dim | `#1F3A31` | 网格、未激活 |
| phos.mid | `#3FAF88` | 次要字 |
| phos.main | `#5FE3B5` | 主色（即现 XgDark.Accent） |
| phos.hot | `#C9FFE9` | 高亮、余辉 |
| warn.amber | `#F2C46D` | 钱、警告（唯一的第二色） |
| err.red | `#FF6E5E` | 只用于错误 |

- 去掉现在的紫色 `#A594FF` 和蓝色 `#6AB8FF`，参数和样本两条线改用实线与点线来区分。
- **字体**：更纱黑体 Sarasa Mono SC（OFL，中英等宽，承担终端主字体）；缝合像素字体 Fusion Pixel Font 12px，或方舟像素字体 Ark Pixel（OFL），用于 HUD 标签和大数字；JetBrains Mono（OFL）作为纯数字备选。
- **图标规则**：16×16 或 12×12 单色像素字形，不加底板和描边，状态用反色块表示。现有 186 个 `Icons/tech/*` 全部改成程序生成或手绘的字形。
- **动效/特效**：
  - 文字以 60 字/秒逐字打出，用 steps() 而不是缓动；
  - 数值变化做成翻转加 80ms 余辉拖尾；
  - 购买成功时整行反色闪 2 帧；
  - 全屏进入时做 CRT 开机动画：一条亮线展开，接 200ms 抖动后定格；
  - 后处理只在实验室开启：扫描线（强度 0.06）、Bayer 4×4 抖动（只作用于图片）、轻微桶形畸变（0.02）、余辉。
- **3D 房间**：显示器的屏幕材质换成磷光自发光。AI 苏醒越深，显示器荧光越往房间里溢出，台灯的暖光相应被压低。这是可以随剧情推进的视觉曲线。
- **2016 桌面**：保持 Aero 不动，但 AI 的“痕迹”以磷光像素的形式侵入：光标拖影、窗口边角出现绿色噪点。
- **AI 实验室**：本方向的主战场，做成**全屏**，取消圆角卡片，改为表格加细线加大号像素数字。
- **AI 素材怎么处理**：所有照片进入实验室前都过 2 色或 4 色有序抖动（`phos.bg` 到 `phos.main`），AI 的糊和塑料感会被完全吃掉；肖像也可以统一抖动。
- **成本**：低，并且**最省美术**。CRT/抖动 Shader 约 2–4 天（项目是 URP）。注意 uGUI 的 Screen Space - Overlay 不吃后处理，需要把实验室 Canvas 改为 Screen Space - Camera，或渲染到 RT 后再套 Shader。像素字形约 1 周。
- **风险**：过度使用会伤可读性，必须遵守“效果预算”；另外这类“赛博终端”同质化较多，要靠限色纪律做出差异。

### 方向 C「纸灯剧场」：手作拼贴与舞台光

- **主张**：整部游戏像一出在小房间里上演的舞台剧。平面化、几何化，靠舞台灯区分情绪，插画使用手绘线条加孔版印刷的套色。
- **参考**：Kentucky Route Zero（平涂几何与舞台光）、Disco Elysium（油画质感与报纸式 UI）、Citizen Sleeper（手绘人像加冷静 UI）、Night in the Woods；平面设计参考 1980–90 年代中国科普杂志、《新周刊》、Risograph 孔版印刷。
- **调色**：纸 `#EDE6D6`、墨 `#1C1B1A`、孔版红 `#E2483D`、孔版蓝 `#2F5AA8`、荧光绿 `#3FE0A0`、暗夜 `#151821`。
- **字体**：霞鹜文楷 LXGW WenKai（OFL）用于叙事和旁白；得意黑 Smiley Sans（OFL）用于标题；思源宋体（OFL，已在用）；站酷高端黑（免费商用）。
- **图标规则**：手绘墨线，套 1–2 色，故意错版 1–2px。
- **动效/特效**：纸片翻页、剪影切换、舞台追光，“灯光变化”替代 UI 发光效果。
- **3D 房间**：改为 flat-shaded 低多边形加手绘贴图，用强烈的舞台光（KRZ 式）。
- **2016 桌面**：难以兼顾 Aero 的真实感，只能把桌面也“舞台化”，这会削弱怀旧卖点。
- **AI 实验室**：做成黑底加孔版绿的“报纸式”信息版面。
- **AI 素材怎么处理**：全部重绘，或者把 AI 图当作底稿描线后再套色。
- **成本**：高。需要一名插画师 6–10 周（约 80 张人像和内容图），3D 场景还要重做贴图。
- **风险**：工期最长；与“鸿蒙 Aero 桌面”的核心梗冲突。

## 3. 推荐：A × B「两个世界」

用 **A 做人的世界**（桌面和应用），用 **B 做机器的世界**（len.exe 和全屏实验室）。3D 房间是两者的交界：台灯（人）对显示器磷光（机器），画面比例随剧情推进而变化。
理由：
1. 主题本身就是“电脑活了”，两套视觉的对立就是叙事；
2. 方向 B 的抖动和限色可以低成本地“洗掉”AI 图的塑料感；
3. 方向 A 让怀旧卖点更真；
4. 都不需要长期插画师。

### 3.1 风格指南骨架

**颜色令牌**（建议在 `XgUi.cs` 旁新增唯一的 `UiTokens`，禁止在其他地方写颜色字面量）

```
// 人的世界 Human / Aero
h.bg.dialog   #F0F0F0   h.text        #1E1E1E   h.text.muted  #6D6D6D
h.title       #1E395B   h.glass       #BFD9F2@55%  h.taskbar   #0F2236@85%
h.sel.fill    #CBE8F6   h.sel.border  #26A0DA   h.hover.fill  #E5F3FB
h.link        #0066CC   h.brand.taohuo #FF5000  h.brand.yy    #FFC300
// 机器的世界 Machine / Phosphor
m.bg          #050807   m.panel       #0A100E   m.dim         #1F3A31
m.mid         #3FAF88   m.main        #5FE3B5   m.hot         #C9FFE9
m.warn        #F2C46D   m.err         #FF6E5E
// 交界 Room
r.lamp        #FFB55A   r.wall        #2A211B   r.phos.spill  #5FE3B5
```

规则：机器侧每屏只用 `m.main`，`m.warn` 只用于钱和警告，`m.err` 只用于错误，不出现第四种色相。

**字号刻度**（8 档，取代现在的 25 种以上）

| 档 | px | 人侧 | 机器侧 |
|---|---|---|---|
| xs | 11 | 状态栏、时间戳 | 像素标签（Fusion Pixel 12px 缩放到 11 档位） |
| sm | 12 | 正文（Win7 默认 9pt） | 表格正文 |
| md | 14 | 窗口标题、YY 消息 | 主正文 |
| lg | 16 | 应用标题 | 小节标题 |
| xl | 20 | 少用 | 关键数值 |
| 2xl | 28 | — | 收入、模型名 |
| 3xl | 40 | — | 全屏大数字 |
| 4xl | 64 | 标题房间 Logo | 阶段转场字 |

字体：人侧用思源黑体（或保留 MiSans，二选一）；机器侧用 Sarasa Mono SC 加 Fusion Pixel；叙事用思源宋（已有）。删除 Inter、OpenSans、Roboto Mono，Noto 只保留一处。

**间距**：4 的倍数（4 / 8 / 12 / 16 / 24 / 32 / 48）。

**圆角**：人侧，按钮 3、窗口 6；机器侧一律 0。

**组件清单**：
- 人侧：Win7 窗口框、按钮（常态/悬停/按下/禁用）、标签页、列表行（选中/悬停）、气泡（YY）、商品格（淘货）、托盘气泡。
- 机器侧：终端行、表格行（反色选中）、数值大字、进度条（字符式 `█▓▒░`，或 2px 实线）、命令按钮（`[ 训练 ]` 方括号样式）、日志流、全屏 HUD 角标。
- 交界：全屏切换（CRT 开机或关机）、AI 侵入特效（磷光噪点）。

**效果预算**（建议扩展现有的 `UiEffectBudgetChecks`）

| 效果 | 人侧 | 机器侧（窗口） | 机器侧（全屏） |
|---|---|---|---|
| Bloom / 外发光 | 0 | 仅 `m.hot` 文字，1 处 | 强度 ≤0.3，阈值 0.8 |
| 扫描线 | 0 | 0.04 | 0.06 |
| 抖动 | 0 | 仅图片 | 仅图片 + 背景 |
| 桶形畸变 | 0 | 0 | 0.02 |
| 色差 | 0 | 0 | 仅转场的 200ms |
| 同屏动效 | ≤2 | ≤3 | ≤4 |
| 动效时长 | 150/200ms 缓动 | steps，80/160ms | 同左 |

### 3.2 资产替换计划（按曝光度排序）

## 4. 待老板确认的问题

1. **总方向**
   - 选项：A 真桌面 / B 荧光管 / C 纸灯剧场 / A×B 混合。
   - **推荐 A×B。**
2. **实验室是否改成全屏独立模式**
   - 选项：①始终全屏 ②窗口和全屏可切换（F11，现已有入口）③保持窗口。
   - **推荐②，默认窗口，首次解锁“走向专长”时强制全屏一次，作为高光时刻。**
3. **磷光主色**
   - 选项：绿磷 `#5FE3B5`（延续现状）/ 琥珀 `#FFB000` / 白磷 `#E8F0FF`。
   - **推荐绿磷，与现有资产和 Logo 一致。琥珀只保留给“钱”。**
4. **AI 生成素材的总体政策**
   - 选项：①全部替换为人工或真实素材 ②可以保留，但必须经过统一滤镜（2016 JPEG / 抖动）且不出现文字 ③维持现状。
   - **推荐②。** 商店的 AI 声明照常保留；头像和商品图优先换掉。
5. **头像风格**
   - 选项：①真人写实（现状）②2016 网友式（宠物、风景、动漫、字图）③统一插画。
   - **推荐②。** 最便宜也最有年代感，老周等主角可以例外。
6. **图标重绘的执行方式**
   - 选项：①外包 Win7 风格图标约 25 个，预算约 ¥5k–8k ②自己用矢量工具做 ③保持素材包加 AI 图标。
   - **推荐①**，桌面图标是曝光最高的 UI 资产。
7. **CRT 后处理强度和开关**
   - 选项：①默认开启并提供“减少特效”开关（现已有 R 键入口）②默认关闭 ③不做。
   - **推荐①**，同时遵守上文的效果预算表，并让“减少特效”一键关闭扫描线、畸变和余辉。
