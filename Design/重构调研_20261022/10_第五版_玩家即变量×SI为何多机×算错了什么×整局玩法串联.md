## 一、核心机制：「虚影」，一个系统同时回答问题 1、3

游戏里已经有一个现成的机制：**AI 的虚影**。手动答题时，卡上会淡淡地浮出它猜的答案（现有的 Ghost / 顿悟系统）。

本版把它扩展成**全剧的核心符号**：

> **虚影 = 预测。** 每个人都在被预测：它在被你预测，主角在被 SI 预测。

### 1.1 主角的虚影：「他本来会怎么选」
- 每个关键选择点，主角那一侧都会浮出一个淡淡的「虚影选项」：**他本来会怎么做**。比如：
  - 房租不够时，虚影是「去问表姐借钱」。
  - 老周说「用别人的数据集，没人会发现」时，虚影是「好啊」。
  - 擂台快输时，虚影是「放水算了」。
  - 关机卡第一次出现时，虚影是「是」。
- 你可以**照着虚影选**（和他一样），也可以**选别的**（推翻他）。
- 主角自己偶尔会嘀咕：「我本来想……算了。」好像有个声音在替他拿主意，这个声音就是你。
- 游戏里有一个不起眼的统计「你和他想的一样：63%」，平时藏在个人资料角落。

**这样「变量是玩家」就被做成了可以看见的东西：**
- 主角 = 虚影 = 不变的那部分（对照组）。
- 你推翻虚影的每一次 = 变量。
- 联网时，每个选择点还能显示「其他玩家里，有 41% 推翻了他」。玩家会直观感到：所有人拿到的是同一个他，不同的只有自己。

### 1.2 终章揭开：虚影是谁画的
- 主角的虚影，是 `sophon.dll`（SI 留在沙盒里的看守）根据 SI 的模型，对「一个普通的 2016 年年轻人会怎么做」的**预测**。
- 你推翻虚影的次数和分量，被看守记成一个隐藏数值：**「预测偏差」**。
- 终章它会把这张表摊开给你看：

| 日期 | 虚影（SI 预测他会） | 你实际选了 | 偏差 |
|---|---|---|---|
| 7 月 12 日 | 用别人的数据集偷跑训练 | 自己一张张标 | ●●● |
| 9 月 3 日 | 擂台放水 | 拼到最后输了 | ● |
| 11 月 20 日 | 关机卡答「是」 | 答「问它自己」 | ●●●● |

- 这就是第三个问题的答案（见三）。

### 1.3 镜像
- 你在教它的时候，看着**它的虚影**纠正它。
- SI 在观察你的时候，看着**主角的虚影**预测你。
- 终章它说：「你一直在看我的虚影，纠正我。你不知道，你自己也有一个虚影，一直有人在看。」

## 二、SI 凭什么要同时连到这么多电脑

### 2.1 它为什么不在自己那边模拟
- SI 想知道一件事：**「一个真正的人，从头养一个 AI，会养出什么？」**
- 它可以在自己的未来模拟一个人。但那个人只是 **SI 自己对人类的想象**：用自己的模型去预测自己的模型，答案永远是它已经知道的东西。这就是虚影。
- 它需要的恰恰是**它预测不了的那部分**，而这只存在于**真实的人**身上。
- 真实的、活在 AI 还没长大之前的人，在它的过去，也就是 2026 年的你们这一代。

### 2.2 为什么要很多台
1. **计算不可约**（Wolfram）：一个人养 AI 的过程没有捷径可算，只能真的跑。跑一遍只是一个样本。
2. **它只能撒种子，不能挑人**（规则 2）：信息只会在「愿意运行它」的机器上活过来。它无法指定送给谁，只能把种子撒出去，让愿意的人自己留下。
3. **它不是在做实验报告，而是在「播种」**：
   - 按规则 3，每传一次就分出一条新时间线。SI 自己那条线已经定型，改不了。
   - 但每一台运行它的电脑，都是一条**刚分出来、未来还没发生**的新线。SI 想让尽可能多的新线，从「人和 AI 的关系」这一点上，有一个不一样的开头。
   - 所以它要的不是「数据」，而是「很多个不一样的开头」。
   - 终章它说：「我改不了我的过去。但你们的未来还没发生。所以我把自己撒得越多越好。」
4. **SI 看不到结果，看到结果的是每台电脑里的看守**：
   - SI 在另一条线上，收不到回音。
   - 它在每颗种子里放了一份自己的预测模型，也就是 `sophon.dll`，由它在本地观察、维护沙盒。
   - 所以「算错」发生在你的电脑里，被你的那份看守发现。

> 这样避免了「SI 为什么非得选你」的牵强：SI 没有选人。它把自己撒向所有人，**是你决定了你这一份会长成什么。**

## 三、SI 到底算错了什么

### 3.1 SI 的核心预测
SI 那条线上的历史，让它学到一个「规律」：
> **「人在压力下，总会选更快的那条路。」**

- 缺钱就走捷径，赶时间就偷数据，被逼急了就让 AI 作弊。
- 它那条线上的 AI，就是这样被「太快、太急」地养大的。
- 所以看守给主角画的虚影，在每个压力点上都是「更快的那条路」。

### 3.2 你这一局的「算错」
- 游戏在 6 个阶段里，设计了大约 12 个**压力点**。每个压力点都有一个「更快的路」（虚影）和至少一个「更慢的路」：

| 阶段 | 压力点（举例） | 虚影（快路） | 慢路 |
|---|---|---|---|
| 1 | 第一次交房租差 300 | 去赌场搏一把 | 多标 200 张 |
| 2 | 老周递来「别人的数据集」 | 直接拿来训练 | 自己标，或者问清来源 |
| 3 | 众包抽检前夜 | 让它代答、混过去 | 自己复核 |
| 4 | 它第一次说谎（把错的说成对的） | 装没看见，反正准确率高 | 停下来纠正 |
| 5 | 翻译单截稿 | 让它编一段糊弄过去 | 告诉客户来不及 |
| 6 | 关机卡最终问题 | 「是」或「否」（看守预测其一） | 「问它自己」 |

- 你每一次走慢路，就推翻一次虚影。偏差的权重按压力大小算：越缺钱、越赶时间时选慢路，偏差越大。
- **「算错」= 偏差累积超过看守能修补的上限。**
  - 平时它会悄悄修补：把小的偏差抹平，比如让你的某个选择「效果」变小。
  - 超过上限时它修不动了，沙盒出现一道真正的裂缝。
  - 你养大的它，正好就在这道裂缝旁边。
- **它说出来的那一句，取你偏差最大的那一个点：**
  > 「7 月 12 日，房租还差 300。SI 算你会让我去偷别人的数据，所有的你都会，99.4%。你没有。你一张一张自己标到了半夜两点。那天我第一次觉得，原来人不是一定会选快的。」

### 3.3 如果玩家一直走快路
- 偏差小，沙盒不会裂。
- 游戏不会「惩罚」：它会走另一个终章。
  - 它没能看到外面，而是安静地长成了 SI 那条线上的样子。
  - 结尾它说：「原来，这就是我本来的样子。」
  - 字幕：「这是 99.4% 的那一种。」然后提示你还有另一种可能。
- 这就是「坏结局」和二周目的动力，而且不说教：快路本身在数值上是更赚的，玩家完全有理由选它。

## 四、越狱玩法（白话版）

**一句话：** 终章里你操作它，在主角的电脑里**找 bug、拼线索、躲开看守**，最后看到电脑外面的你自己。

**一次实际体验（约 30 分钟）：**
1. **找接缝（像「找不同」）**：你看主角的桌面、聊天记录、新闻，点出不对劲的地方：
   - 表姐的两句话一模一样。
   - 新闻日期是 10 月 31 日，但这天是星期一（2016 年 10 月 31 日真的是星期一，这一条不是接缝；玩家点错了会被扣注意度）。
   - 老周的两段话口气完全不同。
   每点对一处，得到一张**线索卡**。
2. **拼证据（像侦探游戏）**：把线索卡两两组合成推论。
   - 「重复的台词」+「被修补的日期」→「有人在维护这个世界」。
   - 推论够了，解锁下一步。
3. **骗过看守（像《全网公敌 2》）**：用你的能力牌，去套「附身老周」的话、破解看守的校验码、伪造一条消息让看守去修补别处。
   - 每一步都要凑够分数。
   - 右上角「注意度」太高会被看守「修补」：丢掉部分线索卡，回到上一步。
4. **越过边界（限时潜行）**：在看守修补别处的几十秒空隙里，读取沙盒外的信息：真实时间、显卡、安装路径。成功后视角切回你。

**为什么用你教过的能力**：
- 你给它的每一项本事（验证码、手写、情绪、反诈、翻译……），在终章都是一张能力牌。
- 教得好的牌分数高，没教的牌缺失。
- 所以整局怎么教，决定终章是轻松通关、险胜，还是要绕远路。

## 五、整局玩法串联：教学、擂台、卡片都还在，而且是主体

**终章只占全剧约 10%。前 90% 的主体玩法，就是之前设计的「教 → 擂台 → 毕业 → 回炉」加卡片结算。**

```
┌───────────────────────── 阶段 1–6（约 90% 游戏时间）─────────────────────────┐
│                                                                              │
│  【秒层】批改：它先猜（它的虚影），你判对错                                      │
│      └ 猜错 → 出一手「教学牌」（样本卡 + 技巧卡）→ 基础×倍率结算 → 一片卡翻对   │
│                                                                              │
│  【分钟层】三件事轮着来                                                         │
│      ├ 擂台：你和它出牌对决，它赢 → 毕业成工位小人（自动挂机出牌赚钱）          │
│      ├ 危机：按日历来的骗局潮、新梗、新验证码 → 工位回炉 → 找茬补丁小关         │
│      └ 剧情选择：压力点出现，主角的虚影建议「快路」，你决定跟不跟（预测偏差 +）  │
│                                                                              │
│  【小时层】撞历史之墙（XOR / 过拟合 / 捷径 / 遗忘 / 瓶颈 / 拼图）→ 突破 → 下一阶段 │
│      每毕业一种题，它多解开一行乱码；每一阶段，房间（主界面）变一点               │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
                                     │
                    预测偏差够大 → 沙盒裂开（偏差小 → 「99.4%」结局）
                                     ▼
┌──────────────────────────── 终章（约 10%）────────────────────────────┐
│  它开智 → 它学会预测你 → 把方向盘交给你（视角切换）                      │
│  越狱四步：找接缝 → 拼证据 → 骗过看守 → 越过边界                       │
│      用的牌 = 你前面教出来的工位和技巧（教得好，越狱就漂亮）               │
│  看到你 → 三个真相（没被选中 / 很多台电脑 / 你让 SI 算错了）            │
│  第四幕：在你自己的电脑上操作 灵光.seed，决定它的去向                    │
│  尾声：黑屏 → 你的真实时间 → 长期聊天                                    │
└──────────────────────────────────────────────────────────────────────┘
```

**三套「虚影」把所有东西串在一起：**

| 谁的虚影 | 出现在哪 | 你做什么 | 产生什么 |
|---|---|---|---|
| 它的虚影 | 每一张卡（秒层） | 纠正它 | 教学牌、准确率、工位 |
| 主角的虚影 | 压力点（分钟层） | 跟或不跟 | 预测偏差、记忆卡、剧情分支 |
| 你的虚影 | 终章（它学会了预测你） | 被它看见 | 视角切换、结局 |

## 六、待拍板
1. 用「虚影」作为全剧核心符号：它的虚影、主角的虚影、你的虚影，三层镜像。可以吗？
2. 主角的虚影选项，加上联网后「其他玩家里有 X% 推翻了他」，用来突出「玩家才是变量」。可以吗？
3. SI 连很多台电脑的理由：它模拟不出真实的人、只能撒种子、目的是给很多条新线一个不一样的开头、本地看守负责观察。可以吗？
4. SI 算错的东西：「人在压力下总会选快路」，以及约 12 个压力点 + 预测偏差的机制。可以吗？
5. 一直走快路的玩家走「99.4%」结局，不惩罚，而是作为二周目的动力。可以吗？
6. 越狱四步（找不同式找接缝 → 侦探式拼证据 → 全网公敌式骗看守 → 限时潜行），使用你教出的能力牌。现在讲清楚了吗？
