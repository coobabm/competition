# 突发事件计时与结果验证（2026-10-19）

依据第七轮和用户本次两个 A 确认：只有整个 Windows 游戏最小化才因最小化停表；当前可用事件用完再循环，新解锁事件优先。此批不重写事件故事内容和奖励数值。

## 已实现

- 购买训练曲线后累计 480 秒活跃时间；结果点“知道了”之后重新计时。当前存档可选 8 分钟、15 分钟、关闭；切换间隔从完整新间隔起算，关闭不吞掉已经打开的选项或结果。
- 删除每阶段两次上限和换阶段重置计时。保留日期、阶段、前置与冷却；永久历史和选择标记不清空，单独记录当前轮已出现事件，新符合条件且从未出现的优先。
- 结果中英文文本和已结算状态进入存档；选择/结果确认通过原 SaveNow 保存钱包与实验室状态，重载只展示结果，不再付款。旧卡回调不能操作另一存档。
- Windows 当前进程 HWND 经 PID 和 UnityWndClass 校验后查询 IsIconic；内部 AI 窗口隐藏、失焦、普通长帧继续计时。已观察到最小化/暂停后的首恢复帧不补记暂停时间。
- 剧情冲突暂停事件时钟；到期冲突在结束后额外等 30 秒。即使升阶分支跳过 Sim.Tick，仍能记录到期冲突。借款返还、临时增益等 lifeClock 保留原行为。
- YY 群预设协程停止/恢复和换档用 owner/generation 隔离，旧协程 finally 不会清掉新一轮状态。

主要文件：`XgSim.LifeEvents.cs`、`XgSim.LifeData.cs`、`XgLifeEventCard.cs`、`XingGuangController.cs`、`XgLifeHostActivity.cs`、`DesktopBridge/PlayerWindowState.cs`、`YYChatHub.GroupPresets.cs`、`CaseMenuController.cs`、`CaseMenuHud.cs`。
