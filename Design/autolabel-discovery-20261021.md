# 自动答题隐藏节点修复

用户截图中提示“也许有更省力的办法”的节点为 label.auto。旧发现条件为模型预测连续与玩家一致 8 次，或见过预测后累计 150 次手动答题。小游戏通过 SettleMiniAction 结算，没有进入普通题的 ObserveGhost 计数路径，长期只玩小游戏可能始终无法发现。

现改为普通题连续 3 次与模型预测一致，或见过预测后累计 12 次有效手动答题；超时不累计。小游戏在模型已能给出预测或已有合格检查点后，累计成功手动题作为同一保底进度；不会伪造模型一致次数。小游戏的错误与超时共用结算状态，因此仅答对计数，自动作答和重复提交不增加进度。

保持开场保护、发现演出及已解锁存档状态，购买仍需开放题包的准确率至少 60% 检查点。题包阶段和价格不变。

专项 18 项测试通过，包括 BeginOpening → 手动题 → TrainEpoch 生成检查点 → 发现 → 购买，以及 BeginMiniGame → SubmitMiniGame 的正常交互 API 路径。额外验证真实 SpiderDragPeek/SpiderDragPress 连续自动作答不累计，超时打断连续但保留有效累计。随后纳入 Unity Editor 回归；不以直接修改进度字段代替正常流程验证。
