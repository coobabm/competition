# 「练」页教学指引 + 知识卡 + 科技树文案简化

> **更新**：开局顺序（科技先于练、「训练曲线」解锁练页）、「教」页逻辑、{名字}代答、脑子窗口、数据包进教页、知识卡存进图鉴，以《开局流程简化_教练科技》为准。本文第三节知识卡内容、第四节科技文案继续有效。

> 现状（截图）：「练」页一打开就有二十多块信息：能力进度、四个页签、装备格、账本、模型行、数据行、答卷、曲线、权重示意、风险、学习率六档、训练按钮、两行状态。玩家第一次看不懂，也不知道这一页和「教」有什么关系。
>
> 做法：
> 1. **开局全部锁住**，只开「教」。
> 2. 「练」页第一次打开时**几乎是空的**，只有一个按钮和一张答卷。
> 3. 其余每一块都要在「科技」里买，或者撞到对应的事件才出现。买一样，页面多一块。
> 4. 第一次撞上过拟合、练崩（NaN）等现象时，**弹出知识卡**讲清含义，并收进成就页。
> 5. 科技树的说明只留确定的描述。
>
> 玩家每一步都知道：现在多出来的这一块，是自己买的，是干什么用的。整页拼完，玩家也就懂了「训练」是怎么回事。

## 一、开局：只有「教」

| 时刻 | 界面 | 「我」的台词（独白气泡） |
|---|---|---|
| 第一次打开 .exe（设置完名字后） | 左栏只有「教」可点；「练」「科技」「{名字}」灰色带锁，悬停显示「还没开」 | — |
| 「教」页第一次出现 | 题桌只有「常识判断」 | **这又是什么鬼？我难道要做题吗？** |
| 答完第 3 道 | — | **这都是什么弱智题目？有什么意义啊？** <br>（停 1.5 秒）**先做完再说吧。** |
| 答完第 4 道（够 `SamplesToTrain = 4`） | 「练」解锁：灰色变亮，图标轻跳一下，带一圈光（《动效策划》D3） | **「练」？……练什么？** |

规则：
- 这四道题之前，不出现任何关于训练、模型、AI 的说明。玩家只是在做题。
- 「练」解锁时不自动跳转，只点亮。玩家自己点进去。

- 答卷里的四道题，**就是玩家刚才在「教」页亲手答的那四道**，原文照搬。

**第一次按「训练一轮」**

- 答卷逐行翻牌：每道题后面出现「它答 是 / 否」和 ✓ / ✗。
- 答卷上方出现一个数：**答对 3 / 4**。

| 时刻 | 「我」的台词 |
|---|---|
| 第一次翻完答卷 | **……它在答我刚才答的题？** |
| 停 1 秒 | **所以那几道弱智题，是在教它。** |
| 第一次 4 / 4 全对 | **全对了。……可这几道我都告诉过它答案啊。** |

最后一句是「过拟合」的伏笔，也是「为什么要考新题」的动机（见 2.2 的 T2）。

**「科技」解锁**：第一次训练完，「科技」亮起，右侧显示「可买 N」。台词：**还能买东西？**

## 三、知识卡：第一次撞上，就弹一张

### 3.1 形式

- 触发时：训练暂停（自动训练也暂停），屏幕中央弹出一张竖卡，背景压暗，曲线上对应位置用光圈圈出来。
- 卡片三段：**名字**（大字，带英文原词）、**你刚才看到的**（一句，指着曲线）、**这是什么 + 怎么办**（两三句）。
- 按钮：「收下」。点后卡片缩小、飞进左栏「{名字}」页图标里（成就页），图标冒红点。
- 成就页（现有卡册 `XgCardsPage`）新增一个页签「知识卡」。卡背是灰色问号，收到后翻面。
- 同一张卡只弹一次。

### 3.2 卡片清单

| 卡 | 触发条件（第一次） | 你刚才看到的 | 这是什么 · 怎么办 |
|---|---|---|---|
| **过拟合**<br>Overfitting | 有了「新题」线后，练过的题比新题高出 15 个百分点以上 | 实线一路往上，虚线却停住了，中间拉开一大片红。 | 它把练过的题背下来了，换道新题就不会。这就是**过拟合**，行内也叫「背答案」。<br>办法：多给它新题；或者在科技里买「随机失活」。 |
| **练崩了**<br>NaN | 一轮训练「炸了」（失稳） | 曲线断了，屏幕上一串 NaN。 | 一步改得太猛，它脑子里的数全乱了，算出来不是数（Not a Number）。<br>办法：步子换小一档；点「回档」退回上一次最好的那版。 |
| **退步** | 第一次分数比上一轮低 | 曲线往下掉了一格，标了红点。 | 这一轮练完反而考得更差了。正常现象，学会的能力不会丢。<br>办法：接着练；有「检查点」可以回档。 |
| **天花板**<br>Ceiling | T5 事件触发时 | 曲线贴着灰色虚线，怎么练都上不去。 | 这颗脑子最多就能考这么多分。再练也没用。<br>办法：换更大的脑子（科技里加深、加宽，或换结构）。 |
| **步子太小** | 选「稳」档连续 5 轮几乎不涨 | 曲线几乎是平的。 | 步子太小，走得太慢。行内叫**学习率**太低。<br>办法：换「中」档。 |
| **错题**<br>Noisy labels | 题库里错标的题第一次超过 20 条 | 「下降风险」里出现「噪声」。 | 题库里有标错答案的题，它照着学就学歪了。<br>办法：挑错（数据清洗）。 |
| **顿悟**<br>Grokking | 新题分在一轮里跳升 10 个百分点以上 | 虚线突然往上跳了一大截。 | 它憋了很久，忽然「想通了」。行内叫**顿悟**，到现在也没人完全说清为什么。 |
| **加层没用了**<br>Vanishing gradient | 阶段 2 的墙（层数超过 4 不再涨） | 加了层，曲线还是平的。 | 信号一层层往下传，传到底就没了，底下几层学不到东西。<br>办法：换激活函数（ReLU）。 |
| **它学会了** | 第一次能力涌现 | 下一项能力的两条进度都满了。 | 脑子够大、题够多，它就会在某一刻突然学会一件新事。这叫**涌现**。 |

卡面上的原词（过拟合、学习率、涌现……）按《名词简化策划》的规则用琥珀色粗体标出。

### 3.3 「我」在收卡时的台词

| 卡 | 收下后「我」说 |
|---|---|
| 过拟合 | 跟我高中背的那本题集一模一样。 |
| 练崩了 | ……我是不是把它弄坏了？ |
| 天花板 | 小学生再努力，也考不过高考卷。 |
| 顿悟 | 它刚才……想通了？ |
| 它学会了 | — （由能力涌现过场接管） |

## 四、科技树文案简化

### 4.1 问题

现在的说明（`XgTechTreeCopy.cs`）同时写原理、模拟公式、叠加规则、前置条件和免责声明。例如「标注报酬倍率」：

> 提高亲手答题的单题报酬。效果：人工答题报酬 ×22 → ×24；购买后立即用于后续人工结算，与其他适用报酬倍数相乘。与标注台商店共用；按人工报酬计算的答错罚款也会提高，实扣不超过余额。自动标注报酬不变。

### 4.2 规则

| 留 | 删 |
|---|---|
| 名字（中文 + 原词缩写） | 「不保证」「需训练后评估」「仍受……限制」 |
| 一句话：这是什么（≤ 18 字） | 叠加 / 相乘 / 不叠加规则 |
| 效果：一行确定的结果（≤ 20 字，有数字写数字） | 内部公式（误差项、保留率、阈值倍数） |
| 价格 / 等级 | 前置条件（已在节点锁定状态里显示） |
| （可选）一行代价，红字 | 免责、例外、离线情况 |

卡面三行：

```
标注报酬倍率   Lv.11 / 17
亲手答题赚得更多。
报酬 ×22 → ×24        ¥3427
```

### 4.3 逐条替换（`XgTechTreeCopy.Explanation` + `Effect` 合并为两行）

**标注与自动化**

| 节点 | 一句话 | 效果 |
|---|---|---|
| 标注报酬倍率 | 亲手答题赚得更多。 | 报酬 ×{当前} → ×{下一级} |
| 自动标注 | 让合格的模型替你答题。 | 每台每级 +{速度} 题/秒 |
| 置信度分流 | 有把握的自己交，拿不准的留给你。 | 可设把握线 50%–99% |
| 本地模型推理 | 让它亲自读题再判断。 | 文字题由本地 AI 作答 |
| 难例复核奖励 | 复核难题有奖励。 | 复核答对：报酬 ×1.5，样本 ×2 |
| 标注质量抽检 | 自动交的题抽查一遍。 | {N}% 的错题被拦下；可手动清洗 |
| 并发推理 | 同时判两道题。 | 同时判题 1 → 2 |
| 金标准题匹配 | 记住平台的考题。 | 遇到考题转人工 |
| 验证码自动填充 | 验证码自己填。 | 验证码自动通过，信用 +1 |
