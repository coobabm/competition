## 交互与真实数据约束

- 节点指针进入立即显示详情，离开立即关闭；浮层不抢节点射线；点击节点购买，键盘聚焦可查看、Enter可触发。已确认的游戏实现保持不变。
- 展示详情的两行正文可以精简，但前置、价格与拒购原因不可因“一屏”限制删掉。必要条件优先完整展示；长前置布局留实现验收。
- 有钱且条件满足才购买成功。经费不足仍可悬浮阅读；不可把整个卡完全禁用而丢失解释。
- 购买动画成功后才播，拖动不购买、失败不播成功反馈；减少动画关闭运动，声音独立控制。
- 正式价格、差额、等级、节点效果来自同一运行时数据。预览不改变定价、训练公式、奖励和门禁。
- 术语入口与详细科普按钮的最终行为等 Claude 交付，本轮预览只展示基础说明，不代表已删除或重做那些入口。

## 已确认补充：2026-10-21 图标悬浮与光效

用户确认：①普通未解锁节点保留名称、效果和前置，仅未发现节点隐藏；②技术缩写与年份改用新稿靠右位置；③采用节点图标悬浮动画，注意光效。两项不再待确认，旧差异表作为历史对照。

悬浮立刻开始，0.8–1.2秒完成一次演示，余下约1.6秒静息再循环；离开/页面隐藏立即停止复位，不影响命中范围与连线。仅当前悬浮或键盘聚焦节点播放；购买成功优先用340ms金色加强反馈，失败没有成功光效。悬浮不新增声音。减少动画时取消路径移动、回弹、闪烁，仅保留静态描边；静音独立控制。

光效采用两层同路径线段：2px清晰信号芯＋5px低透明度外层（峰值12%），不用Bloom、实时模糊和全屏闪白，不溢出图标区域。正常状态用浅青绿，锁定/资金不足用灰蓝且整体55%亮度；购买短暂暖金。正文和卡片背景保持稳定可读，不靠光效表示唯一状态。

| 类型 | 动画设计 |
|---|---|
| 多层感知机 | 信号依次经过多层连接，小节点依次点亮 |
| 卷积 | 小扫描框跨过图案，局部笔画依次亮起 |
| 循环/记忆 | 沿回路走一圈，尾迹短暂淡出 |
| 注意力 | 少量连接先后强调，最后汇聚中心 |
| 学习率 | 三档滑轨依次扫亮，表现尝试不同步幅 |
| 批归一化 | 不等长线段向中心对齐，轻扫一遍 |
| Adam等优化器 | 小信号沿下降路径趋近目标 |
| 梯度裁剪 | 信号通过两条边界，强调幅度限制 |
| 数据/工具/奖励 | 扫描、归整或单次局部亮边，不持续旋转整张卡 |
