# .exe UI v4 交接（给 GPT）

> 原型：`Design/ui/exe_ui_v4.html`（浏览器打开，左上角「原型控制」可切进度、模拟读完一本书）。本文件取代 v3 交接。
> 原型的作用是定**视觉风格、交互手感**和**「每个栏目都要买」的规则**。数值、小游戏、数据格式以 `main` 现有代码为准；冲突的地方见第 5 节。
> **范围**：.exe 窗口，加上和它直接相连的三样桌面东西：「len 的资料」文件夹、YY 通知和 YY 聊天框。其余桌面软件照原设计（按阶段开放）。

---

## 1. 规则

1. **左栏**：很窄（112），四项「教 / 练 / 科技 / {AI 名字}」**竖向平均分满整列**，每项是一个大图标加名字。没解锁的项灰着，图标换成锁，下面一行小字写怎么解锁。四项下面留一个小框，给蜘蛛灵宠预留「出来走走 / 休息」按钮（现在只做占位：切换文字和图标、放音效）。最底部是两个圆形小按钮：音效、减少特效。
2. **窗口**：不再全屏最大化，左边留出桌面图标那一列（「len 的资料」、YY、len.exe），这样能从桌面拖文件进来。
3. **练页每一块都是科技节点**。没买的块显示「封印」（毛玻璃 + 名字 + 一句话 + 价格），点了跳到科技节点并打开说明卡。
4. **参数靠买**「网络宽度 / 网络深度」等级；结构节点再乘倍数。
5. **记账本**（¥15）买了才显示钱、收入/秒、电力，练页多「资金账本 / 总账」。科技页标题旁一直显示钱。
6. **装备**的能力类节点在科技「装备」行买；练页「装备」页签只负责展示和跳转。
7. **教页右侧「答题记录」**：可筛「全部 / 我答错的 / 它答错的」，点开看正确答案、我的答案、它当时的答案和把握、报酬、当时的能力和连对数、解析。
8. **数据包：保留「拖动数据包」**
   - 在科技或「练 › 数据来源」买数据包 → 以 ADSL 速度**下载到桌面「len 的资料 › 数据包」文件夹**（文件图标上有进度条，下好了任务栏「资料」闪一下）。
   - 从文件夹把 `.zip` **拖进「练」页**任何地方（页面会盖一层「松手，装进去」）才算安装：样本增加，「教」多一张题桌。
   - **可以批量**：文件夹里按 Ctrl 多选，或点「全选可装的」，一次拖进去。
   - 「数据来源」页签里也能**输入网址下载**（例：`yann.lecun.com/exdb/mnist`）。网址出现在贴吧帖子、书页批注里；能力阶段不够时提示「它现在还看不懂这些」，地址不对提示「打不开这个网址」。下载同样进文件夹，再拖进来。
   - 没买「数据来源栏」时，拖进来会提示先去买。
9. **「len 的资料」文件夹**（桌面图标，Win7 资源管理器样式，可拖动窗口）：里面有「数据包」文件夹、`使用说明.txt`、`训练日志.txt`（最近几轮成绩）、`答题记录.csv`、买了「回档」后出现 `存档_第N轮.ckpt`。单击看右侧预览，双击进文件夹。
10. **喂书照原来的流程**：书架 →「读给它听」打开读书窗口逐字读（可暂停、合上，进度保存）→ 读完**桌面右下角弹 YY 通知**（任务栏 YY 闪）→ **点通知打开 YY 聊天框**，它的问题在聊天里，你在聊天框里回复。问题不在 .exe 里显示。
11. **新科技节点「数据回顾」**（性格行，能力 2，¥150，前置「脑子窗口」）：买了以后，和它的 YY 聊天框工具栏多一个「数据」按钮（没买时按钮带锁，点了提示去科技买）。点开后聊天框向右变宽，右边多一页「它读过的」：**按能力阶段分组、按系统时间倒序**列出喂过的数据，每条带类型标签（题 / 书 / 数据包 / 对话）和对错。
    - 本次原型里写进这一页的有：教页做过的题（含它当时的答案）、读完的书、装进去的数据包、回答它的读书提问。
    - 以后的性格数据包等「教」以外的数据，按同样格式往里加即可，这次不用做。
12. **「看它学」**：每阶段多一张图，旧图都留着。「真训练 · 异或」照现有 demo。
13. **音效和点击动画**（见第 3 节）。答对特效、连击动画的完整版在 Unity 里做，原型里只有简版。

## 2. 视觉规范

| 项 | 值 |
|---|---|
| 窗口底色 | `#06080C`，左上叠薄青绿光晕、右上叠薄紫光晕（透明度 ≤ 0.09）；窗口圆角 10 |
| 面板 | 白色 4.5%→1.8% 竖向渐变，1px 描边 `rgba(255,255,255,.07)`，圆角 18 |
| 文字 | 主色 `#F2F4F7`，次级 62%，弱化 34% |
| 强调色 | 青绿 `#5FE3B5`（主操作 / 正确 / 新题线），紫 `#A594FF`（参数），蓝 `#6AB8FF`（样本），琥珀 `#F2C46D`（价格 / 已拥有），红 `#FF7A6E`（错误 / 风险） |
| **字体** | 中文 **HarmonyOS Sans SC**（首选）或 **MiSans**，两者都可免费商用，请打包进 Unity 做 TMP 字体资源；读书窗口正文用**思源宋体**（Source Han Serif SC）；数字用 **Inter** 或 DIN 风格字体，等宽数字。网页原型在没装这些字体的电脑上会退回微软雅黑，**以 Unity 打包的字体为准** |
| 字号 | 12 / 13 / 15 / 20 / 22 / 28 / 40；大数字用细体 300 |
| 左栏图标 | 50×50，圆角 15，彩色渐变（教 蓝、练 橙、科技 绿、名字 紫），选中项整块 10% 白底 + 图标放大 1.06 |
| 主按钮 | 「训练一轮」：青绿渐变圆角块（圆角 24）；其它确认：白底深色字的胶囊 |
| 次按钮 / 分段控件 | 6% 白胶囊；分段控件底 5% 白，选中 14% 白 + 轻阴影 |
| 封印块 | 深色毛玻璃 + 极淡横线纹，背后一圈很慢转动的青绿→紫光（14 秒一圈） |
| 科技节点 | 50×50 圆角方块（圆角 15）。可买：青绿描边 + 微光；钱不够：红描边；已拥有：琥珀底；未解锁：35% 透明；说一句话解锁：琥珀描边 |
| 桌面窗口（资料、YY） | 保持 2016 年 Win7 样式，不用 .exe 的深色风格 |

**性能**：Unity 里不要做实时模糊，用半透明贴图；封印块后的光用一张贴图慢慢转。

## 3. 音效和动效

**每个可点的东西都有反馈。** 原型用网页合成音（不用音频文件），Unity 里请做成同样感觉的短音效（全部 < 0.35 秒，音量很轻）：

| 事件 | 声音 | 动画 |
|---|---|---|
| 点任何按钮 | 很轻的「嗒」（高频短促） | 按下缩到 0.95，松开弹回（弹簧曲线，约 0.22 秒）；手指下方淡出一圈光 |
| 切换左栏页面 | 两个上行音 | 新页面从下方 8px 淡入（0.26 秒）；左栏图标放大 1.06 |
| 答对 | 两个清脆上行音 | 按钮染绿；连对数字弹一下变绿；顶栏小球亮一下；飘出 +¥ |
| 每 10 连对 | 三个上行音 | 同上 |
| 答错 | 一声低沉短音 | 按钮染红并左右抖一下 |
| 下一题出现 | 无 | 题目从右侧 14px 滑入 |
| 买下科技节点 | 三音和弦 | 节点放大再回弹，金色光圈 |
| 开始训练 / 一轮练完 | 上滑音 / 两音 | 按钮底部进度条；顶栏小球亮一下 |
| 练崩了 | 低沉短音 | 提示条 |
| 下载完成 | 两音 | 任务栏「资料」闪 |
| 拖起数据包 / 拖进安装 | 「啵」/ 下落音 + 一个高音 | 练页盖一层「松手，装进去」 |
| 打开窗口（读书、总账、真训练、文件夹） | 上滑音 | 弹出：从 0.94 放大到 1，弹簧曲线 |
| YY 通知 | 两声提示 | 右下角滑入；任务栏 YY 闪 |
| 点锁住的东西 | 一声闷短音 | 无 |

「减少特效」打开时关掉所有动画；音效按钮单独控制声音。

## 4. 原型里的功能清单（要保留）

- 教：任务大厅（已装的题桌；没装的题桌显示「科技 · ¥」或「在桌面文件夹里，拖进练安装」或「下载中」）、题卡（对/错、手写数字、九宫格）、代答、键盘 1–4、点完立刻下一题、连对和倍率、答题记录。
- 练：下一项能力、四个页签（装备 / 数据来源 / 它学会了吗 / 书架）、拖放区 + 网址下载、资金账本和总账、模型名牌、回档、成绩行、答卷、曲线（练过的 / 新题 / 上限 / 退步 / 「它在背答案」）、看它学、真训练、学习率六挡、训练一轮、风险预报。
- 科技：阶段卡 1–6、六行分支、57 个节点（含新增「数据回顾」）、说明卡、拖动、滚轮以鼠标为中心缩放（50%–150%）、−/＋/适应、双击回 100%、跳到能力 N、只看可买。
- {名字}：粒子球、6 项能力、性格三轴、记住的词、「去 YY 和它说话」（打开 YY 聊天框）。
- 桌面：「len 的资料」文件夹（数据包、说明、日志、记录、存档）、YY 通知、YY 聊天框（表情 / 题本 / 性格 / 数据）。

## 5. 和现有游戏不一致的地方

| # | 原型里 | 现有游戏 / 之前的设计 | 怎么处理 |
|---|---|---|---|
| 1 | 「划短信」「算术」是普通对/错题卡 | 已有「划短信」左右划、「算术打地鼠」等，还有 `minigame_packs.json` 的 19 个数据包小游戏 | **保留现有小游戏**；只借用任务大厅和答题记录的样式；小游戏每一步也写一条答题记录，并写进 YY「数据」页 |
| 2 | 装备压成页签 + 科技一行，显卡也在科技里买 | 显卡、散热等实物在网购（淘货）买，有电力 295/3500W 和装备格子 | **实物照旧网购**，到货后进装备栏；科技「装备」行只卖能力类：装备栏、GPU 驱动、cuDNN、混合精度。原型里的「九州风神」「显存 6G」「机房」改成网购商品 |
| 3 | 参数、样本数字是编的 | `main` 有真实公式（8.2K、2,426、噪声扣、已算数） | **数值全用 `main`**；只把参数的增长来源改成购买「宽度 / 深度」等级 |
| 4 | 大脑只在 {名字} 页 | 有可拖动的「脑子窗口」小窗、壁纸大脑 | 保留小窗（买「脑子窗口」后出现），{名字} 页放大版，数据同步；壁纸改回普通 |
| 5 | 数据包：下载进文件夹 → 拖进练页安装 | 「开局流程简化 §6」曾决定删掉拖拽 | **以本文件为准：恢复拖拽**，并支持批量和网址下载。下载速度沿用 ADSL 2.5 MB/s（原型为了演示加快了） |
| 6 | 书架 4 本书和提问是原型自己写的 | 原来有喂书系统 | 用原来的书；流程按第 1 节第 10 条 |
| 7 | YY 聊天框是简化版 | 现有 YY 聊天（含之前设计的「题本」「性格」按钮） | 在现有 AI 聊天框上**加「数据」按钮和右侧页**；通知 → 打开聊天回复，照之前的设计 |
| 8 | 「去考」一按就升阶 | 升阶有过场 | 用现有升阶过场 |
| 9 | 顶栏状态格写「蛛」「券」 | 原来的状态格 | 照原含义 |
| 10 | 桌面只放了三个图标 | 桌面图标、便签按阶段出现 | 照原设计；新增「len 的资料」文件夹（开局就在，买了数据包才有东西） |
| 11 | 科技节点名称、价格、前置是原型排的 | `main` 的科技节点 | 以 `main` 为准；原型新增的练页模块节点和「数据回顾」要补进去 |
| 12 | 学习率风险是简化算法 | `main` 的「×2.5 炸 90%」等 | 数值用 `main`，文字只留短句 |
| 13 | AI 名字默认 `len` | 玩家起的名字 | 全部用 `Sim.AiDisplayName`；文件夹名「len 的资料」也跟着改 |
| 14 | 音效是网页合成的 | 现有音效资源 | 按第 3 节的表做成音频；已有合适的就复用 |

## 6. 做的顺序

1. 视觉组件（第 2 节）+ 按压动画和点击音效（第 3 节第一行），先让所有按钮手感统一。
2. 左栏改窄、四项均分；窗口位置让出桌面图标列。
3. 练页逐块「买了才显示」+ 封印跳科技。
4. 记账本 + 总账。
5. 答题记录侧栏（小游戏也写）。
6. 「len 的资料」文件夹 + 数据包下载 → 拖进练页安装（批量）+ 网址下载。
7. 喂书：读书窗口 → YY 通知 → 聊天框回复。
8. 「数据回顾」节点 + YY 聊天框「数据」右侧页。
9. 第 5 节逐条对齐；最后补答对特效、连击动画的完整版。

每做完一项在 `Design/整合记录.md` 记一行；拿不准的写到「待确认」。
