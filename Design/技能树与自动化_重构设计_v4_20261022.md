## 1. 新结构：六条主线 + 时代里程碑

### 1.1 骨架

```
            Ⅰ 1958        Ⅱ 1986         Ⅲ 1989–2014      Ⅳ 1997–2015       Ⅴ 2014–2015      Ⅵ 自研
            学会简单判断   学会组合特征    走向专长          学会保留信息       学会寻找重点      重构学习方式
            感知机→MLP    LeNet-5 · RNN  AlexNet · LSTM   ResNet · Seq2Seq  看图说话 ·         机房 · 预训练
                                                          · 注意力          Transformer
 ───────────●─────●───────●──●──────────●──●─────────────●──●──●──────────●──◆──────────────────── 时代主干（里程碑）
 ① 自动槽位   [槽位 1/6] ……………………………………………………………………………………………………… 机房 +2
 ② 准确率     [通用] [文字] [逻辑数学]  [识图]
 ③ 边做边学   [边做边学]

 ⑥ 电力       [电源额定功率] [通用省电] [文字省电] [逻辑数学省电] [识图省电] [散热器]
 ── 折叠区（默认收起）：训练练法 · 数据包 · 支线（人格/生活/棋/蜘蛛/图书馆/装备）
 ── 图鉴（现象、能力）移出科技树，进「图鉴」页签：它们从来不能买
```

- **列 = 时代**（`S.stage` 1–6，等于已学会能力数，`XgSim.Abilities.cs`）。列名直接用 `XgCatalog.StageNames / StageYears`；里程碑画在它的 `node.stage` 那一列（在第 n 时代买、用来走向第 n+1 时代），与现有目录一致。
- **行 = 主线**。每条主线由若干「阶梯格」组成，一格 = 一个可升级 6 次的东西。
- **阶梯第 n 级需要进入第 n 时代**。格子上 6 个刻度点和 6 列一一对应，玩家一眼看出「下一级要等到哪个时代」。
- 格子画在它**第一次能买**的那一列；它的后续等级不另画格子。
- 里程碑（真实模型）在中间的主干上，按年份排；它们是「打开下一时代」的门，也是科普的主要入口。

### 1.2 题型家族（每题一桌 → 三个家族）

13 张桌子各开 4 条线会变成 52 个阶梯，太碎。按「难度 + 用的模型轨道」并成三个家族，正好对应 `XgTrack`：

| 家族 | 题桌（`XgCatalog.Desks` id） | 轨道 | 色 |
|---|---|---|---|
| 识图 | mnist 手写数字、meme 表情包、cifar 验证码、go 围棋气数 | Vision | `#6AB8FF` |
| 文字 | sense 常识、spam 垃圾短信、danmu 弹幕、headline 标题党、review 刷单评论、poems 唐诗、longtext 长句 | Sequence | `#5FE3B5` |
| 逻辑数学 | logic 逻辑题、arith 算术（含 arith.calculus 解锁后的高数题） | Sequence | `#F2C46D` |

### 1.3 六条主线逐条定义

所有效果都只作用于**自动答题**的结算，除非另外写明。训练、能力门槛、成绩等级的数学不动（故事节奏由 `AbilityParamsK / AbilitySamples` 决定，本稿不碰）。

#### ① 自动槽位（`label.auto`，复用 id）
- 显示：「可同时自动 2 种题（2/6）」。
- 第 1 级 = 原「开启自动答题」。之后每级 +1 槽。第 6 时代买「租机房」(`datacenter`) 再 +2，上限 8。
- 槽位是 **按题桌** 分配的（不是按家族）。同一家族多张桌各占一槽。
- 买了但没开：显示「已备好 1 个槽位」，不报错。

#### ② 准确率（4 格：通用 + 三家族）
- 部署准确率 `a = min(0.995, 检查点准确率 + 通用加成 + 家族加成 + 边做边学增益)`。
- 通用 `acc.all`：每级 +2 个百分点（满级 +12）。家族 `acc.vision / acc.text / acc.logic`：每级 +3 个百分点（满级 +18）。
- 这些加成**只影响自动答题的部署表现**，不改检查点、不改成绩等级与能力判定。卡面写「自动答题准确率 +3%」，科普里说明「这是部署调优，不是重新训练」。
- 识图/文字准确率格**同时是模型规模的承载者**：买第 n 级也会把对应的旧层数、宽度上限一起给你（见 §2 映射），所以练页能配更大的模型，训练出来的检查点也会更高。卡面第二行写「练页模型上限：8 层 · 宽 256」。

#### ③ 边做边学（`auto.learn`，新）
- 显示：「边做边学：+0.12%/分钟，最多 +5%（2/6）」。
- 自动答对的题，每 k 题记 1 条有效样本进该数据集（与训练共用样本池），同时给这桌一个**部署增益** `live`，向上限 `cap` 渐近：
  - `k = [∞, 20, 16, 12, 9, 7, 5]`，`cap = [0, 3%, 5%, 8%, 11%, 14%, 18%]`（下标 = 等级）
  - `d(live)/dt = 正确题速 / k × 0.0004 × (1 − live / cap)`（每秒 1 道正确题、k = 20 时约 +0.12%/分钟）
- 换模型/重新部署检查点时 `live` 清零（界面写「新模型从头边做边学」），已记入的样本保留。
- 「花钱练 AI」放这条线旁边作为**操作**而不是节点：见 §3.6。

#### ④ 速度（4 格：通用 + 三家族）
- 自动题速 `r = r0 × (1 + 0.25·L通用) × (1 + 0.35·L家族) × 算力份额 × 电力系数 × 效率(a)`
- `r0 = 0.5 题/秒`（原 0.2/级 × 等级被槽位取代，基础给高一点，迁移见 §2.4）。
- 「算力份额」= 现有 `Math.Min(2, host.Compute) × WireSpeed("label:" + desk)`，保留。

#### ⑤ 单价（加薪 + 三家族 + 难例加价）
- `label.raise` 加薪保留（17 级、头衔不变），归入本线，卡面「手动单价 ×6（3/17）· 资深标注员」，第二行「自动答题拿一半加成」（`AutoRaiseShare = .5`，不变）。
- 家族单价 `pay.vision / pay.text / pay.logic`：每级 +30%，手动与自动都吃。
- `label.hard` 难例加价保留在本线。
- 基础价改表见 §3.3。

#### ⑥ 电力（额定功率 + 省电）
- **额定功率** `power.psu`：整机电源，等级 0–6 = 450 / 550 / 650 / 750 / 850 / 1000 / 1200 W（2016 年 DIY 常见档位，副标题写「金牌全模组」之类的装机口吻）。
- **负载** = 待机 95 W + Σ 自动桌功耗 + 训练中的显卡功耗（现有 `cards[].watts × 利用率`）。
- 自动桌功耗：识图 120 W、逻辑数学 90 W、文字 60 W，× `(1 − 0.08·L通用省电) × (1 − 0.10·L家族省电) × (1 + 0.06·(L通用速度 + L家族速度))`。速度越高越费电，这是两条线互相牵制的地方。
- **超载**：负载 > 额定时，电力系数 `PF = (额定 / 负载)^1.5`，同时乘到所有自动题速**和**训练速度上。卡面、电表写「超载 112% · 全部降到 84%」。不跳闸、不扣钱——跳闸只留给预训练剧情（3500 W 房屋线路，`XgSim.Finale`）。
- 通用省电 `power.save`、家族省电 `save.vision/text/logic`。`cuDNN`、`九州风神` 也挂在这条线（见映射）。
- 第 6 时代 `datacenter` 租机房：额定变为 20 kW（与现有 `IdcLineWatts` 一致），并且 +2 槽。

### 1.4 效率 = f(准确率)

```
c   = 随机基线（是/否题 0.5；k 选 1 为 1/k；唐诗下一字按选项数）
eff = clamp( ((a − c) / (0.60 − c)) ^ 1.5 , 0.15 , 1 )
```

- 60% 起满效率（保留老口径，改名「满效率线」）。低于它不归零，最低 15%。
- 效率同时乘到**题速**上（低准确率的桌自动答得更慢、更谨慎），收入 = 题速 × 正确率 × 单价，所以准确率影响是双重的但连续的。
- 自动错题的抽检罚款上限钳到 `≤ 单价 × a`，保证**每题期望收入 ≥ 0**，玩家不会因为把低准确率桌交出去而亏钱。
- 卡面：「效率 45%（准确率 55%，满效率线 60%）」。

### 1.5 一桌自动收入（汇总公式）

```
income_d = r_d × a_d × p_d × PF × Q × R
r_d = 0.5 × (1+0.25·Ls_all) × (1+0.35·Ls_fam) × compute_d × eff(a_d)
a_d = min(0.995, best_d + 0.02·La_all + 0.03·La_fam + live_d)
p_d = LabelPay(.5) × base_d × (1 + .5·(deskLevel−1)) × (1 + .5·(raiseMult−1)) × (1 + 0.30·Lp_fam)
PF  = min(1, rated / load)^1.5
Q   = QualityPayMultiplier（现有），R = RelicIncomeFactor（现有）
```

## 2. 现有节点 → 新结构映射与存档迁移

原则：**id 尽量不动**；`XgSim.Has(id)` 继续成立；迁移「只给不收」——玩家已有的能力只多不少，花过的钱不退也不再扣。

### 2.1 数据结构（工程建议）

- 新增 `XgNodeKind.Axis`。一个阶梯格 = 一个 `XgNode`（`maxLevel = 6`），附一张等级表：
  `XgAxisLevel { int stage; double cost; string[] carriers; string subtitle, subtitleEn; string topic; double value; }`
- `carriers`：买这一级时一并写入 `S.unlocked` 的旧 id（层数/宽度/研究）。这样练页、`NextStudyNode`、能力折扣、`Has()` 都不用改。
- 状态：`XgState.axisLevels : List<XgLabelCount>`（沿用现有计数列表的存法），新 `axisVersion` 用于一次性迁移。
- `XgTechTree` 继续负责把节点折成格子：Axis 节点直接成一格；Depth/Width 不再单独成格（被承载）。

### 2.4 存档迁移（`axisVersion` 0 → 1，读档时一次）

1. **槽位**：`slots = max( min(6, autoLevel), 当前处于「自动」状态的题桌数（上限 6） )`。超出阶梯等级的部分记 `bonusSlots`（显示「迁移赠送」）。`autoLevel` 7–10 的部分换成 `speed.all` 等级（每 2 级换 1 级，向上取整）。
2. **槽位分配**：按老存档最近 100 题的每桌收入从高到低，自动把前 N 桌放进槽位；其余桌为「手动」。
3. **收入不降保护**：迁移后按新公式算一次总自动收入 R_new；若 < 老公式 R_old，则补 `speed.all` 等级直到 ≥ R_old（上限 6），记 `migrationGift`。
4. **层数/宽度 → 准确率阶梯**：对每个阶梯，等级 = 「任一承载 id 已拥有」的最高级号；该级及以下的其余承载 id 免费补齐。
5. **研究 → 通用准确率 / 通用省电**：同上规则（`bias` 或 `step` 任一已买 → Lv1；`cudnn` 已买 → 通用省电 Lv2 并补 Lv1）。
6. **顿悟**：`autoLevel > 0` 已视为顿悟（`AutoLabelRevealed`，现有逻辑），不变。
7. 迁移后第一次打开灵光弹一张「实验室改版说明」卡（一次），列出：槽位数、谁在自动、赠送内容。
8. 迁移不可逆，迁移前自动备份一份 `*.pre-v4` 存档（复用现有存档备份流程）。

### 3.4 花钱跳题（F5）

- 手动答题时，卡右下「跳过 ¥x」。`x = ceil(0.3 × 该题手动单价（含加薪，不含连击）)`，最低 ¥1。
- 跳过：不出样本、不罚款、**连击保留**（这正是它值钱的地方：错一题罚 50% 还断连击）。
- 抽检题、剧情题、复核题不能跳（按钮灰，悬浮写原因）。

### 3.5 每日「神题」（F7）

- 每个真实日期（本地日期，沿用 `XgDailyKnownDates` 的日期口径）在「逻辑数学」家族出现一张金边题卡「今日神题」，逻辑数学桌开放后才有。
- 四选一，干扰项都是同类常数的近似形式；一天一次作答机会，答错当天不再出现，不罚钱。
- 奖励：`max(¥2000, 当前每秒收入 × 600)`（约 10 分钟收入）+ 成就卡「神人」（首次）。跳过：¥1，无奖励（「一般玩家花钱跳过」）。
- 题库（首批 14 道，答案均已核对）：
  1. ∫₀^∞ sin x / x dx = π/2　2. ∫₀¹ ln x · ln(1−x) dx = 2 − π²/6　3. ∫₀^{π/2} ln(sin x) dx = −(π/2)·ln 2
  4. lim_{x→0} (tan x − sin x)/x³ = 1/2　5. ∫_{−∞}^{∞} e^{−x²} dx = √π　6. Σ_{n≥1} 1/n² = π²/6
  7. ∫₀¹ x^x dx = Σ_{n≥1} (−1)^{n+1} n^{−n} ≈ 0.7834　8. ∫₀^∞ x³/(eˣ − 1) dx = π⁴/15　9. lim_{n→∞} (n!)^{1/n} / n = 1/e
  10. ∫₀^π x·sin x / (1 + cos² x) dx = π²/4　11. ∫₀¹ x⁴(1−x)⁴ / (1+x²) dx = 22/7 − π　12. ∫₀^∞ e^{−x} ln x dx = −γ
  13. ∫₀^{π/2} dx / (1 + tan^{√2} x) = π/4　14. d/dx (x^x) 在 x = 1 处 = 1
- 自动答题永远不答神题（它不进槽位逻辑）；老周可以在 YY 里吐槽一句（文案另交）。

### 3.6 花钱练 AI（外包标注）

- 练页数据区按钮「外包标注」：`100 条 / 1000 条`，价格 = 条数 × 1.2 × 该桌手动单价（不含连击、不含加薪），**高于自己动手的收入**（反馈 B4 要求）。
- 60 秒内分批到货（像下载一样有进度条），5% 错标（受 `dataclean` 减半）。属于运营费用，不套百元起。

### 3.7 赢棋奖钱（F8）

- 赢自家 AI 一盘：`奖金 = max(¥200, 当前每秒收入 × 60) × [1, 1.5, 2.5][难度]`，和棋 30%。
- 每个真实日期前 3 盘赢棋有奖，之后只记战绩。结算卡写「今日奖励 2/3」。

### 3.8 挂机小组件（F11）

- 买下槽位 1 后，游戏内桌面右下固定一个 256×148 小组件（复用 v3 标题电脑屏外框），内容：状态、本次收入、近 10 秒均值、槽位一行「槽 3/4 · 手写 · 短信 · 逻辑」、两个按钮。现有系统级「挂机小窗」保留为「最小化挂机」。
- 组件可拖动、可收起成一个状态点，位置存档。

## 4. 价格与节奏

### 4.1 阶梯价公式

```
cost(格, 等级 n) = nice( B[n] × w格 )
B = [—, 200, 1200, 4000, 12000, 30000, 80000]         （下标 = 等级 = 时代）
w: 槽位 1.6 · 通用准确率/通用速度 1.3 · 边做边学 1.2 · 家族各线 1.0 · 额定功率 0.9 · 省电 0.8
nice(): 取 1 / 1.2 / 1.5 / 2 / 2.5 / 3 / 4 / 5 / 6 / 8 × 10^k 中最近的一档；最低 ¥100（v3 百元起）
```

里程碑价格沿用现有（含 `StagePrice` 系数），加薪沿用 `RaiseCost`。

### 4.2 节奏表（目标值，P0 用回放 / 机器人存档校准）

| 时代 | 预计时长 | 目标收入 ¥/秒（手动+自动+众包） | 主要买点 | 中位单价 | 期望购买间隔 |
|---|---|---|---|---|---|
| Ⅰ 1958 | 12–15 分 | 1.5–4 | 槽位 1、通用准确率 1、文字/逻辑各线 1、加薪 1–4、功率 1 | ¥200–320 | 60–120 秒 |
| Ⅱ 1986 | 20–25 分 | 6–15 | 槽位 2、各线 2、识图线开放、数据包 | ¥1.2k–1.9k | 90–150 秒 |
| Ⅲ 1990–98 | 25–35 分 | 20–45 | 槽位 3、各线 3、LeNet/RNN/LSTM | ¥4k–6.4k | 90–160 秒 |
| Ⅳ 1997–2015 | 30–40 分 | 60–130 | 槽位 4、各线 4、ResNet、Seq2Seq | ¥12k–19k | 90–160 秒 |
| Ⅴ 2014–15 | 30–40 分 | 150–350 | 槽位 5、各线 5、注意力、翻译订单 | ¥30k–48k | 90–160 秒 |
| Ⅵ 自研 | 25–30 分 | 400–1000 | 槽位 6、各线 6、机房、预训练 | ¥80k–128k | 90–180 秒 |

- 判据：「任意时刻，最便宜的未买有效项 ≤ 当前收入 × 180 秒」的时间占比 ≥ 85%。上一时代没买完的格子在新时代会显得便宜，用来填空档——这是有意的。
- 每时代收入约 ×3：来自槽位 +1、单价 +30%/线、速度 +25–35%、题桌等级、加薪。
- 若校准发现某时代空档过长，先调 `B[n]`，不调单线权重。

## 5. 交互规则

4. **固定**：点格子的图标区固定悬浮卡（现有行为保留），`Esc` 解除。

### 6.5 特效预算（Unity 1080p）

- 同屏冲击环 ≤ 3，粒子 ≤ 120（一个 UI 粒子网格），连线一律用现有批处理 `XgTechLinksGraphic` 画，流动光用 UV 偏移，不逐段生成对象。
- 扫描线/暗角：一张全屏叠加图（静态贴图 + 透明度），不做实时后处理、不加模糊。
- 预算：科技树页面动效 ≤ 1.5 ms/帧（中端 2016 显卡 GTX 960 级别），空闲时（无悬浮、无购买、无收入）不刷新连线网格。
- 窗口不可见或失焦时停所有循环动效（现有 `NodeMotionAllowed` 逻辑沿用）。

### 6.6 减少特效（现有 `S.reduceFx`）

- 关闭：粒子、冲击环、抖动、闪烁、扫描线、呼吸、连线流动、数字滚动。
- 保留：颜色状态、静态发光边、超载红色 + 「超载」文字、数字直接更新、格子按下 0.96 的 80 ms 反馈。
- 超载在减少特效下用**静态红边 + 斜纹**提示，不闪。

### 6.7 实验室全屏（F11 / 按钮）

- `F11` 或标题栏「⛶ 实验室」→ 灵光窗口铺满游戏桌面画布（1920×1080 逻辑），隐藏任务栏，四角 HUD 角标；再按一次恢复原窗口位置大小（复用 v3 小窗「进入前保存窗口状态」的做法）。
- 设置里可选「实验室全屏时也切换显示器全屏」（`Screen.fullScreenMode`），默认关。
- 全屏布局：上 HUD 64 px（时代、钱、每秒收入、电表、按钮）；左 1240 px 科技看板；右 640 px 槽位 + 工位卡 + 当前题；底 28 px 终端状态行。这个布局即原型布局。

## 7. 开场与首次引导

### 7.1 开场可跳过（F1、F2）

现有序列（`PrologueDirector` 的 `SetStep`）：`title → music-intent → virus → txt → hijack → grab → shutdown(-burn) → extract → setup → done`。

- **点击 = 加速**：任意空白处点击，当前段落的文字立即打完、等待时间 ×0.4；连续点击不会跳过选择题。
- **按住 = 跳过本段**：按住鼠标或空格 0.8 s，右下角圆环填满后跳到本段结束状态（不派发任何点击/打开事件，沿用 `music-interrupted` 那种「只看结果不执行」原则）。
- **标题页「跳过开场」**：第一周目就允许（负责人已同意）。确认框一句话：「开场讲它从哪儿来，约 2 分钟。跳过后仍可在『图书馆 · 来历』重看。」跳过直接进 `setup`（起名等选择不跳，默认值预填，约 15 秒）。
- 全部开场动画整体时长 ×0.6（A1）。
- 目标：首次开机到第一次可操作 ≤ 60 秒；跳过时 ≤ 15 秒。P0 先实测各段秒数。
- **BGM**：桌面第一次显示即开始播放（1.2 s 淡入到 −6 dB），不再绑在演出里。病毒弹窗时 300 ms 内压到 −18 dB 并加 800 Hz 低通，弹窗结束 600 ms 恢复。`music-intent` 那句台词需要改（音乐已经在放），改写交给文案，建议改成「先把歌切了……」。

### 7.2 首次「打开灵光」聚焦（F3）

触发：灵光 exe 图标出现且玩家 6 秒内没打开（或字幕已提示一次）。前提：常驻蜘蛛此时已存在（`XgResidentSpider` 注释写「灵光.exe 安装并设置后出现」，需确认与这个时刻的先后，见开放问题）。

| 时刻 | 发生什么 |
|---|---|
| 0.00 s | 桌面蒙版 `#05070A` 透明度 0 → 0.62，400 ms `ease-out`；灵光图标处挖一个半径 72 px 的柔边圆洞（羽化 24 px） |
| 0.40 s | 蜘蛛中断当前行为（`Brain.Interrupt()`），以「scurry」行程走到图标右下 (+38, +10)；距离 > 900 px 时改为从屏幕顶端吊丝落下（900 ms） |
| ≈2.2 s | 到达，转身面向图标，停 150 ms |
| 2.35 s | **搓手**：两条前腿交替上下 4 次，每次 400 ms（新增一个空闲动作，复用 groom 的腿部关键帧，幅度加大）；身体随之轻微前倾 4° |
| 2.35 s 起 | 图标呼吸：缩放 1.00 ↔ 1.06，1.6 s `ease-in-out` 循环；外圈薄荷光环透明度 0.2 ↔ 0.6 |
| 每 4 s | 再搓一轮；间隙里蜘蛛看向鼠标 |
| 点到蒙版其它地方 | 蒙版轻闪一次（透明度 +0.08，150 ms）；第 3 次时图标下方出字「双击打开它」 |
| 双击图标 | 蒙版 250 ms 淡出；蜘蛛小跳一下（300 ms）并跟进窗口角落；之后照常 |
| 20 s 或按 Esc | 蒙版自动撤掉，只留蜘蛛在图标旁搓手 |
| 减少特效 | 无呼吸、静态光环；蜘蛛淡出再在图标旁淡入（200 ms），只搓 1 轮 |

之后每次「该去灵光了」的引导：不加蒙版，蜘蛛走过去搓一轮即可。
