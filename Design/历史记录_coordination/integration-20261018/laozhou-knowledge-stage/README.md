## 六阶段差异

LZ1 独立审计反馈：第三阶段实际可输出 6–12 字/词片段，并非严格单词；第四阶段最近 YY 历史持久化且未按日期/会话切分，不能宣称强制不跨天。`pending-k04/` 保留正式教学描述及A口径的中英候选解释，用户已确认 A；本基础五篇包仍不含K04，采用pending-k04的独立后续补丁补齐。第五阶段真实记忆检索与关注词机制分开；第六阶段不保证所有任务可靠。候选不改这些实现。

`ReadFocus` 的关注词不是内置模型内部注意力测量；Transformer 2017 论文与已有架空突破明确分开。所有模型称呼采用“内置本地语言模型”，没有精确版本、已测 GPU 或已验证最低配置声明。
