# 资料窗口模拟网址 / 下载进度 UI 候选

文件 `files-window-url-ui.patch`。从当前生产（包含共享中文字体、zip后缀）生成窄差异，不碰 Records 或 QA。未改生产、未运行 Unity；git apply --check 通过。

## 内容

- 新 XgFilesWindow.Urls.cs：资料窗口工具栏下增加明确“游戏内模拟下载”的网址输入、MNIST 来源线索和填入按钮、模拟下载按钮及双语状态。
- 只调用正式 PreviewDataUrl / DownloadDataUrl / DataUrlClue；不自行解析、网络请求或修改授权。点击时核心重新校验价格/余额/重复拥有。
- 未识别、门槛未达、余额不足、下载中、已在资料夹、已安装、旧拥有、提交失败均显示核心 message。可下载才启用按钮；开始状态保留3秒，随后显示队列状态。语言切换及时更新；换档清空文本/焦点/旧消息。
- 下载队列每百分比/预计秒数/暂停状态变化刷新，显示0–100%及细进度条。预览写“模拟下载 · 预计N秒”，没有虚构真实MB/s。
- 主窗口只接 Build/Bind/Refresh 与队列条目，保留 root 的字体补丁与 .zip 名称。若另一通知补丁改了相邻 Bind 行，串行保留 ResetDataUrl() 和 BindDownloadFeedback(sim) 两个hook，不能整文件覆盖。

## 待验收

- Unity 编译；现有目录/记录/图片布局在新增地址栏后仍可滚动，中文无缺字、英文不截断。
- 实际 LCD 点击 MNIST 线索能填入；键盘可编辑，粘贴HTTP/HTTPS/无协议受核心白名单识别。
- 未知网址、未达能力、余额不足、可下载价格、点击只扣一次、双击/重复/下载中/已装状态均可见。
- 小体积棋包和MNIST实际百分比持续更新；暂停状态与预计时间；完成变为zip待装且可拖放。
- 换档清空网址/反馈，窗口隐藏不继续刷新UI；UI本身不写钱、不联网、不打开操作系统网址。
- 和 legacy Feedback partial 的下载完成通知并存，不能抢焦点。
