# Teach tools audit

Static source inspection, not a claim of completed runtime acceptance. VisualRasterInteractionChecks passed separately per root.

- Bias threshold: core Knobs includes bias and accuracy gains, but no purchased bias draggable line in the new question card. Legacy XgLabelPage coopThreshold slider (50–99%) changes auto-label routing; it is a different feature and cannot count as the bias tool.
- Confidence: new XgPackQuestion.ShowAi gates percentage on sigmoid; XgActionMoles also gates. But Choices prints answer only, omitting percentage, so digits/face/picture four-choice desks do not consistently gain it. Values are C.Skill, the simulator's skill estimate, not image-specific neural output confidence. The hall remains pay-sorted; no least-confident-first sorter.
- Vary: XgPackPhotos currently rotates RectTransform only by -8..8 degrees. No card pixels/seed are changed and AI suggestion is unchanged. This is visual decoration, not actual augmentation or shifted-digit recognition.
- Suspected-label tray: old cooperation pane has manual recheck and hall rows have review counts; no purchase-gated dataclean tray at new Teach hall top.
- Hard-example corner tag: legacy cards show待复核 and older data flags, but new pack cards lack a hard-review tag/queue.
- Stage quiz shift: no NoteTrainingPhenomenon("shift") caller. Current comment says actual interactions report it, but none does. Do not queue by elapsed time, stage entry or rotating an image object. A valid implementation needs the same real model to predict the original then shifted image and report observed correct→wrong.
- New 28×28 handwriting is original procedural raster while current small inference network uses 8×8 input. Attribution is deliberately unavailable for new 28×28 kind; do not use old 8×8 heat overlay as evidence about this image. Any real shift probe must transform actual supported model inputs, preserve them in the card/notebook and keep rendering and prediction aligned.

Suggested implementation order after photo assets: new generic per-question tool row; reliable confidence/sort semantics; true transform with explicit per-image model adapter; suspected-label / hard-example review backed by saved actual questions. All need real purchase-before/after checks, answer verdict preservation, old-save defaults and bilingual labels.
