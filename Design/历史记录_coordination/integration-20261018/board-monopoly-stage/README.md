# Native Monopoly-style candidate

Apply after board-ludo and board-checkers. Adds pure engine, native 20-square board and 6th launcher. Both computer/personal AI, actual completed-session recording, restart/owner-change abandonment, shared rules and manual pack installation use the imported bridge. No real currency API is called.

Original 20 map names, eight chance cards, 1500 starting play money, 200 passing Start, optional purchase, rent, eight turns each and worth-based winner are retained. Cash below zero after a bill causes bankruptcy; exact-zero cash alone does not. Purchase choice must resolve before a turn ends. Chance movement resolves the new square, including purchase/rent. Dated cards are excluded before actual game date: volleyball 20160821, iPhone 7 resale 20160916 (availability rather than announcement), Singles Day 20161111. Unknown game date excludes all three. No invented date or stage-to-date advance.

Default-A necessary choices (authored design omits amounts): each ordinary property costs 200+20*zero-based-square-index, rent is 20% of purchase price, electric bill is 100. Both price and rent are visible on every property, and the formula is visible in the board account area. All ordinary named squares except Start/Chance/Free Parking/Electric Bill are properties. No houses, auctions, mortgage, selling or jail. Cash plus original property purchase value is the final worth. Level 0/1 buys affordable land, level 3 reserves cash using three actual die-distribution projections of current opponents' rent and bill exposure and acquisition potential. Dice are unchanged and random. Six-minute duration is not verified or enforced.

Nine NUnit cases authored (purchase/skip affordability, Start+rent, bankruptcy, historical filtering, chance movement, eight-turn draw, planning purity, invalid input). NOT EXECUTED here. Static delimiter audit and git apply --check only. Unity compile, tests and actual native visual/input QA remain root-owned. No production or shared QA-runner edits.
