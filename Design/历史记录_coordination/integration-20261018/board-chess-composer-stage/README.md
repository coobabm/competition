# Lv4 verified chess puzzle composition

`board-chess-composer.patch` is independent of the self-play-variety package and depends on `board-picture-source-stage` (Game Hub partial). 9 paths, static delimiter audit and production `git apply --check` passed, no baseline drift. No compilation, Unity, tests or model execution performed here.

The purchased Lv4 Game Hub entry **Compose mate / 自出棋题** composes original **king and queen versus king, mate in one** positions. It shuffles queen placements around a mirrored/rotated king arrangement, tests at most one candidate per active frame and stops after at most 64. The existing `ChessGame` verifies both kings' initial legality and enumerates real legal moves to checkmate. A board is published only when at least one such move exists; no random unsolved board is presented. The engine independently validates the player's chosen move, accepting every legal mating solution.

The UI explicitly limits its scope, supports reset and another composition, and retains the current puzzle across page reopen. Purchase/owner/state guards protect every action. Switching saves cancels generation and clears the former board. The existing Lichess Teach banks remain unchanged. Composing or solving this local practice tool never awards samples, adds a completed-game prerequisite receipt, or creates a data file.

Four `ChessComposerTests` NUnit cases are authored for root's serial execution: multiple seeds' legal solutions, correct initial checks, exactly three pieces, bounded incremental work and deterministic replay. `BoardComposerUiQaHelper.CheckMain(hub, ctl, switchToUnpurchasedSave)` is an **IEnumerator helper** for root's already-isolated Main-scene fixture. It uses actual canvas raycasts/clicks for the purchased entry, generating, legal mate, reset and reopen; it checks unpurchased/stale callbacks, no rewards, and calls root's real save-rebind callback while generation is pending. It does not bootstrap a scene or touch user saves itself; root must run it and capture UI/text in both locales. Helper gate setup directly adjusts fixture unlocks; it does not claim to test the Tech purchase transaction.

This implements a narrow, verified form of the authored “自己出题”; it does not claim arbitrary chess composition, mate in two, or xiangqi. A separate next candidate is being prepared for explicitly labeled generals-and-rook Xiangqi mate-in-one, per root direction.
