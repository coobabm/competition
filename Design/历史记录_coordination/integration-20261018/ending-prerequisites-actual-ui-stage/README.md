It clicks the real route, selects three unique cards including shutdown, tests review/cancel, confirms permanent pins, checks privacy/public-preview fields, then confirms and saves the route. This is repeated route testing from a real checkpoint, not three natural independent playthroughs.

For each online branch it uses actual Start, Pause, Throttle, Resume and PullPower controls with natural frames. Paused data must stay unchanged.
