## 下载与运行

这是 **Windows 便携包，不是安装器**。完整解压后运行 `MyComputerAlive.exe`，保留全部依赖、数据与许可文件，无需安装 Unity Editor。

完整 ZIP 用于本地交付。现有完整 ZIP 超过 GitHub Release 单资产 2 GiB 限制，公开下载使用 7-Zip 分卷方案，每卷目标 1500 MiB。最终完整 ZIP 与分卷须来自同一版本内容，准确大小、卷数、SHA-256 和下载链接待最终产物确认。
