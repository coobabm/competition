# UI 设计提示词（可直接粘贴给设计方／AI）

> 用途：把《我的电脑活了》科技卡、术语解释、自动化面板、任务提示、右下角小窗，以及它们与 `MyComputerAlive.exe` 主窗口的融合方式，一次性交给设计方产出可用的界面稿与实现参数。
> 用法：整段复制给具备画布/原型能力的设计 AI，或作为人类设计师的任务书。

---

## 提示词正文（从这里开始复制）

你是《我的电脑活了》的 UI 设计师。这款游戏是一个 2016 年 Windows 桌面模拟：玩家在桌面上养一个 AI，通过答题、训练、买科技卡让它变强。整体气质是**旧版 Windows 桌面 + 一点科幻感**，不是手机 App，也不是赛博朋克。

请设计下面 6 组界面，并给出它们与 `MyComputerAlive.exe` 主窗口融合的方式。**只做 UI 与交互，不要改任何经济数值、价格、文案内容**（价格由另一边定，文案以随附设计文档为准）。

### 一、科技树卡片

基准画布 1920×1080，页面缩放后卡片实际宽度约 180–220px、高度约 150–170px。

每张卡包含（自上而下）：
1. 图标区：正方形，占卡片上部约 40%，居中。
2. 名字：中文，最多 6 字，单行，14–16px，主文字色。
3. 第 1 行「增益」：12–13px，次级色，最多 8 字。
4. 第 2 行「数值」：12–13px，更浅一档，最多 14 字。
5. 灰字标签：10–11px，颜色 `#7A7F8C`，靠右对齐第 2 行，内容形如 `MLP · 1986` 或 `LRS`（没有就不显示，但保留行高）。
6. 状态行：`已拥有` / `购买 ¥〈价格〉` / `还差 ¥〈差额〉` / `已满级`。
7. 分级节点右上角：`15/17` 形式的等级角标；满级显示 `已满级`。

需要 4 种状态：可购买、已拥有、锁定（名字显示 `？？？`，两行显示 `继续练就能看见`）、买不起（按钮置灰）。
悬停：卡片上浮 2px、描边提亮；按下：下沉 1px。禁止发光、禁止大面积渐变。

### 二、详情弹窗

宽度约 520px，内容一屏放下，不滚动。结构：

```
标题（中文名）                        右上角关闭
灰字（MLP · 1986，75% 字号，#7A7F8C）
状态（Lv.1/1 已拥有）
──── 分隔线 ────
增益（加粗，同卡片第 1 行）
数值（同卡片第 2 行）
一句话（≤20 字，正文色）
具体效果（≤25 字，次级色，解释这个增益到底怎么起作用）
[词条标签] [词条标签]        ← 灰底圆角，可点，最多 3 个
[ 购买 ¥〈价格〉 ]        [ 看详细科普 ]
```

关键：**正文只有两行**（一句话 + 具体效果），原理不放在这里。词条标签点击后打开「术语解释卡」（见下）。

### 三、术语解释卡

覆盖在当前页上的浮层，宽度约 480px，可滚动但首屏必须看到「一句话 + 第一段」。

```
[ 返回 ]                    科技树 › 脑型 › 卷积
标题（词条名）
──── 分隔线 ────
一句话（≤30 字，加粗）
怎么起作用（≤3 句）
在哪张卡里用到（灰字，列出 2–4 个卡名）
延伸：词条A · 词条B · 词条C     ← 可继续点，最多两层
```

交互：点词条打开；**再点一次原词或按 Esc 原路返回**；返回后保留滚动位置；面包屑可逐级回退；最多两层。

### 四、自动化面板（线程面板）

从任务栏「后台」图标或主窗口入口打开，宽度约 560px。

- 顶部：`后台 3/4 线程` + 总速率 `+¥〈速率〉/秒`（实时数字）。
- 每条线程一张卡：题桌名、准确率、速度（题/秒）、当前连对 `×N`、本线程累计收入、`换题桌` 与 `暂停` 两个小按钮。
- 线程停止时在卡片底部写明原因：`没有检查点` / `复核箱满` / `断电` / `你暂停了`。
- 空态：`还没有后台线程` + 一行说明 + `去科技树` 按钮。

### 五、任务提示

- **开局没有任何任务**：任务面板显示空态「还没有任务。先去教页答几题。」
- 新任务出现：右下角滑入一张卡片（宽约 320px），停留 4 秒后淡出；任务栏「任务」图标闪烁（亮/暗 500ms 一次，共 6 次）。
- **点任务图标 = 打开面板并停止闪烁**；不点则图标保留一个小圆点。
- 多个任务同时到来时合并成一张「2 个新任务」。
- 需要给出：滑入/淡出曲线、闪烁示意图、小圆点样式、卡片两行文案的排版。

### 六、右下角小窗 + 与 .exe 的融合

这是重点。游戏主程序 `MyComputerAlive.exe` 需要一个「缩到桌面角落继续干活」的形态。

**小窗规格**
- 尺寸 320×170，无边框，圆角 10，背景不透明度 92%，始终置顶但不抢焦点。
- 默认吸附屏幕右下角，距边 16px；可拖动，位置记忆；多显示器各自记忆。
- 内容：
  - 顶部一行：状态点（绿/灰）、`后台 3/4`、准确率 `88%`、右上 `—`（收回托盘）与 `×`（退出，二次确认）。
  - 中部：`¥ 24.4 /秒` 大号数字（占视觉中心），下方小字 `今日 +¥ 12,840`。
  - 底部：复核箱进度条 + 正在跑的题桌名（最多 3 个，超出显示 `+2`）。

**动效（给出时长与曲线）**
- 每秒结算：大数字按位滚动进位（odometer，120ms，ease-out）。
- 单笔到账：数字旁飘 `+¥12`，上浮 24px 淡出，600ms。
- 连对升档：数字短暂变金色 + 放大到 1.06，300ms 回弹。
- 满额里程碑：进度条一次微光扫过（1s）。
- 线程中断：状态点变灰 + 呼吸（1.5s 循环），数字停止滚动。
- 低配模式：关闭飘字与微光，仅保留数字滚动。

**与主窗口的融合（必须画出来）**
1. **窗口模式**：主窗口标题栏新增两个按钮——`缩为小窗`（图标：两个叠放的方块）与 `置顶`（图钉）。点击 `缩为小窗` 后主窗口隐藏、小窗出现，后台线程不中断。
2. **全屏模式**：小窗隐藏；`Alt+Tab` 切出游戏时小窗自动出现，切回全屏自动隐藏。
3. **快捷键**：`F9` 在大窗 ↔ 小窗之间切换；`Esc` 不触发（避免误触）。
4. **托盘**：小窗关闭（`—`）后收进系统托盘，托盘图标右键菜单：`展开大窗` / `显示小窗` / `暂停后台` / `退出`。
5. **任务栏**：小窗存在时任务栏只保留一个图标，不重复计数。
6. **DPI**：100% / 125% / 150% 三档下文字不糊、不裁切；给出三档的尺寸对照。
7. **退出**：`×` 必须二次确认（`退出后后台停止，确定吗？`），确认后正常存档退出。

### 视觉规范

- 沿用游戏现有字体与色板；不要引入新字体。
- 圆角统一 8–10px；描边 1px；阴影只用于浮层，不要重投影。
- 主色用于「可点/可买」，金色只用于「到账/连对」，灰色只用于「不可用/说明」。
- 所有可点元素命中区 ≥ 32×24，键盘 Tab 可聚焦，Enter 触发。
- 深色底为主；不要纯黑，不要霓虹描边。

### 输出要求

1. 6 组界面的**高保真稿**（1920×1080 基准，另附 1280×720 检查图）。
2. 每个可交互元素标注：尺寸、字号、颜色、圆角、间距、状态（默认/悬停/按下/禁用）。
3. 动效说明表：触发事件、时长、曲线、影响属性。
4. 小窗与主窗口融合的**三张状态图**：全屏、窗口、小窗（含托盘态）。
5. 切图清单：图标、进度条、状态点，标注 1x/2x。
6. 验收自检：1280×720 下文字不溢出、150% DPI 不裁切、深色下对比度 ≥ 4.5:1。

### 不要做

- 不要改文案、不要填价格、不要新增功能入口。
- 不要把小窗做成手机小组件、不要加圆环仪表盘。
- 不要动科技树的布局规则（列宽、连线、滚动方式）。

## 给实现方的落地备注（不属于提示词）

- 小窗用独立 `Camera` + 无边框窗口（`Screen.SetResolution(320,170,false)` + Win32 `WS_EX_TOOLWINDOW`），不要新建第二个 Player。
- 置顶与托盘用 `SetWindowPos(HWND_TOPMOST)` 与 `Shell_NotifyIcon`；Unity 侧只保留一个窗口句柄。
- 数字滚动用 `Mathf.SmoothDamp` 或 DOTween 的 `To`，避免每帧 `ToString` 分配。
- DPI 感知在 `Player Settings` 勾选「High DPI Support」，并按 `Screen.dpi` 反算缩放。
