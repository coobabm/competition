### 1.4 ★三个容易混的说法

| 说法 | 含义 | 玩家的感受 |
|---|---|---|
| 自动答题**准确率** | 答对比例提高 | 答对的题变多，收入提高 |
| 自动答题**连续性** | 复核箱已满、验证码、超时等原因造成的中断减少 | 后台持续运行，不用频繁回来处理 |
| 自动答题**稳定性** | 长时间运行不出现异常停止 | 挂一夜也在跑 |

「不断档」「更稳」不再作为卡片用词；「不崩」「不掉」「不卡住」全部弃用。

## 2. 详情弹窗（简化 + 一句具体效果）

```

│ 手写卷积                 [图标] │
│ LeNet · 1998                   │

│ 先找笔画，再把笔画拼成数字。     │  ← 一句话（≤20 字）

│ [ 购买 ¥38 ]      [ 看详细科普 ]│
```

- **一句话**：它做什么（现有）。
- **具体效果**：★新增，解释「这个增益到底怎么起作用、提升多少、对什么生效」，让愿意钻研的人能比较不同技能的差别。必须与数值行不同，不重复「×1.3」这类字面。
- 具体的、专业性的词（如「卷积核」「学习率」「梯度」）标为可点词条，点击跳到第 3 节的解释卡。

| 卡 | 增益 | 具体效果 |
|---|---|---|
| 权重 | 训练速度提升 | 每轮更新时多处理 10% 的样本，同样时间多练一遍。 |

规则：
- 一条只说**一个机制**，不叠形容词。
- 有数字就写数字（10%、6 档、4 条）。
- 出现专业名词（学习率、梯度、归一化、卷积核）就挂可点词条，不在此展开。

## 3. ★术语解释卡（tip list）

### 3.1 交互

- 任何带下划线/灰底的专业词，点击 → 在当前页上盖一张解释卡（不跳走页面）。
- 解释卡底部有 `返回`；**再点一次原词（或按 Esc）= 原路返回**，滚动位置保留。
- 最多 2 层（解释卡里再点词可以再开一张），面包屑可回。
- 解释卡固定三段：**一句话 / 怎么起作用 / 在哪张卡里用到**，总共 ≤6 句。

### 3.2 词条清单

| 词条 | 一句话 | 关联卡 |
|---|---|---|
| **网络层数** | 模型从输入到输出要经过几层计算。层多能学更复杂的规律，也更容易训坏。 | 网络深度、批归一化、残差网络 |
| **结构** | 信息在模型里怎么流动，比如一层层往下传，还是回头再看前文。 | 感知机、多层感知机、循环网络、自研新脑 |
| **特征** | 模型自己总结出来的「看什么」，比如笔画、偏旁、词序。 | 权重可视化、卷积类脑型、组合线索 |
| CNN | 用小窗口在图上滑动，逐块找笔画，再把笔画拼成整体。 | 手写卷积、文字卷积、深层卷积 |
| RNN | 按顺序读，边读边把前文记在一个状态里。 | 循环网络 |
| LSTM | 带三个门的循环网络：记什么、忘什么、输出什么。 | 门控记忆 |
| Transformer | 整句一起看，用注意力决定每个词该关注谁。 | 自研新脑、回看注意力 |
| 注意力 | 回答当前词时，给句子里其他词分配不同权重。 | 回看注意力、多路注意 |
| 反向传播 | 从错误出发，逐层往回算每个参数该负多少责任。 | 自动求导 |
| 梯度 | 参数往哪个方向调、调多少的依据。 | 自动求导、梯度裁剪 |
| 过拟合 | 练习题背下来了，新题不会。 | 随机失活、留出新题 |
| 学习率 | 每次更新走多大一步。太大震荡，太小走不动。 | 学习率搜索、学习率衰减、学习率预热 |
| 损失函数 | 衡量「答得有多错」的分数，训练就是把它压低。 | 反向传播 |
| 检查点 | 某一轮训练结束时的模型快照，可以回退或对比。 | 检查点、留出新题 |
| 准确率 | 答对的题占全部题的比例。 | 自动答题准确率 |
| 连续性 | 后台不因复核箱满、验证码而停下的程度。 | 复核扩容、验证码代填 |

### 3.3 三个新词条的卡片文案

**网络层数**
> 一句话：从输入到输出要经过几层计算。
> 怎么起作用：每层做一次变换，层数越多能表达的规律越复杂；但层数一多，梯度容易消失，需要归一化或残差连接。
> 在哪张卡里用到：网络深度、批归一化、残差网络。

**结构**
> 一句话：信息在模型里怎么流动。
> 怎么起作用：同样的数据，结构不同，能学到的东西就不同——有的擅长看图，有的擅长记前文。
> 在哪张卡里用到：感知机、多层感知机、循环网络、自研新脑。

**特征**
> 一句话：模型自己总结出来的「看什么」。
> 怎么起作用：底层认笔画、边缘，高层认偏旁、数字；特征越准，同样的层数成绩越高。
> 在哪张卡里用到：权重可视化、卷积类脑型、组合线索。
