## 0. 与 Claude 稿的差异（先看这里）

| 项 | Claude 稿 | 本稿 | 原因 |
|---|---|---|---|
| 离线收益 | 建议**不加** | **加**：50% 效率，最多 8 小时 | 用户明确要「挂机玩法/离线收益」，试玩时间短不是理由——离线收益是「它还在替我干活」的情感回报 |
| 详情展开 | 弹窗里放原理正文 + 意境句 | 弹窗只留**一句话结论** + **可点的缩写标签**，原理移到独立**科普页** | 用户图示：卡片/弹窗要更轻，想深看的人自己点进去 |
| 自动化入口 | 顿悟之后才能看到 | **首次拿到 60% 检查点就解锁**（保留顿悟过场，只是提前触发） | 用户要求「任务里面尽早加个解锁自动化」 |

其余（后台线程、分级、阶段上限、价格曲线、存档字段）沿用 Claude 稿，本文补全数值与文案。

## 1. 科技卡：名字 + 两行

### 1.1 卡片版面（不放大的科技树）

```
┌──────────────────┐
│      [图标]      │  15/17        ← 分级节点才有，右上角
└──────────────────┘
     学习率搜索                     ← 名字（中文，14–16px，主色）
     提高训练效果                   ← 第 1 行 增益（12–13px，次级色）
     学习率 6 档可选                ← 第 2 行 数值（12–13px，更浅）
                    LRS  ·  ⓘ      ← 缩写标签（右侧，10–11px，灰 #7A7F8C）
     购买 ¥38                       ← 状态行（现有样式不动）
```

- 名字、增益、数值**左对齐同一基线**；缩写标签靠右，垂直对齐第 2 行。
- 卡片高度固定，名字最多 1 行（超出省略号），两行各 1 行（超出省略号）。
- 分级节点右上角 `当前级/本阶段上限`；满级显示 `已满级`。

### 1.2 名字规则

| 情况 | 写法 | 例 |
|---|---|---|
| 通用技术 | 只写中文，去掉英文/年份/「工具」 | `学习率搜索 LRS 工具2016` → **学习率搜索** |
| 自研 | 中文名，不加「自研」二字（灰字里标） | `自研新脑 TF 探索2016` → **自研新脑** |
| 脑型 | 中文名，保持现有叫法 | **手写卷积**、**门控记忆** |
| 网络深度/宽度 | 名字固定，数值行体现级数 | **网络深度** / **网络宽度** |
| 数据包/题包 | 用包名本身 | **唐诗**、**短信判断** |

英文界面：只写英文名，不写缩写、年份。

### 1.3 第 1 行「增益」：固定词表（最多 8 字）

> 词表的意义：玩家不读原理，也能一眼知道「这张卡加强哪个系统」。同一系统必须用同一个词。

| 系统 | 允许的增益词 |
|---|---|
| 训练 | 提高训练速度 · 提高训练效果 · 训练不怕退步 · 换脑型不丢进度 · 减少训练花费 · 降低训练风险 · 提高成绩上限 · 训练更稳定 · 能训更大的模型 |
| 模型能力 | 开放基础脑型 · 提供模型视觉 · 增强模型视觉 · 能看图说话 · 增强模型记忆力 · 增强语言理解 · 能用更深的网络 · 模型容量提升 · 能组合多条线索 · 棋力提升 · 能读棋盘图 · 夜间自动练棋 · 了解它的性格 |
| 数据 | 增加数据量 · 提高数据质量 · 增加题目种类 |
| 答题与钱 | 答对奖励提升 · 自动答题 · 自动答题更准 · 自动答题更稳 · 自动答题不断档 |
| 信息与功能 | 开放训练 · 看清真实水平 · 看懂它在学什么 · 看懂它在想什么 · 看清收支 · 每题都有参考 · 开放图书馆 · 开放预训练提示 · 能装更多道具 |
| 生活 | 买显卡更便宜 · 聊天更贴心 · 读懂网络梗 · 预报更准 · 找到学习资料 · 提示跟上音乐 |

**不允许**：一句诗、比喻、原理（「用直线分两边」这种只能进科普页）。

### 1.4 第 2 行「数值」：格式规则（最多 14 字）

- 倍率 `×`，加减 `+ / −`，变化 `→`，速率 `：`。
- 分级节点写「本级 → 下一级」，满级写 `已满级 ×34`。
- **不写** `▶`、不写「加入…脑型」这种空话，必须是可验证的数字或状态。

示例：

| 卡 | 第 2 行 |
|---|---|
| 学习率搜索 | `学习率 6 档可选` |
| 权重 | `训练速度 ×1.1` |
| 残差网络 | `跨层直连：加深不退化` |
| 答题加薪（5/8 级） | `报酬 ×26 → ×28` |
| 后台线程（2/3 级） | `后台作答 3 → 4 个` |
| 道具扩容 II | `装备格 8 → 12` |

### 1.6 边界与状态

- **锁定**：名字显示 `？？？`，两行显示 `继续练就能看见`，标签不显示。
- **已拥有**：状态行 `已拥有`，两行照常显示（当资料看）。
- **可购买**：状态行 `购买 ¥38`；钱不够时按钮变灰并显示 `还差 ¥12`（本行不加新字）。
- **长数值**：超过 14 字截断加省略号，完整内容在弹窗。
- **英文**：`Train speed ×1.3` / `Spawn 1 more background thread`，同样两行。

## 2. 详情弹窗 + 缩写标签 + 科普页

### 2.1 弹窗结构（一屏放得下，不滚动）

```
┌──────────────────────────────────────────┐
│                                      关闭 │
│  手写卷积                        [图标]  │
│  LeNet · 1998                            │   ← 灰字：缩写 · 年份（75% 字号，#7A7F8C）
│  Lv.1/1   已拥有                         │
│  ──────────────────────────────────────  │
│  提供模型视觉                             │   ← 增益（加粗）
│  可用：手写卷积 · 认笔画                  │   ← 数值
│  ──────────────────────────────────────  │
│  看图先找笔画，再看整体。                  │   ← 一句话（≤22 字，唯一正文）
│                                          │
│  [CNN] [1998] [卷积]                     │   ← 可点标签，最多 3 个
│                                          │
│  [ 购买 ¥38 ]              [ 看详细科普 ] │
└──────────────────────────────────────────┘
```

- **一句话**：只讲「它干了什么」，不解释原理。模板：`<对象> + <动作> + <结果>`。
- **标签**：缩写/年份/关键词，圆角灰底，点击 → 科普页。标签**不随解锁变化**，锁着也能点（好奇驱动）。
- **两个按钮**：主按钮购买；次按钮「看详细科普」= 点第一个标签的快捷方式。

- **三段固定**：一句话 / 它怎么工作 / 为什么 2016 年的它需要这个。每段 ≤4 句。
- **可滚动**，但首屏必须看到「一句话 + 第一段」。
- **相关标签**：再跳一层，最多 2 层深（防止迷路），面包屑可回。
- **来源**：每个科普页底部一行小字 `参考：LeCun et al., 1998`（有真实出处的才写）。

### 2.5 聊天里的 CNN 标签（用户给的那张图）

场景：AI 回答「常识自动化，一般由 CNN 实现」。

- 回答正文照常显示，**第一次出现的术语**后挂一个小灰 tag：`…一般由 CNN [CNN] 实现`。
- 点 tag → 同一个科普页（不新开窗口）。
- **只对白名单术语生效**：CNN / RNN / LSTM / Transformer / 注意力 / 反向传播 / 过拟合 / 学习率 / 梯度 / 损失函数 / 检查点。
- 一条回答最多 3 个 tag；同一术语只挂第一次。
- 未解锁对应科技卡时，科普页仍可看，但购买按钮显示 `还没解锁这张卡`。
- 不做全量实体识别，避免满屏按钮和误标。

### 2.6 科普页文案示例（写 5 篇作为标准）

**CNN**
> 一句话：看图先找笔画，再看整体。
> 它怎么工作：小窗口在图上滑动，每块判断有没有某种笔画；浅层认横竖撇捺，深层把笔画拼成偏旁和数字。
> 为什么 2016 年的它需要这个：手写数字题靠像素硬记，换个写法就错；有了卷积，它认的是笔画，不是位置。
> 参考：LeCun et al., 1998

**LSTM**
> 一句话：该记的记住，该忘的忘掉。
> 它怎么工作：三个门控制信息进出——输入门决定记什么，遗忘门决定丢什么，输出门决定现在用什么。
> 为什么 2016 年的它需要这个：普通循环网络读到句尾就忘了句首；门控记忆让它能撑过一整段话。

**Adam**
> 一句话：下坡快的方向多走一点。
> 它怎么工作：同时记录梯度的均值和平方均值，给每个参数单独调步长。
> 为什么 2016 年的它需要这个：学习率调不好就震荡或走不动；自适应步长让它少调一个参数。

**过拟合**
> 一句话：把练习题背下来了，新题不会。
> 它怎么工作：模型把训练集的噪声也当成规律，训练分很高、新题分很低。
> 为什么 2016 年的它需要这个：留出新题、随机失活、早停，都是为了让它学规律而不是背答案。

**反向传播**
> 一句话：答错了，从结果往回找每个环节的责任。
> 它怎么工作：从损失函数出发，按链式法则逐层算梯度，再按梯度改权重。
> 为什么 2016 年的它需要这个：没有它，多层网络只能一层层瞎试，训练慢到不可用。

## 3. 自动化系统（详细设计）

### 3.1 体验目标

1. 第 1 阶段 **5 分钟内**买到第一条后台线程，看到钱自己往上涨。
2. 每条线程都能看到「在答什么题、多快、准不准、赚了多少」。
3. 后台永远比手动慢：**手动始终是最优解**，自动化是「睡觉时也在赚」。
4. 模型练得越准，后台赚得越多——训练和自动化互相拉动。
5. 每个阶段都留一个新的自动化目标，不会一次买完。

### 3.2 核心概念

**后台线程（Thread）** = 一个后台作答槽。

- 每个线程绑定一个题桌；未指定时自动选「当前每秒收益最高」的题桌。
- 线程数量 = `1 + 后台线程等级`（初始 0 级 = 没有线程，需购买）。
- 线程独立连对、独立累计收入、可单独暂停。
- 关闭灵光.exe 窗口后继续；游戏退出后按第 5 节结算离线收益。

### 3.3 数据模型（新 partial，不改旧字段）

```csharp
public sealed partial class XgState
{
    public int autoThreadLevel;      // 后台线程等级 0..8
    public int autoSpeedLevel;       // 作答提速 0..10
    public int autoPayLevel;         // 代答报酬 0..5
    public int autoStreakLevel;      // 后台连对 0..3
    public int trainScriptLevel;     // 训练脚本 0..3
    public int dataAutoLevel;        // 资料自动安装 0..2
    public List<XgThread> threads;   // 每线程：desk、paused、streak、earned
    public int autoVersion;          // 迁移版本，见 3.7
    public double lastSeenUnix;      // 离线结算（第 5 节）
}
```

旧的 `autoLevel` 保留只读，用于迁移折算；不再驱动显示与结算。

### 3.4 结算公式

每线程每秒：

```
accuracy_i   = 该题桌最好检查点成绩；没有则用教页 AI 代答正确率；再没有按 0.5
rate_i       = 0.5 × (1 + 0.2 × autoSpeedLevel)          // 题/秒
pay_i        = 题桌基础价 × 1.5 × (2 + autoPayLevel)      // 每答对一题
streakMult_i = 1 + 0.5 × min(streak_i / 2, autoStreakLevel) // 连对倍率上限 1 + 0.5×level
income_i     = rate_i × accuracy_i × pay_i × streakMult_i  // ¥/秒，期望值
```

- 答对：给钱 + 产出一条样本；答错：0 元、不罚、不计样本。
- 抽检（`label.audit`）保留：错答 40% 进复核箱。
- 不吃玩家加薪（`label.raise`）与玩家连对——这是「手动更赚」的保证。

### 3.5 六个节点（名字 / 两行 / 详情 / 价格）

| 阶段 | 可买线程 | 累计投入（线程+提速） | 后台收入/秒（65%→90% 准确率） |
|---|---|---|---|

| 2 | 2 | ≈ ¥400 | ≈ ¥7 |
| 3 | 3 | ≈ ¥2,000 | ≈ ¥24 |
| 4 | 4 | ≈ ¥8,000 | ≈ ¥100 |
| 5 | 6 | ≈ ¥30,000 | ≈ ¥200 |
| 6 | 8 | ≈ ¥90,000 | ≈ ¥380 |

设计约束：后台收入 ≤ 同期手动答题的 **70%**；超过就调低 `pay` 或提高价格。

### 3.7 老存档迁移

- `autoVersion == 0` 时：`threads = ceil(autoLevel / 2)`，`autoThreadLevel = threads - 1`；`autoVersion = 1`。
- 不退钱、不补钱；旧 `autoLevel` 保留原值只读。
- 迁移只跑一次，写完立刻存档，避免重复折算。

### 3.8 UI

**任务栏托盘**：新增「后台」图标，悬停 `后台 3/4 · +¥24.4/秒`；点击打开线程面板。

**线程面板**（每线程一卡）：

```
┌────────────────────────────────────┐
│ 线程 1   短信判断   88%  0.7 题/秒  │
│ 连对 ×3   本线程 +¥1,204           │
│ [换题桌] [暂停]                     │
└────────────────────────────────────┘
```

- 暂停/停止原因写在卡片底部：`没有检查点` / `复核箱满` / `断电` / `你暂停了`。
- 换题桌只列当前已开放的题桌。

**反馈**：每秒结算；经费旁飘淡 `+¥`；每满 ¥1,000 响一声硬币（可在设置关）。

**顶栏**：`收入/秒` = 合同收入 + 所有线程的实际速率（取近 10 秒平均），不再读已废弃的 `autoLevels`。

### 3.9 异常与边界

| 情况 | 表现 |
|---|---|
| 没有线程 | 顶栏不显示后台段，托盘图标灰 |
| 线程无检查点 | 该线程速率 0，卡片写「没有检查点」，不产生空账 |
| 复核箱满 | 暂停，提示「先清一批复核」 |
| 游戏暂停/断电 | 线程停，恢复后继续，不补算在线时间 |
| 改系统时间 | 离线结算只认 `min(now, lastSeen + cap)`，回拨不产生负数收益 |

### 3.10 测试清单（实现方照此写）

1. 价格表逐级匹配；阶段上限外不可购买。
2. 老存档折算：`autoLevel=5 → 3 线程`，只折算一次。
3. 线程结算：答对给钱+样本，答错 0 元无样本。
4. 抽检：错答 40% 进复核箱。
5. 顶栏收入 ≠ 0（买 1 条线程后）。
6. 离线结算：8 小时封顶、50% 效率、回拨不产生收益。
7. 线程面板：换题桌后速率随之变化。

## 4. 任务里尽早解锁自动化

### 4.1 触发点

**首次拿到 ≥60% 的检查点**就点亮（不再要求幽灵答案连对 8 题 / 手答 150 题）。顿悟过场保留，只是提前到这一刻播放。

### 4.2 任务条目（按顺序出现）

| # | 触发 | 标题 | 正文 | 按钮 |
|---|---|---|---|---|
| 1 | 第一个 60% 检查点 | 让它自己干 | 你已经能判断对错了。花 ¥30 开一条后台线程，关掉窗口它也会接着标注。 | `去科技树` |

- 点 `去科技树` → 打开科技树并**高亮 `后台线程` 卡片**（呼吸光 3 秒），顶部一行提示 `花 ¥30，让它替你答`。

### 4.4 与「顿悟」的关系

- 保留 `EpiphanyCardText` 的过场（「让它替我标」），触发点从「幽灵连对 8 题」改为「首次 60% 检查点」。
- 顿悟卡关掉后，科技树的 `？？？` 变成 `自动答题`，与任务 1 同时出现。
- 这样既保住剧情，又让玩家在**第一次真正练出可用模型**时就能自动化。

## 5. 挂机 / 离线收益

### 5.1 规则

| 参数 | 值 | 说明 |
|---|---|---|
| 效率 | 50% | 离线时线程按在线速率的 50% 结算 |
| 上限 | 8 小时 | 超过部分不算 |
| 结算时机 | 进入游戏、读完存档后 | 一次性结算 |
| 记录字段 | `lastSeenUnix` | 每次存档写入 |
| 回拨保护 | 忽略负时长 | 改系统时间不给钱 |

### 5.2 玩家看到什么

进入游戏后，复用现有「欢迎回来」卡片：

```
你不在的 3 小时 12 分钟
后台标注赚了 ¥1,284
（按 50% 结算，最多 8 小时）
[ 知道了 ]
```

- 没有线程或收益为 0：不弹卡片。
- 顶栏 tooltip：`后台 3 个线程 · 约 ¥24.4/秒（离线按 50% 结算，最多 8 小时）`。

### 5.3 设计取舍

- **不给经验/样本**：离线只结算钱，避免玩家靠改时间刷训练样本。
- **不做「离线收益翻倍」内购**：这是单机买断，保持公平。
- **不写「领取」按钮**：自动到账，减少一次点击。

### 5.4 数值示例

| 线程数 | 在线 ¥/秒 | 离线 1 小时 | 离线 8 小时（封顶） |
|---|---|---|---|
| 1（65%） | 0.7 | ¥1,260 | ¥10,080 |
| 3（80%） | 24.4 | ¥43,920 | ¥351,360 |
| 6（90%） | 200 | ¥360,000 | ¥2,880,000 |

> 注：后期数值增长快，是现有经济系统的量级；若担心通胀，可把上限改为 4 小时，或把离线效率降到 35%。**默认 50% / 8 小时**，按用户要求「增加挂机玩法」先给足。
