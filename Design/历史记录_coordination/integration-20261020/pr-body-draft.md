## 问题与结果

《我的电脑活了》2026.10.20.1 整合新版桌面，同时保留存档保护、软件解锁、独立阅读与 YY 回答。此次整理科技购买、资料安装、道具和个人页入口，并为非玩家人物回复增加逐消息 AI 标识。

这是发行前草稿。v5 名字标已通过预览与原场景开关机检查，但用户随后要求重做图标物料，目前等待 Claude v6 完成；全套回归修复后的复验、最终构建与远端资产结果仍需补齐。

## 主要变更

- 迁回桌面存档路径、验证目录隔离与开窗前的软件解锁检查，修正旧窗口类型迁移；开始菜单复用原设置及偏好保存逻辑，控制面板采用紧凑入口。
- 科技图标负责说明，价格区域负责购买；人物档案沿用资格、300 元收费与重复购买保护。
- 单一资料文件夹允许浏览已有文件或真实下载队列，安装与网址下载仍受 `train.data` 控制；训练页按真实文件更新安装提示，保留拖拽与批量安装。道具入口复用既有 24 种道具、装备容量和替换流程。
- 将“它记得”移入玩家命名的个人页，保留每阶段一次的随机关机问题及待答/历史记录，补齐保存故障恢复保护。
- 每条非玩家人物回复显示双语 AI 标签，包括文字与图片等消息；排除玩家和系统内容。标签只属于界面，不进入模型提示、对白历史或存档。
- 保留独立阅读、YY 回答及 `Qwen3.5-4B-Q4_K_M.gguf`，继续使用 BM25；标题等待最新物料交付核对。
- 教学专用题桌不再通过旧众包/分包入口提交；合法教学、小游戏奖励与企业合同保留。整包购买的规划样本量和安装提示与实际下载文件一致，保留旧存档补买剩余批次。

## 交付形态

**Windows 便携包，不是安装器。** 完整 ZIP 用于本地交付；现有 ZIP 超过 GitHub Release 单资产 2 GiB 限制，公开下载采用每卷目标 1500 MiB 的 7-Zip 分卷。完整 ZIP 与分卷必须来自同一已核验 payload，最终产物与下载链接待补。

玩家下载全部分卷及同版 SHA256SUMS.txt，以 7-Zip 从 `.001` 测试并解压，保留完整目录后运行 MyComputerAlive.exe；无需 Unity Editor。压缩测试通过不等于玩法验收。当前草稿不宣称上传成功或 TapTap 后端验收完成。
