# 连对倍率 ×1–×5：设计与交接（2026-10-20）

- 基线：凌晨约 5 点的 1.3 GB 包 `rel/2026.10.20.1-17b`，对应源码 `40d885e1`。不含之后的谐音替换。
- 分支：`claude/streak-x5`，提交 `b53e0a66`。工作树在 `games/competition-streak-x5`。
- **没有推送，没有动 `competition-integration-20261020` 工作区，也没有启动 Unity。**

## 一、规则

连对两题以后，第三题起奖励翻倍；之后每再连对三题加一倍；最高 ×5。答错就清零。

| 连对数 | 1–2 | 3–5 | 6–8 | 9–11 | 12+ |
|---|---|---|---|---|---|
| 倍率 | ×1 | ×2 不错 | ×3 手热了 | ×4 上头 | ×5 灵光一闪 |

- **适用范围**：所有手动答题，包括小游戏（常识判断、划短信、打地鼠……）、是非题卡片（「教」页也算；纠错的 ×2 再叠在上面）、摆渡众包订单、协作复核。
- **连对数**：全局共用一个，会存进存档。只有答错（含超时）才清零；换题桌、换小游戏、读题慢都不会清零。这些规则和原来一样。
- **快答奖励**：单独再加最多 +50%，不跟着倍率翻。常识判断是 7.5 秒内答对加 +50%；其他小游戏从 0 秒的 +50% 线性降到 5 秒时为 0。
- **手写数字**：这一页没有连对，快答奖励保持原来的最多 +100%，不变。
- **遗物「通宵赶工」（通宵卡 + 红牛）**：原来是「连击上限 ×2 → ×3」，现在改成「每 2 题升一档」，8 连对就到 ×5，上限仍是 ×5。没有改成「答错只降一档」，因为这个组合里的通宵卡已经让连对永不中断，那个效果等于白给。

## 二、基础单价

手动单价系数 `HandPayScale` 从 2.5 改成 1.5。常识判断每题从 ¥1.25 变成 **¥0.75**，答错罚款从 ¥0.63 变成 ¥0.38。

模拟 20 万题，比较平均每题收入相对旧规则的变化：

| 正确率 | 旧规则每题倍率 | 新规则每题倍率 | 乘新单价后，收入是原来的 |
|---|---|---|---|
| 60% | 0.68 | 0.87 | 0.78（少约 20%） |
| 80% | 0.99 | 1.77 | 1.07 |
| 90% | 1.29 | 2.81 | 1.31（多约 30%） |
| 95% | 1.56 | 3.71 | 1.43 |

意图是让钱跟着连对走，而不是跟着点击次数走。开局节奏没变慢：开局 11 题答对就能买 ¥10 的训练曲线（新规则下约 ¥26），24 题能买 ¥20 的节点。对应测试都通过。

## 三、特效与音效（逐级加码）

| 倍率 | 升档那一题（StreakUp） | 之后每题（StreakHit） | 音效 |
|---|---|---|---|
| ×2 不错 | 绿色闪屏、一圈冲击波、¥ 粒子、「×2 不错！」大字、计数器弹跳 | 「×2」小字 + 少量 ¥ | Up2：两声叮 + 轻低音（1.6 秒）；Hit2：单枚硬币 |
| ×3 手热了 | 在 ×2 基础上：第二圈白色波、星星、震屏、¥ 飞向顶栏「经费」 | 同上，字更大 | Up3：短蓄力 → 三音上行 + 硬币串 + 低音（2.2 秒）；Hit3：木击 + 两枚硬币 |
| ×4 上头 | 再加：顿帧、第三圈大波、彩纸、火花；桌宠蜘蛛说「上头了……别停！」 | 再加小冲击波 | Up4：蓄力 → 重低音 + 大三和弦 + 电火花 + 硬币雨（3.0 秒）；Hit4：低音 + 硬币 |
| ×5 灵光一闪 | 再加：全屏金色波、金星、「满倍 · 每题 ×5」；蜘蛛说「灵光一闪！五倍了！」 | 同上，最大 | Up5：长蓄力 + 机箱风扇起转 → 双重低音冲击 + 九和弦号角 + 玻璃泛音上行 + 金币雨（4.5 秒）；Hit5：低音 + 硬币 + 铃 |
| 断连 | 碎屑掉落、「×4 → ×1」红字；×4 以上会震一下 | — | Drop：下滑的嗡声 + 闷响 + 电火花熄灭，丢的档越高越响 |

- 音色复用 `make_sfx.py` 里的合成部件（毡锤钢琴、铃、低音下坠、混响），和游戏原有音效属于同一套。生成脚本是 `Tools/XingGuang/sfx/make_streak_sfx.py`，固定随机种子，重跑结果一样。
- 试听：`claude-streak/连对音效试听.wav`，按 Up2→Up5、Hit2→Hit5、Drop 的顺序。
- 「FX−」减弱特效时：震屏和顿帧关掉、粒子减半、闪光降到 40%。「S×」静音时全部不出声。粒子有上限，超出会自动截掉。

### 界面

- **常识判断右侧面板**：大字显示「×N」，用当档颜色（白→绿→橙→红→金），字号随倍率变大；下面是档名和「再对 k 题 ×N+1」或「满倍」。规则说明改成「连对越多奖励越高，最高五倍」。
- **小游戏底栏**：最前面加「连对 7 · ×3（再对 2 题 ×4）」，后面是新规则说明。原来写的「答得快或连对最多再加 100%」本来就不准（常识判断其实能到 +150%），已经替换。
- **结算提示和飘字**：结算提示加上「· 连对 ×N」；「+¥」飘字用当档颜色，倍率越高字越大。
- **是非题卡片**：「连击 ×1.05」改成「连对 ×N」，用当档颜色。去掉了原来每 10 连击的白闪，现在由升档特效代替。
- **灵光的脑子窗口**：升档时显示「连对 ×N · 档名」。

## 四、验证

我不能启动 Unity，所以用 Unity 6000.4.5f1 自带的 Roslyn 编译器和 .NET 8 运行时在外面编译和跑测试：

- **编译**：`LingGuangV05.XingGuang.Core`、`Assembly-CSharp`（615 个源文件）、`LingGuangV05.XingGuang.Tests` 都是 0 个错误。
- **测试**：用一个小运行器通过反射跑 NUnit 测试，新版 1398 通过 / 246 失败，基线 `40d885e1` 是 1397 / 246。**两边失败的是完全同一批测试**，都需要 Unity 运行时（JsonUtility、Resources、存档事务），在外面跑不了。没有任何测试因为这次改动而新失败。新增的 3 个测试（档位、奖励构成、第三题翻倍）都通过。
- **没覆盖到的**：Unity 里的实机观感，也就是特效时长、粒子密度、音量平衡，需要在编辑器里看一眼。Unity 也还没导入新音效的 meta 文件。
