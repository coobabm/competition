# TapTap Windows 包上传 · 后台字段填写稿（2026-10-20）

> 适用于：`我的电脑活了` Windows 包。包体可能被重新压缩到 1.8 GB 以内，字段值不变，**但「更新日志」的模型措辞要看最终是否还带本地模型**（见文末两版）。

## 1. 启动项配置

| 字段 | 填写值 | 说明 |
|---|---|---|
| 可执行文件 | `MyComputerAlive.exe` | 必须在压缩包**根层**；不要多套一层文件夹（如 `MyComputerAlive-Windows/…` 里再套同名目录），否则下拉框里选不到 |
| 游戏启动参数 | 留空 | 无需命令行参数；模型与存档都按相对路径自动定位 |
| 版本设置 | `1` . `0` . `0` | 平台营销版本号；与内部分支 `2026.10.20.1` 无关。后续热修发 1.0.1 |

## 2. 相关配置

| 字段 | 选择 |
|---|---|
| 防沉迷能力 | **「此次上传的包体未接入防沉迷能力，审核通过后，将自动为游戏应用 TapTap 平台通用的防沉迷系统」** |

理由：单机、无账号体系、无联网对战。选「已接入」需要自证一套实名与时长系统；选「未接入」由平台统一套用。

（约 240 字，留有余量）

### 版本 B —— 不带本地模型时用这版（把最后一行换掉）

```
· 本地对话模型改为后续版本单独提供，本版以预置对话与规则应答为主，游戏内容不上传服务器。
```

> 注意：如果这版不带模型，游戏内「忘言夜」会全部走「模型没回复」分支，第四阶段那段体验等于关闭。建议至少保留一个小模型（见下方技术说明）。

## 4. 上传前检查清单

- [ ] ZIP 文件名：`MyComputerAlive-Windows-1.0.0.zip`（版本号与后台一致，便于对账）
- [ ] 大小 ≤ 平台上限（目标 1.8 GB 内），上传前用 `7z t` 或 `unzip -t` 自测
- [ ] 根层存在 `MyComputerAlive.exe`、`UnityPlayer.dll`、`MyComputerAlive_Data/`、`ThirdPartyNotices/`
- [ ] 包内 `ThirdPartyNotices/` 完整（LLMUnity、LlamaLib、USearch、DOTween、Blackjack、Oxygen、字体与照片声明）
- [ ] 包内只有一份 `.gguf`；若换了模型，文件名/大小/SHA256 与包内 `MODEL_SOURCE.json`、`SHA256SUMS.txt` 一致
- [ ] 解压后双击可进标题页，能开始新游戏、能读档

## 5. 换模型不是「只换文件」

工程里模型身份是硬编码常量，`Assets/LingGuangV05/LocalLLM/LocalModelRelease.cs`：

```
Name    = "Qwen3.5-4B"
FileName= "Qwen3.5-4B-Q4_K_M.gguf"
Bytes   = 2740937888
Sha256  = "00fe7986…ef11a4"
```

`IntegratedReleaseBuild` 在构建前后都会校验 size+SHA256，运行期也可能据此校验。**换 GGUF 必须同步改这四个常量 + 重新构建 + 重新打包**，否则构建直接失败或进游戏后模型加载被拒。只重新压 ZIP 不改代码，是行不通的。
