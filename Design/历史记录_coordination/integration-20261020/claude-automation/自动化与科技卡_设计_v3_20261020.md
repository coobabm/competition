### 1.4 ★三个容易混的说法

| 说法 | 含义 | 玩家的感受 |
|---|---|---|
| 自动答题**准确率** | 答对比例提高 | 答对的题变多，收入提高 |
| 自动答题**连续性** | 复核箱已满、验证码、超时等原因造成的中断减少 | 后台持续运行，不用频繁回来处理 |
| 自动答题**稳定性** | 长时间运行不出现异常停止 | 挂一夜也在跑 |

「不断档」「更稳」不再作为卡片用词；「不崩」「不掉」「不卡住」全部弃用。

## 4. ★任务弹窗 + 闪烁

### 4.1 初始状态

- **一开始没有任何任务**：任务面板显示一句话「还没有任务。先去教页答几题。」
- 只有触发条件满足才生成任务，不在开局堆列表。

### 4.2 新任务 / 任务更新时

1. **右下角滑入一张任务卡**（从屏幕右侧滑入 240ms，停留 4s，向下淡出）。
2. **任务栏「任务」图标闪烁**（Windows 式：图标底色亮/暗 500ms 一次，共 6 次）。
3. **点任务图标 = 打开任务面板，同时停止闪烁**（这就是"点击暂停"）。
4. 不点也不消失：图标保持一个**小圆点**提示，直到打开面板。
5. 一次来多个任务，合并成一张卡：「2 个新任务」。

```
┌───────────────────────────────┐
│ 新任务                     ×  │
│ 让它自己干                     │
│ 花 ¥30 开一条后台线程。        │
│ [ 去看看 ]                     │
└───────────────────────────────┘
```

- 设置里可关「任务提示音」，闪烁保留。
- 任务卡不抢焦点，不暂停游戏。

## 5. ★离线选项 + 右下角小窗

### 5.1 离线开关

设置 › 自动化：

```
离线挂机        [ 开 ]
关掉游戏时，后台线程按 50% 效率继续工作，最多 8 小时。
钱在下一次进入游戏时到账，不会产生训练样本。
```

- 默认**开**；关掉后完全按在线结算。
- 不提供"翻倍"之类选项。

### 5.2 小窗（右下角）

把游戏缩成桌面角落的一块「状态牌」，随时看它在赚钱。

```
┌─────────────────────────────┐
│ ● 后台 3/4        88%   — × │  ← 状态点 + 线程数 + 准确率 + 最小化/关闭
│                             │
│      ¥ 24.4 /秒              │  ← 大数字，每 100ms 滚动
│      今日 +¥ 12,840          │  ← 小字，累计
│                             │
│ ▓▓▓▓▓▓▓░░░  复核箱 14/20     │  ← 进度条
│ 短信判断 · 唐诗 · 常识        │  ← 正在跑的题桌
└─────────────────────────────┘
```

- 尺寸 **320×170**，无边框、圆角 10、半透明 92%，置顶但不抢焦点。
- 默认吸附**右下角**（距边 16px），可拖动，位置记忆。
- **双击**还原大窗；右上 `—` 收回托盘；`×` 退出游戏（二次确认）。
- 右键菜单：暂停后台 / 恢复 / 还原大窗 / 退出。

### 5.3 动效（全部 60fps，可在设置里降级）

| 连对升档 | 数字短暂变金色 + 轻微放大 1.06，300ms |
| 满 ¥1,000 | 进度条微光扫过一次（1s） |
| 线程中断 | 状态点变灰 + 缓慢呼吸（1.5s 循环），数字停止滚动 |
| 离线结算回来 | 打开大窗时，小窗先显示 `+¥1,284` 大字 2s，再缩回正常 |

- 静音默认：只有满 ¥1,000 一声轻响，可关。
- 低配模式：关掉飘字与微光，只保留数字滚动。

### 5.4 和窗口模式的关系

| 模式 | 行为 |
|---|---|
| 全屏 | 小窗不显示；按 `Alt+Tab` 切出时自动出现 |
| 窗口化 | 可手动切小窗（标题栏按钮 / `F9`） |
| 小窗 | 后台线程照常，点击展开回大窗 |
