## 审查结论

不能直接照收外部快照。六个 Panel 的差异仅首页 Blurb；HubGame.BoardSessions 的规则、入口是新增行为。

1. `XgSim.BoardRecords.cs` 的 BuildBoardBatch 按 game 分组，因此“每3局”必须注明“同一种棋”。BeginBoardSession 在开局时固定 recording；购买前开的棋局不会事后追录。独立候选已补这两点。
2. `HubGame.BoardSessions.cs` 的目标常量 `XgBoardRecords.Node` = `gamedata` 正确。显示条件阶段>=2且尚未购入正确；未下完第一局也可以先跳转查看，Blocker 会解释条件，不应直接购买。外部回调缺存档归属检查且忽略 FocusNodeDetails 返回值，独立候选已补。
3. 规则正文原为固定区域、字号16–21自动缩小、没有滚动。新稿很长，无法保证最小字号仍容纳，尤其英文。独立候选已用 ScrollRect + RectMask2D + ContentSizeFitter，正文20号，保留底部165px按钮区域。
4. `GameHubView.cs` Comment 在阶段6且 AiPlays 才输出。新国际象棋 Blurb 在阶段2就承诺边下边解说，候选改成阶段6偶尔评论。电脑实为深蓝式三层搜索，并不是原版深蓝，中文首页只保留向后推算与将死条件。
5. 首页卡片正文原区域270×68，和 State 的26px区域几何相交14px。长新文案可覆盖状态。候选已压短中文；**仍需实际字体测量/截图验收**，没有宣称排版通过。英文暂不作为本轮交付目标。
6. Rules 有8个 case，但 GameHubView 实际仅注册五子棋、围棋、国际象棋、飞行棋、跳棋、大富翁6个 HubGame。`xiangqi_endgame` / `chess_mate` 两分支没有对应 HubGame，不能把这两段称为已接入；目前棋局摆盘/残局走独立 GameHubView.BoardComposer / XiangqiComposer 页面。

- 五子棋：15路、五连、无禁手，与 GomokuGame 一致。
- 围棋：9路、禁自杀、简单劫、两次停手、数子与地盘、白贴6.5，与 GoGame 一致。
- 国际象棋：将死/逼和、王车易位、吃过路兵与升变，对应 ChessGame；当前玩家执白。

- 跳棋：每方6子，双方各40回合后按入营数比较，可提前全部入营胜出，与 ChineseCheckers 一致。
- 大富翁：20格、各8回合、1500游戏币、经过起点200、现金+地产、现金<0破产，与 MonopolyGame 一致。
