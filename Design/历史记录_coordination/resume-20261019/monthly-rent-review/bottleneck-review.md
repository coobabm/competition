# 六阶段瓶颈问答卡：当前实现与设计核对

日期：2026-10-19。只读审阅 production `competition-latest-20261016`；未修改生产，未启动 Unity、测试或模型。以下“已实现”均指静态代码证据，不代表交互验收通过。

## 结论

“玩家先看到失败 → 一句问题 → 短解释 → 去试对应技术”的方向成立，而且基础流程已经存在。当前 21 道阶段小题、9 张知识卡，还有独立的四原因瓶颈诊断。优先工作应是让题目依据玩家刚见到的证据，并与诊断结论一致，而非给每阶段硬套一个唯一技术上限。

现有进阶规则是参数量和有效样本量推动六种能力出现；结构道具可以降低门槛，代码明确允许不买这些结构、在更晚达到能力。因此“答对题才解锁下一阶段”或“必须研究某技术才能升阶段”都不是当前机制。

## 六阶段核对与建议

| 阶段 | 当前题目与触发 | 建议的“失败 → 问题 → 解释 → 技术/行动” | 现状与缺口 |
|---|---|---|---|
| 1 是/否 | q1a 入阶段→感知机；q1b 任意平线→MLP；q1c 练习/验证差距>15个百分点→留出集；q1d 发散→学习率调度 | 同一批组合条件题总错、简单题能答 → “两个条件合起来，它为什么分不开？” → “单个线性分类器无法表达这类非线性边界；隐藏层配合非线性激活可以表达更复杂的关系。” → MLP；如果真实主因是数据/容量，则分别补题/扩容 | q1b 标题固定“50%”，触发却没有分数接近50%、逻辑题或感知机限制；不能保证问题与画面相符。“加一层就行”漏掉非线性和优化条件。q1c 的跳转是 `train.holdout`，解释却要求更多不同题，宜提供补题行动。 |
| 2 多选一 | q2a 入阶段→MLP；q2b depth>4且平线→ReLU；q2c 平移后由对变错→LeNet | 加深后早层更新弱 → “前面的层为什么学得很慢？” → “深网络中梯度可能衰减；ReLU等激活可缓解一部分问题，仍需合适初始化与训练设置。” → ReLU。或原图正确、平移错误 → “位置变了，为什么就认不出？” → “共享小窗口能在不同位置识别相似局部特征；结合数据增强可提高平移鲁棒性。” → LeNet/数据增强 | shift 已有真实前后识别比较；deep_flat 只是层数+平线，尚未检查真实梯度或当前激活。“换ReLU就不缩了”“就不怕挪了”过度保证。没有“超过五层普遍失效”的科学定律。 |
| 3 看图说词 | q3a 入阶段→默认LeNet；q3b poems/longtext、低于.65且epoch≥2→LSTM；q3c 发散→梯度裁剪；q3d 练习/验证差距→Dropout | 近处线索能答、远处线索经常丢 → “前文隔远了，为什么忘？” → “普通循环结构学习长依赖可能困难；门控可更有选择地保留信息。” → LSTM。发散则先缩步、检查数值，再看梯度裁剪 | long_fail 尚不是前后文距离对照，也不检查运行结构是否已是LSTM；两轮低分可能只是没练够。q3a “两种脑型”默认只去LeNet，无法表达视觉/序列分支。NaN原因不止学习率；裁剪不能保证修复所有NaN。Dropout降低过拟合风险，不保证小样本泛化。 |
| 4 短句 | q4a 入阶段→LSTM；q4b 视觉depth>4且本轮较上一轮低→ResNet；q4c translate且未拥有seq2seq→Seq2Seq | 在同数据/训练预算下，加深反而持续更难优化 → “更深了，为什么反而难学？” → “深网络可能更难优化；残差连接为信息和梯度提供更直接的通路。” → ResNet。输入句与输出句需要对应→“怎样把读到的句子变成另一句话？”→条件化的编码/生成→Seq2Seq | 单轮下降不是深度导致退化的证据；需控制条件并复测。translate_fail 检查的是拥有道具而非当前实际结构和一次翻译失败。q4a 把阶段4能力归为LSTM，而能力折扣表是RNN对应4、LSTM对应5，应与当前能力规则对齐。 |
| 5 长记忆/翻译 | q5a 入阶段即声称长句翻乱→Attention；q5b parallel数据+串行连线→Transformer；q5c 噪声>20→清洗 | 短句可译、长句关键信息漏掉 → “只记一份摘要，够用吗？” → “固定长度表示可能丢失细节；注意力允许生成时选择相关输入信息。” → Attention。训练中序列位置依赖导致等待 → “哪些计算必须等前一步？” → “去掉循环可并行计算许多训练位置，但自回归生成仍通常逐token进行。” → Transformer | q5a 是进入阶段触发，没观察翻译错误。q5b 未检查有八张卡及只一张忙，且“所有字同时看所有字”忽略因果掩码。“便宜数据导致分数降低”也超出噪声阈值能够证明的事实；改为已核对的错标签证据。 |
| 6 通读/预训练 | q6a 入阶段→空node默认SFT；q6b 任意平线→机房；q6c 题本回复明确继续出题→SFT；q6d 已见sycophancy后一个epoch→空node默认SFT | 先显示训练损失/留出表现及资源瓶颈 → “这次停住，主要缺什么？” → 按证据分别给模型容量、优质数据、优化或算力建议。题本问题得到“下一题…” → “它在回答，还是续写？” → “预训练主要学习续写；指令示例可改善按要求回答的倾向。” → SFT。偏好选择后出现迎合→“怎样的反馈会鼓励实话？”→结合正确性而非好听程度评价→偏好训练/评价入口 | q6b 固定“难度降一半”，实际触发只看验证准确率历史平线，未检查预训练难度或资源瓶颈。规模不能保证新能力、真实性或可靠性。q6c 已由真实交互触发，但只识别狭窄措辞。q6d 不是刚发生迎合时直接触发，且默认跳SFT与偏好反馈概念不匹配。q6a 建议跳预训练说明而非SFT。 |

## 已有流程与两套诊断的关系

- 题库由 Resources `Training/stage_quiz.json` 在场景加载前读入；缺失/校验失败则使用 `XgTrainingLessons.cs` 内置题。当前读取的21题文本和映射一致。两处后续应同步维护。
- 每题三个选项，当前21题正确答案全部是第一项；这会鼓励位置记忆。可在保留答案索引正确性的前提下混排，或用更可信的相邻概念作干扰项。
- 小题在当前阶段发生对应现象时排队，一题只答一次；答对+¥20，答错显示解释且不扣钱。两种答案都会标为“已答”并进图鉴，没有答错重答或正确率纪录。
- 答后解释保持在 `answeredQuiz`，不会立即被下一题替换；“去看看”清理该状态，打开科技树并定位对应节点。节点不可见/不存在时退到前沿节点。它不会代买技术、自动应用或复测。
- 问答面板没有单独“稍后/继续训练”按钮；离开页可隐藏，返回可继续。知识卡是覆盖层，有“收下/返回”；知识卡可能盖住问答。`TrainingLessonModalOpen` 对知识卡生效，问答本身不是这个模态标志。
- 排队只在发生时限定阶段，取下一题时不再检查当前阶段：旧阶段题可到下一阶段才展示。适合保留复习，但宜标明“刚才遇到的…”并保存当时数据/结构/证据，否则“现在为什么…”可能失真。
- 问答没有保存触发时的运行配置或验证证据。知识卡只有部分曲线快照；只有历史逐点完全匹配才显示曲线光环，这是谨慎的已有实现。
- 通用平线判定：最近6个有限点极差≤.002，并排除严格逐点下降；本质是五个轮间变化，不是因果诊断。小步计数是状态级计数，不能替代某个运行的学习率对照实验。
- 独立 Diagnosis 使用 `Plateaued` + `CeilingLimit`，从参数、数据、结构、标签噪声中选最大限制。它提供练过/新题、错题类别、标签抽查，再让玩家选原因，错误会排除并解释，正确提供行动；首次答对另有奖励。
- Diagnosis 的“证据”由当前模拟规则和稳定随机种子合成，不是对真实训练模型的独立实验统计。可作为游戏模拟教学，但不要宣称其证明真实模型的唯一因果原因。
- 两套平线判定不同，可能一边说“卡住”、一边尚未触发；更重要的是阶段小题可能归因于结构，而 Diagnosis 认定是数据。建议统一使用一份瓶颈上下文：先有现象/证据，再出题；普通平线只出中性诊断邀请。

## shift / continues 回调核对

**shift 已实现实测链：** `XgPackContentGames.cs:109` 的“挪一格试试”调用 `ObserveTeachingDigitShift(target,seed)`；对同源28×28图像和真实像素平移图分别识别，只有 before/after都valid、原图命中目标、移后不命中目标才上报shift。界面随后显示平移图和前后识别结果。题目q2c仍只在stage2排队。失去valid而非识成别的数字不计入当前lost定义；没有真实失败就不会硬弹卡。

**continues 已实现送达链：** `XgYyTalk.Deliver` 添加消息后调用 `LearningDelivered`；后者核对最后一条消息归属、正文及未重复登记，再检查该提问来自题本。题本已送达回复进入 `NoteNotebookReply`；仅stage6、明确“下一题：/接着出题：/Next question:/Next problem:”开头并有问号才上报continues。普通聊天追问不算。当前epoch观察器没有“未买SFT且两轮”触发。这个窄判定避免普通追问误报，但会漏掉其他续写措辞；不应泛化为“所有续写失败均已识别”。

## 推荐交互收口（建议，尚未实现）

1. 卡头保留一条具体证据，例如“同一张图：原来认对，挪后认错”或“最近五轮新题分数几乎没变”；事实不满足时不编写50%、八张卡等数字。
2. 问题只问一个判断，解释最多两句；把确定断言改成与证据相称的候选机制。
3. 答后并列“去试这个办法”和“继续训练”；目标按当前瓶颈/轨道明确配置，避免空node的阶段兜底。
4. 跳转节点不可见时说明解锁条件或给当前可用行动，不默默跳到不相关前沿。
5. 应用办法后用同一道/同组留出题复测，展示前后变化；答题奖励与真实瓶颈解决分开记录。这样玩家学到的是检验假设，而非记住每阶段必须买什么。
6. 优先修正文案与门控：q1b、q2b、q4b、q5b、q6b；其次补q3a/q6a/q6d的显式目标与问答/诊断/知识卡的展示顺序。
