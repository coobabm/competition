## 明确决策 A

采用玩家主动分享现有摆渡新闻详情的方式接入三条已批准短评。现有“读完新闻”和“转给 AI”是私有行为，不能当作向老周披露。新按钮为“发给老周 (YY/贴吧私信)”，玩家点击后才发出原文“这篇新闻，你怎么看？”＋已有新闻标题＋已有来源网址；不包含玩家私有进度。

只有 `yyLinkSource == tieba_dm_accept` 选择 YY；无接受记录和 `legacy_existing` 均用已有贴吧私信，不补造玩家接受事件。已主动加 YY 但当前 YY 未绑定/不可用时拒绝本次发送，不悄悄更换按钮显示的目的地。旧按钮若渠道或存档已改变也拒绝，重新显示后可重试。

玩家主动动作同步追加两条消息（一条分享、一条批准回复），复用既有消息容器、未读、保存、`ZhouIdle` 节奏门禁。不调用自动新闻通知，不注册新的 Tick、协程、后台任务或窗口打开。老周忙于剧情、阅读、考核、其他消息或输入脚本时本次不发送，未消耗收据。新闻页在成功后展示该次短评，仍可到对应私信查看真实记录。

此方案无需从既有公共讨论的自动通知调度派生第二条通知，因此不改变其节流；亦不虚构老周加入生活群、看到玩家其他群消息或实际读完新闻。
