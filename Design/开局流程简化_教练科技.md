# 开局流程简化：教 → 科技 → 练

> 本文覆盖《练页教学指引与科技文案简化》的第一、二节（开局顺序和「练」页解锁方式）。知识卡内容、科技文案简化规则照旧有效，只是知识卡改存进**科技树的图鉴**。
>
> 一句话：**先教，做完一套题出现科技；科技第一个买「训练曲线」，才有「练」。之后「练」页上的每一样东西、新题库、{名字}代答、脑子窗口，全都在科技里买。**

---

## 一、整体顺序

```
设置名字
  ↓
「教」（只有这一页能点）
  做题：点了就跳下一题，答对有特效，连对攒连击
  ↓ 做完第 1 套（12 题）
「科技」亮起 + 任务台词
  ↓ 买「训练曲线」
「练」亮起（只有：练按钮 + 一条曲线 + 答卷）
  ↓ 之后按需购买
脑子窗口 · {名字}代答 · 新题库 · 新题线 · 步子 · 回档 · ……
```

左栏在开局就显示四项：「教」「科技」「练」「{名字}」。没开的带锁、灰色，悬停写怎么开：

| 项 | 锁着时悬停 |
|---|---|
| 科技 | 做完一套题开放 |
| 练 | 在科技里买「训练曲线」 |
| {名字} | 第一次和它说话后开放（照旧） |

## 二、「教」页：保留现在的样子，逻辑回到以前

### 2.1 保留

- 题卡大字、对 / 错两个大按钮、左侧任务大厅、顶部「加薪」「改答是非题」。
- 页面配色和布局不变。

### 2.2 改回以前的逻辑

| 现在（开心辞典） | 改成 |
|---|---|
| 12 题一局，答对往上爬，第 4、8 题是安全点 | **不分局，一直做下去**。12 题只是计数单位「一套」 |
| 答完要点「继续下一题」 | **点完对 / 错立刻跳下一题**（0.25 秒过渡） |
| 每题倒计时，超时算失败 | 倒计时只用来算「快答奖励」，超时不判错 |
| 求助灵光 / 换一题 / 放弃并保留成绩 | **全部删掉**。求助改成科技里的「{名字}代答」，见第四节 |
| 右侧 1–12 的爬梯 | 换成**连击与套数** |

### 2.3 答题反馈

| 情况 | 反馈 |
|---|---|
| 答对 | 按钮绿色闪一下；题卡上飘「+¥1.25」；连击数字 +1 并弹跳；音效「叮」 |
| 连击到 10 / 25 / 50 / 100 | 大字飘过「不错」「手热了」「上头」「灵光一闪」（现有 `ComboTierNames`），金色粒子；报酬倍率随连击升到最高 ×2 |
| 答错 | 按钮红色抖一下；飘「−¥0.63」；连击归零，数字碎掉；下方一行小字给出正确理由（现有 `why`），1 秒后跳下一题 |
| 快答（倒计时剩一半以上） | 飘字后面多一个「快」字，奖励 +50% |

**连击跨套不清零**：做完 12 题不打断，只在右侧「第 2 套 · 5 / 12」跳一格。

### 2.4 开局台词（沿用上一版）

| 时刻 | 「我」 |
|---|---|
| 「教」页第一次出现 | 这又是什么鬼？我难道要做题吗？ |
| 答完第 3 题 | 这都是什么弱智题目？有什么意义啊？……先做完再说吧。 |
| 第一次「练」完翻答卷 | ……它在答我刚才答的题？所以那几道弱智题，是在教它。 |

### 2.5 右侧栏

```
┌───────────────┐
│   连对         │
│    37          │  ← 大号数字，到档位变色
│   上头 ×1.8    │
│               │
│ 第 4 套 · 5/12 │  ← 套数，小字
│ 今天 89 题 · ¥3238 │
└───────────────┘
```

## 三、科技：做完一套题出现

### 3.1 出现

- 第 1 套（第 12 题）答完的瞬间，左栏「科技」解锁，图标跳一下，带光圈。
- 「我」的独白：**做完了……然后呢？**
- 桌面便签待办：**去「科技」看看。**
- 第一次点开科技：只看得到第一行节点，其余是灰色轮廓。独白：**还能买东西？**

### 3.2 早期节点顺序

钱以第 1 套题的收入为准（现在约 ¥15–30），首个节点必须买得起。

| 顺序 | 节点 | 价格 | 前置 | 买完 |
|---|---|---|---|---|
| 1 | **训练曲线** | 刚好等于第 1 套的收入左右 | 无 | 「练」解锁 |
| 2 | **脑子窗口** | 低 | 训练曲线 | 桌面上出现一个可拖动的小窗，看它脑子的变化（第五节） |
| 3 | **{名字}代答** | 低 | 训练曲线 + 做完 2 套题（24 题）+ 练过 1 轮 | 「教」页每道题都显示它的回答（第四节） |
| 4 | **新题库：垃圾短信** 等数据包 | 中 | 训练曲线 | 「教」的任务大厅立刻多一张题桌（第六节） |
| 5 | 留出验证集、学习率、检查点、训练监控、权重可视化 | 见《练页教学指引》2.2 | — | 「练」页逐块补全 |

节点 2、3、4 的顺序不强制，三个都放在第二行，玩家按兴趣买。

## 四、{名字}代答：科技买，买了就一直显示

- **名字**：节点名、按钮名、显示的说话人，一律用玩家起的名字（`Sim.AiDisplayName`），不再出现「灵光」。
- **解锁条件**（不难）：买过「训练曲线」，做完 2 套题，练过 1 轮。
- **显示位置**：题卡和对 / 错按钮之间，单独一条，字号和题目差不多大，紫色：

```
┌────────────────────────────────────┐
│  手机可以用来打电话。                 │
│                                    │
│  len：对 · 72%                      │  ← 大字，紫色，玩家答题前就显示
├─────────────────┬──────────────────┤
│       对         │        错         │
└─────────────────┴──────────────────┘
```

- **没有次数限制**，每一道题都显示，不用点。
- 玩家答完后，这一条后面补一个 ✓ 或 ✗：它这次猜对了没有。玩家能直观看到「它越练越准」。
- 把握低于 55% 时显示「len：……不知道」，灰色。
- 原来的「求助灵光」按钮删除。

## 五、脑子窗口：取代看不见的壁纸大脑

壁纸大脑常被窗口挡住，玩家看不到。改成科技里的一个早期节点，买了以后桌面出现一个小窗：

| 项 | 设计 |
|---|---|
| 名字 | 「{名字}的脑子」 |
| 大小 | 默认 320 × 240，可拖动、可缩放、可最小化；关掉后从任务栏或开始菜单重新打开 |
| 位置 | 第一次出现在 .exe 窗口右侧；默认置顶，标题栏有「取消置顶」 |
| 画面 | 沿用现在壁纸大脑的画法（点和连线），只是缩到小窗里 |

**每一次操作都有一点变化**

| 操作 | 窗口里 |
|---|---|
| 「教」答对 | 对应题库的那片区域亮一下，一个点稍微变大 |
| 「教」答错 | 那片区域红光闪一下 |
| 连击到档位 | 整个窗口边框金色呼吸一次 |
| 「练」一轮 | 一道光从上往下扫过，连线变粗一点 |
| 新题库加入 | 窗口里长出一片新区域 |
| 学会一个新概念 | 一个新点亮起，旁边飘出概念名（如「打电话」） |
| 能力涌现 | 全窗口闪白，点阵重新排布 |
| 知识卡触发（过拟合等） | 窗口里对应现象的区域闪红，标题栏写现象名 |

壁纸恢复成普通的 2016 年桌面壁纸（海豚那张），不再画大脑。

## 六、新题库：买了就出现在「教」

**现在的问题**：数据包在「练」页左下角「数据来源 · 拖到 GPU 安装」，很难看到；买完只进了训练和测试，「教」页没有新题桌。

**改成**

- 数据包全部移到**科技里的「数据」分支**，和其他节点一样点击购买。
- 买完立刻：
  1. 「教」的任务大厅多一张题桌，带红色「新」标签，排在最上面。
  2. 托盘气泡：「新题库：垃圾短信」，点一下直接打开那张题桌。
  3. 这批题同时加进训练数据（原来的效果不变）。
- 删除：「数据来源」页签、「拖到 GPU 安装」、宽带 / 硬盘下载进度、「第 2/5 批」分批购买。一个题库一个节点，大题库可以分 2–3 级（Lv.1/3）。

## 七、「练」页：买了才有

### 7.1 买「训练曲线」后的第一版

```
┌──────────────────────────────────────────────┐
│ 常识判断                        第 1 轮       │
│ ┌──────────────────────────────────────────┐ │
│ │  （一条曲线：每轮答卷答对率）               │ │
│ └──────────────────────────────────────────┘ │
│ 它的答卷  3 / 4                               │
│  ✓ 一年有 13 个月。          它答 否           │
│  ✓ 一天有四十八个小时。      它答 否           │
│  ✗ 一年有十二个月。          它答 否           │
│  ✓ 鱼会爬树。                它答 否           │
│                                              │
│            [  训练一轮  ]                     │
└──────────────────────────────────────────────┘
```

就这三样：曲线、答卷、按钮。其余位置留空，不放灰框也不放「未解锁」字样。

### 7.2 之后每买一个节点，多一块

沿用《练页教学指引》2.2 的表，有两处修改：

| 原设计 | 改为 |
|---|---|
| T1「学习曲线」是要买的第一块 | 「训练曲线」就是解锁「练」的那个节点，买它即得 T1 |
| T11「数据来源」页签 | 删除（见第六节） |

现在页面上的其余内容（装备页签、它学会了吗、书架、资金账本、学习率六档、模型行、权重示意、风险预报、视觉/文字切换、下一项能力面板）全部对应一个科技节点或事件，没买就不显示。

## 八、知识卡进科技树图鉴

- 过拟合、练崩了（NaN）、退步、天花板等知识卡（内容见《练页教学指引》第三节），触发时照常弹出。
- 点「收下」后，卡片飞进左栏「科技」图标；科技树的**图鉴**分支里，对应节点从灰色问号变亮（复用现有图鉴节点 `XgSim.IsAtlas`）。
- 图鉴节点点开就是那张卡的全文。
- 成就页不再收这些卡。

---

## 九、摆渡众包

桌面上没有摆渡众包**是现在的设计**：它在阶段 4 才出现（《名词简化策划》§1.6），阶段 1–3 的答题都在「教」里。阶段 4 开放时图标弹出，用来接公司的委托。

## 十、程序清单（给 GPT 整合）

| 项 | 位置 | 改法 |
|---|---|---|
| 左栏锁定 | `XgSim.FeatureVisible`、`XingGuangView.Frame` | 「科技」= 已答 ≥ 12；「练」= 拥有 `train.curve` |
| 科技出现台词 | `InnerVoice.Say` + `GuideNote` 待办 | 第 12 题答完触发一次 |
| 教页逻辑 | `XgLabelPage`（开心辞典相关代码） | 去掉 12 题局、安全点、继续按钮、求助/换题/放弃；答完 0.25 秒自动下一题；倒计时只算快答奖励 |
| 连击 | `S.combo`、`XgCatalog.ComboTiers` | 跨套保留；右栏大号连击数 + 档位名 + 「第 N 套 · x/12」 |
| 答题特效 | `Fx.Float`、`Fx.Knock`、`XgJuice.Sfx` | 对：绿闪 + 飘钱 + 叮；错：红抖 + 飘扣钱 + 理由；档位：大字 + 金粒子 |
| {名字}代答 | 新节点 `label.ai`，前置 `train.curve`、`S.answers >= 24`、`S.epochs >= 1` | `XgLabelPage` 题卡下常驻一行 `AiDisplayName + "：" + 对/错 + 把握`；答后补 ✓/✗；删「求助」按钮 |
| 脑子窗口 | 新节点 `brain.window` + 新 `XgBrainWindow`（复用 `XgBrainWallpaper` 的绘制） | 独立可拖动窗口；订阅答题、训练、概念、涌现、知识卡事件做小动画；壁纸改回普通图 |
| 数据包 | `XgCatalog` 数据包节点挂到「数据」分支；`XgSim` 购买回调 | 购买即 `DeskOpen` 新题桌 + 「新」标签 + 托盘气泡；删 `XgTrainPage.Sources`、拖拽安装、下载进度 |
| 练页分块 | `XgTrainPage.Refresh` 每块 `SetActive(Sim.TrainPart(id))` | 默认只有曲线、答卷、按钮 |
| 知识卡 → 图鉴 | `XgLessonPopup` 收下后点亮对应图鉴节点 | 不再写入成就页 |
