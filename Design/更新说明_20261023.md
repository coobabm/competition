# 更新说明（2026-10-21 ～ 10-23）

本次上传把 10/21 发布 2026.10.21.4 之后、在本地完成的改动合到 GitHub。按主题列出，详细过程见《整合记录.md》中 10-22、10-23 两条。

## 一、改了什么

**AI 中文路径修复**
- 游戏装在含中文等非英文字符的路径下时，本地模型会加载失败。现在会先换成安全路径再加载（`LocalLLM/NativePathGuard.cs`）。

**标题不再自动开机**
- 标题画面里的电脑屏改为深色关机状态，不再自己亮屏开机，由玩家开机。

**存档**
- 读档时系统存档排在最前面。
- 补上「新游戏」入口。

**挂机小窗重做**
- 挂机小窗第三版（v3）重做。

**自动化收益调整、离线收益开关**
- 负责人 10/22 决定提高自动化收入：众包档位每秒 0.2 / 0.8 / 1.5 / 3 / 5 元，见面礼为 120 秒档位收入；自动答题拿一半加薪加成，每级每张题桌 +0.2 题/秒，价格 120×1.55^级。依据见《crowd-economy-20261021.md》。
- 设置里新增「离线收益」开关。

**鼠标问题修复**
- 只有左键能拖窗口、双击全屏；拖后台窗口会先把它提到最前。
- 拖动阈值按实际屏幕像素换算，小窗口下不再一碰就拖。
- 窗口拉到最小/最大尺寸后，鼠标要回到边缘才继续跟随，不再漂移。
- Esc 键行为统一（`EscapeKey.cs`），场景里只保留一个事件系统。

**设计不一致与科普纠错**
- 一批文案与设计稿对齐：加薪提示、自动答题引导走科技树、任务提示样式、众包见面礼提示、训练封印名称、LeNet-5 1998 / RNN 1990 年份统一等（完整列表见整合记录 10-22 条）。
- 科普纠错：散热科技统一叫「机箱风道」，效果写作「显卡高温损耗」，不再写「烧卡」「塔式散热器」；LeNet 改为「数字稍微挪一挪也能认出来」；「指令微调」改为游戏内的「示范跟答」；Dropout 年份改为 2012，反向传播标 1986，示范跟答 / 分步解题不再标 2022（游戏里是 2016 年的自研尝试）。
- 时代用词：桌面右下角水印改为「2016 · Aero 桌面」，显示器边框铭牌改为「HM-2310」，序章开机字改为「正在启动 Aero 桌面」。只改显示文字。

**开场提速 / 跳过 / BGM / 焦点引导 / 蜘蛛**
- 开场演出整体按 0.6 倍时长播放；每段可「点击加速 / 按住跳过」，标题后可直接跳过开场（起名设置不跳过）。
- 进入桌面就开始播放背景音乐。
- 第一次该打开灵光时，桌面压暗、只留灵光图标；常驻蜘蛛爬到图标旁搓手提示，打开后蒙版消失、蜘蛛离开。

**新题目背景自动答题**
- 新背景的题桌（F10）也显示自动答题状态，以及「交给它 / 我来做」「去训练」入口。

**按难度定价**
- 题桌单价按难度和耗时定价，高数、逻辑高于识图，识图高于常识、垃圾短信。

**赢棋奖励**
- 赢自家 AI 一盘给一笔奖金（和棋给 30%），每天前 3 盘有奖；第 4 盘起只记战绩。
- 飞行棋结束时不再显示规则两行，奖金和对局回执放在一起，避免文字超出。

**QA 检查更新**
- 刷新了一批界面检查以适应上述改动；新增 `P1OpeningQa`（开场节奏/跳过/F10）、`CaseMenuPlayQaBatch`、`PrologueLifecyclePlayQaBatch`（序章「否 / 是」两支）。
