## 一、反馈提取（按主题归并）

| # | 主题 | 玩家原话要点 |
|---|---|---|
| F1 | 开局太慢 | 开局演出拖，约 3 分钟才进入游戏内容；演出本来就多，动画播放也慢 |

| F4 | 自动化要能自选 | 应该让玩家自己决定哪些题自动做、哪些题自己做；不喜欢的题降低一点效率也能自动做，不至于直接砍掉一大半收益 |
| F5 | 花钱跳题 / 花钱练 AI | 可以花钱跳题、花钱练 AI |
| F6 | 题目定价不合理 | 费劲做出来的高数题，价格只有常识题的一半 |
| F7 | 整活难题 | 放一道很难的微积分题：一般玩家花钱跳过，总会有神人自己做 |
| F8 | 下棋奖励 | 可以设计赢棋直接奖钱 |
| F9 | 技能树看不懂 | 应改成「识图能力提升（1/6）」这样的效果名，科普放在等级后面一段话就行；网络深度 = 通用准确率提升；网络宽度 = 同时工作的项目数增多；学习率逻辑没问题，但转了个弯，不好理解 |
| F10 | 新题目背景不能自动化（bug） | 题目区有新旧两套背景，只有旧的显示自动答题和跳转，默认的新背景无法自动化 |

## 二、改进方案（按投入从小到大分三批）

### 第一批：快速修正（不改核心机制，1–2 天）

**A1 开局提速（F1、F2）**
- 目标：启动后 60 秒内进入第一次可操作的内容。
- 所有演出段落支持「点击加速 / 按住跳过」；第二周目起默认跳过。
- 动画时长整体压到 0.6 倍，删掉相邻的重复镜头。
- BGM 进入桌面就开始播放，不再绑在演出里。
- 需要先实测：现在从开机到第一次能操作，每一段各要几秒。

**A2 视觉焦点（F3）**——已有基础：常驻蜘蛛 `XgResidentSpider`
- 第一次该打开灵光 exe 时：桌面压暗（半透明蒙版），只留灵光图标高亮。
- 蜘蛛爬到图标旁边搓手，图标轻微呼吸闪烁；玩家点开后蒙版消失。
- 之后每次出现「该去灵光了」的引导，都只让蜘蛛指一下图标，不再加蒙版。

**A3 修新题目背景无法自动化（F10）**
- 新背景要和旧背景一样，显示自动答题状态和跳转入口。
- 这是 bug，第一优先修。

**A4 题目按难度定价（F6）**
- 每张题桌的单价改成「难度 × 耗时」：高数、逻辑 > 识图 > 常识、垃圾短信。
- 目标：高数单价是常识的 2–3 倍。只调题桌单价表，不动其他系统。

**A5 赢棋奖钱（F8）**——已有基础：对局记录、游戏中心
- 赢自家 AI 一盘给一笔奖金，按难度递增，每天前 3 盘有奖，避免刷钱。

**A6 技能树改成效果名（F9 第一步）**
- 节点主标题改成效果，原名放进副标题和科普：
  - 网络深度 → 「准确率提升 2/6」（副标题：网络深度 · 可用层数上限 3）
  - 网络宽度 → 「能力上限提升 2/6」，按它现在的实际效果写
  - 学习率搜索 → 「训练更稳 · 少走弯路」
- 悬浮卡片第一行写「升级后：xxx 从 a → b」，科普收在最后一段。
- 只改文案，不改数值，风险最低。

### 第二批：自动化改成玩家可控（核心改动，约 3–5 天）

**B1 自动答题槽位（F4、F12-5、F11）**
- 自动答题从「全局等级」改成「槽位」：初始 1 个槽，每升一级多 1 个槽，显示为「可同时自动 1/6 种题」。
- 玩家把题桌拖进槽位，或在题桌上点「交给它」，自己决定哪些题自动、哪些题手动。
- 挂机小窗和题桌上同时显示「槽位 2/3：识图 · 垃圾短信」。
- 小窗方面：现在是整个游戏切成一个系统小窗。玩家期待的是买下后固定在游戏桌面上的小组件。建议桌面上加一个常驻的「挂机面板」小组件，现有的系统小窗留作「最小化挂机」。

**B2 不达标也能自动，只是效率打折（F4）**
- 现在：题桌检查点 ≥60% 才能自动。
- 改为：任何题桌都能放进槽位；准确率越低，速度和单价越低（例如按准确率的平方计算），收入不会突然归零。
- 60% 改成「满效率线」，界面写成「当前效率 45%（准确率 52%）」。

**B3 AI 自己慢慢变准（F12-3）**
- 自动答对的题，按一定比例算作有效样本（例如每 20 题算 1 个），准确率会慢慢上涨。
- 界面显示「它在边做边学：+0.1%/分钟」。
- 和训练系统共用样本池，不另加新数值体系。

**B4 花钱跳题 / 花钱练 AI（F5、F7）**
- 难题卡上加「花 ¥x 跳过」，代价是这题不出样本。
- 加一道「神题」（如一道微积分）：每天一题，跳过很便宜，亲手做对奖励很高，并给一张成就卡。
- 「花钱练 AI」：在训练页加「外包标注 ¥x → +N 样本」，价格高于自己动手的收益。

### 第三批：技能树重构（大改，约 1 周，建议等前两批上线后再定）

**C1 按六要素重排技能树（F12、F14）**
- 主干分六条线：自动化（槽位）、准确率（每种题 + 通用）、自动提升准确率、速度（每种题 + 通用）、同时数量、单价。
- 现有的真实模型名（多层感知机、LeNet、RNN……）保留为「解锁这一线的里程碑」，放在副标题和科普里，保留本作「教 AI 认识世界」的特色。

**C2 共享电力（F13）**——已有基础：电费、显卡功率、「显卡没在算」状态
- 电脑有一个额定功率；显卡、自动槽位、训练都占功率。
- 总需求超过额定功率时，所有自动和训练按比例变慢。
- 加「省电」升级：每种题省电、通用省电。
- 这条线会改动经济平衡，必须单独测试。

## 三、建议的执行顺序

1. **A3**（bug）和 **A1、A2**（开局体验）：直接影响第一印象，最先做。
2. **A4、A6、A5**：只改数值和文案，很快就能见效。
3. **B1、B2**：玩家抱怨最集中的自动化问题，第一批上线后马上做。
4. **B3、B4**。
5. **C1、C2**：先出一版技能树草图，确认后再动。

## 四、需要拍板的问题

- B1 的「槽位制」会替换掉现在的「自动答题全局等级」，老存档按「现有等级 = 槽位数」迁移，是否同意？
- A6 的效果名和 C1 的重构是否二选一？建议先做 A6，看反馈再决定要不要做 C1。
- 开局演出是否允许第一周目就能跳过？建议允许，但先播完第一段标题镜头。
