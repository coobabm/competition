本政策适用于天星果工作室提供的《我的电脑活了》Windows 单机版本，说明游戏在您的电脑上处理的数据，以及您主动向我们反馈问题时我们如何处理相关信息。TapTap 等分发平台、电子邮件服务以及本政策网页的托管服务，由相应服务提供方依据其隐私政策处理信息。

一、核心说明

  • 游戏的 AI 对话由随游戏提供的本地模型在您的电脑上处理。我们不会通过本游戏把您的聊天输入、模型回复或存档上传到云端模型服务，也不会将这些本地内容用于我们的云端模型训练或跨用户画像。
  • 游戏会在您的电脑上保存进度、玩家设置、聊天和学习记录等数据。本地保存不等于开发者收到这些数据。 除非您主动发送反馈材料，我们无法通过游戏远程查看您的存档或聊天记录。
  • 游戏内的聊天软件、论坛、网页、下载、转账和模型发布情节属于模拟世界中的功能，不会因此给现实中的联系人发送消息、发起真实支付或把您的模型发布到互联网。
  • 本游戏没有独立的在线账号注册、云存档、广告展示或真实充值功能。分发平台的登录、下载、评论及其它平台服务不属于本游戏内部功能。

数据类别具体内容处理目的与位置

软件设置语言、音量、画质、窗口及界面偏好、减少特效等选项，模拟桌面的配置在本机保存使用偏好；部分设置由 Windows 注册表中的 Unity PlayerPrefs 保存

三、本地 AI、第三方组件与联网边界

本游戏使用 Unity 引擎及本地界面、音频、推理组件。Qwen 模型与 LLM for Unity／LlamaLib 等推理组件用于在设备上生成回复，不是向 Qwen 云服务或其它商业 AI 接口发送对话。游戏中的检索和记忆缓存也在本机处理。

当前 Windows 版本未启用 Unity Analytics、Unity Ads、Unity IAP 和 Unity 云崩溃报告服务。引擎与推理组件可在本地生成运行日志；我们没有为这些日志提供游戏内自动上传至工作室的功能。素材或程序使用某个第三方组件，不意味着该组件的所有在线服务均已启用。

您通过 TapTap、GitHub 或其它下载渠道获取、更新游戏，使用平台账号、评论、社区，或者通过系统浏览器访问外部网页时，相关提供方可能处理 IP 地址、浏览器或设备信息、平台账号和访问记录。这些行为遵循对应平台的规则，不应与游戏内模拟桌面的行为混淆。

本政策页面采用静态文档，不由工作室添加广告、统计脚本或跟踪 Cookie。页面托管方仍可能按其政策记录网络请求信息。GitHub 托管服务的说明可见：GitHub 隐私声明。

四、您主动联系开发者时的信息处理

您向 17383787@qq.com 发送咨询、问题反馈或权利请求时，我们会收到您的发件邮箱、邮件正文，以及您主动附上的截图、日志或存档。若您在平台公开反馈，我们可看到您在该平台公开或主动提供的信息。

我们仅将这些材料用于回复您的请求、复现故障、修复问题以及必要的争议处理。提供日志或存档并非游玩条件，您可以先用文字描述问题。发送前可删除与问题无关的名称、私人对话、个人文件路径及其它敏感信息；请不要公开发布未经检查的完整存档。

反馈资料仅供处理该问题所需的开发成员访问。我们不会出售您的个人信息，不将私人反馈用于广告营销，也不会未经许可公开带有可识别个人信息的反馈材料。邮件的传输与存储同时受您使用的邮件服务及我们使用的 QQ 邮箱服务规则约束。

五、保存位置、期限与删除

1. 本机数据

当前 Windows 版本的主要数据目录为：

%USERPROFILE%\AppData\LocalLow\DefaultCompany\competition\

其中可能包含 LingGuangV05 游戏存档及档案、快照和备份、模型检索缓存、DreamOS_UserData 模拟桌面数据、Music2016 自定义音乐目录，以及 Unity 的 Player.log 等日志。旧版本、便携版本或您自行使用的独立数据路径可能保留其它副本。

本机数据通常保留到您删除为止，部分日志会随运行更新或轮换。重新开始游戏、删除某一个存档或卸载程序，不一定会删除玩家档案、历史备份、缓存及所有设置。 若要完整清理，请先退出游戏，按需要备份个人素材，然后删除确认属于本游戏的数据目录、您另行导出的存档及备份。删除后可能无法恢复进度。

部分偏好存储在当前 Windows 用户的注册表 HKEY_CURRENT_USER\Software\DefaultCompany\competition 中。若需要清除这些设置但不熟悉注册表操作，请通过上述邮箱联系我们获取指导，不要删除其它程序的目录或注册表项。

我们无法替您从本机远程删除或恢复上述文件。您自行启用的操作系统备份、云盘同步或其它备份工具可能留存副本，需在相应工具中另行管理。

2. 主动提供的反馈

我们仅在处理反馈、提供必要后续支持以及履行法定义务所需的期间保留您发送的材料。问题处理结束且不再需要相关材料时，我们会删除或去除其中可识别个人的信息；依法需要保留或尚有未解决争议的除外。您也可以随时通过联系邮箱提出删除请求。

六、您的选择与权利

您可以选择不使用自由对话、不提供可选本地素材、不向我们提交日志或存档，并通过本地设置及文件管理控制数据保留。为提供存档、对话和记忆功能所必需的本地数据若被删除，相应进度和历史连续性将受到影响。

对于您主动提供给我们的个人信息，您可以申请了解处理情况、查阅或取得副本、更正、删除，以及依法撤回同意或提出其它请求。请邮件说明您的请求和此前反馈的基本线索；我们仅在必要范围内核实请求人与材料的关联，不会默认要求提交身份证照片。我们会尽快核实并答复；无法按请求处理时将说明原因。

本游戏没有工作室运营的在线账号，因此不存在游戏内工作室账号注销流程。TapTap 等第三方平台账号的注销需在对应平台办理。

七、未成年人保护

本游戏的适龄建议为16周岁及以上。未满18周岁的用户应在监护人指导下阅读本政策和使用游戏。我们不要求未成年人提供真实身份资料，也不会为了年龄判断在游戏内主动收集身份证件信息。

如监护人发现未成年人通过反馈渠道向我们提供了个人信息，可通过联系邮箱要求核实、更正或删除。对不满14周岁未成年人的个人信息，如确需处理，我们将依法取得监护人同意并采取相应保护措施；不再需要或不具备合法处理依据的，将及时删除。

八、安全措施与政策更新

我们通过本地处理、限制反馈资料访问范围等方式减少不必要的信息流转。存档及缓存并非为保存敏感资料设计，也不应被视为加密保险箱；能够访问您 Windows 账户和文件的人，可能查看或复制相关内容。请妥善管理设备、账号与备份。

如后续版本增加云端 AI、账号、云存档、在线统计、支付或其它改变个人信息处理方式的功能，我们将在启用前更新说明，并在依法需要时另行告知和取得同意，不把本政策视为对未来新增处理行为的一揽子授权。

政策更新将在本页标明日期。对个人信息处理产生重大影响的变更，我们会通过游戏更新说明或其它适当方式提示。
