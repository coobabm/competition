Bundled local inference software and model / 本版离线推理来源

Current Windows release / 当前 Windows 发行版

- Model: Qwen3.5-2B-Q5_K_S-emb5.gguf, based on Qwen3.5-2B by the Qwen team / Alibaba Cloud, Apache License 2.0.
  Base source: https://huggingface.co/Qwen/Qwen3.5-2B (bf16 GGUF and imatrix from bartowski/Qwen_Qwen3.5-2B-GGUF).
  Modified by the game team: a LoRA trained on the game's own dialogue is merged into the weights, the MTP (nextn)
  block is removed, and the file is quantized to Q5_K_S with a Q5_K token embedding.
  Full license, model card, source provenance and checksum are beside the model:
  MyComputerAlive_Data/StreamingAssets/LingGuang/Models/{LICENSE,MODEL_CARD.md,QUANT_MODEL_CARD.md,MODEL_SOURCE.json,SHA256SUMS.txt}.
  Recorded model SHA256: 4b154ece943d21ebdf8179935a335cd35897babd212cb144a86a8605bf1782b1 (1,306,533,984 bytes).
  Runtime use is text-only; no vision projector is bundled.
- Retrieval model: bge-small-zh-v1.5-q8_0.gguf, BAAI, MIT License; GGUF conversion by CompendiumLabs.
- LLMUnity 3.0.3, Undream AI, Apache License 2.0.
  Source: https://github.com/undreamai/LLMUnity/tree/9931a9ea46906b1f43adaf9498c05ccf227b5d0b
  The final distribution's ThirdPartyNotices/ contains LLMUnity-LICENSE.md,
  LLMUnity-ThirdPartyNotices.md and USearch-LICENSE, copied from this package.
  The upstream notice also lists optional downloadable models; that list is not this game's model inventory.
- LlamaLib v2.0.5, Undream AI, Apache License 2.0.
  Source: https://github.com/undreamai/LlamaLib/tree/21d3b9dcd1c05ad13f94f198e59462960019a057
  Windows CPU DLLs: MyComputerAlive_Data/StreamingAssets/LlamaLib-v2.0.5/win-x64/native/.
  The final distribution's ThirdPartyNotices/LlamaLib-Native/ contains full license texts and README-SOURCES.md:
  LlamaLib-LICENSE; llama.cpp-LICENSE (MIT, pinned 872646b30c342c5fa98efec002f94fdb4f1f1ea5);
