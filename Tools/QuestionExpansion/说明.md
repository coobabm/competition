# 题库扩充补丁（2026-10-21）

目标：每个文字类题包约 100 题，且在**开放当天**就有 20 题以上可以抽。算术、棋类、数独、看图类不在范围内。

## 文件

- `data/*.json`：新题原始数据，共 13 个题库约 1000 题，中英双语。改题就改这里。
- `build_bank.py`：校验 data，和各题包现有的题查重，然后生成 `XgQuestionBank.cs`。
- `apply_question_expansion.py`：把改动写进 Unity 工程。
  - 第一阶段：60 道手写题，加上按日期抽题、避免短期重复、标题党混抽、英文兜底。
  - 第二阶段：复制 `XgQuestionBank.cs`，在 11 个类里各加一个静态构造函数，把新题接到原数组后面。

## 使用

```
python -I build_bank.py <工程根目录>                        # 改过 data 才需要重跑
python -I apply_question_expansion.py <工程根目录> --check   # 只校验
python -I apply_question_expansion.py <工程根目录>           # 写入（先关掉这个工程的 Unity）
```

每处改动都先确认原文锚点只出现一次，对不上就一个文件都不写。可以重复运行，已打过的部分会自动跳过。
